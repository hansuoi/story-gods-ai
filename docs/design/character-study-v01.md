# 主要人物・作画用デザイン基準 v0.1

このファイルと [5人のシルエット比較図](character-lineup-v01.svg) は、「1枚見て誰か分かるか」の評価基準となる。比較図は編集可能なベクター試作であり、**完成したキャラクター原画ではない**。

**重要:** 全員を「細身・長髪・眼鏡の若者」に寄せると識別できなくなる。シルエットだけでも人物が分かるよう、肩の幅・頭身・髪の長さ・姿勢で差を作る。

## 比較図の見方

[シルエット比較図 v0.1](character-lineup-v01.svg) は服装・持ち物・年齢・体格の初期合意を図として示す。図の顔の造形は仮で、まだ美形さや作画方向、細部を固定していない。

### 安希

- 長いコートを脱ぐと事務所では袖をまくったブラウス。事務作業と現場移動が両方できる。
- 調査中は髪が乱れる。葬儀の整った黒服から、生活の仕事着へ移っていく変化もデザインの一部。
- 緊張しても眉だけ大きく動かさず、口を結ぶ・指を止める動作で表情を見せる。
- **描画NG:** 典型的な女探偵として眼鏡やトレンチコートの襟だけに頼って個性を作ること。

### 榊

- 救助シーンでは、能力の派手なエフェクトより **指先の数滴 → 固定ピン → 周囲の人の救助** を順に見せる。
- 水鉄砲は拳銃そのものを持つ技ではない。数滴の水を操作する。
- 無傷の遺体では白シャツ・キャンディーを外し、読者が「何かがない」と分かる口元にする。
- **描画NG:** 十代の少年のように見える輪郭や、能力の強さを水の奔流として描くこと。

### 凪

- 赤いウインドブレーカーの大きな首元と、右の刈り込みがシルエット上の特徴。写真の説明より先に手が安全ピンへ伸びる。
- ピンに結ばれた青糸はカラーだと青、モノクロだと細い白の糸と小さな結び目で示す。
- 罪悪感を隠すときだけ表情と手が一致しない。口元は笑っているのに指先が落ち着かない。
- **描画NG:** 長髪のお嬢様風、眼鏡で知的キャラにする、年齢を実年齢より10歳上に見せること。

### 久住

- 道具を整える手は最初から丁寧。疑わしくなった途端に悪役的な目つきへ急変させない。
- 肉体的な重さと、蝶番の軸だけを静かに動かす能力を対照にする。
- **描画NG:** 芹沢より若く見える細身のスーツ男性にすること。仕事着と太い腕は不可欠。

### 芹沢

- **女性47歳**。眼鏡の初老男性や権力者風のスーツには変更しない。
- 作業現場の責任者なので肩に使用感がある。髪に白髪を含み、年齢による仕事の積み重ねが出る顔。
- **描画NG:** 政治家・軍人のような飾った制服。敵組織の顔として不必要に悪役化しない。

## 生成画像のセルフレビューと扱い

本作の初期のイメージ生成試作では、漫画32ページを一覧する演出画像が複数作られた。しかし次の問題があったため**不採用**。

1. 第1話の2024年の救助を2018年と混同していた。
2. 主に榊の死を描く物語で、神谷椿が殺されたかのような説明も生じた。
3. 凪の髪型・年齢・能力小物が設定と一致しなかった。
4. 芹沢の性別、久住の外見や年齢、安希の髪型が作品内で一貫しなかった。
5. ネームの台詞・場面が既存の32ページ文字ネームと対応しなかった。

よって、生成画像を「完成ネーム」「公式キャラデザイン」として公開することは避ける。写真風の陰影、雨の背景、紙の余白といった**雰囲気のみ**参考にできるが、場面・文字・登場人物の設定は採用しない。

## 次の作画条件

- 第1話P01～P04とP05～P08の**別々の完成イメージ**をまず作る。32ページを1画像に詰めると、文字・人物・事件時系列が崩れやすい。
- 1枚で確実に描く人数は榊・安希・凪など2～3人まで。必要なら別カットを接続する。
- 文字・台詞は生成画像の中で確定させず、コマに文字を後から別レイヤーとして載せる。
- キャラシートは全身、顔、表情、背面、能力発動時の五つを分けて確認する。
- 年齢・性別・髪型・小物・人物の相互関係の**全項目一致**を採用条件にする。

## 合格判定（次の画像に対して）

- 設定上の年齢・性別・体格が5人とも一致。
- 白黒・シルエット表示でも人物が見分けられる。
- 凪と榊の能力を取り違えない。
- 第1話で**2024年の救助、2026年10月の榊の葬儀**が正しく分かれる。
- コマ・台詞は文字ネームと矛盾しない。

合格できなければ新しい案の生成か、コマ単位の手作業で調整する。
