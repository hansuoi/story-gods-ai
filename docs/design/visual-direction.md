# 漫画・キャラクターデザイン方針

本書は文章による初期デザイン仕様。画像・キャラクターシートの完成稿ではない。

## 基本的な画面設計

- ジャンルの軸は異能バトルだけではなく、記録・調査・家族劇。
- 戦闘と事務作業で画面を切り替える。帳票・現場図・鍵・損傷した蝶番・水位標を繰り返し視覚的な手掛かりにする。
- 「修復」は破損部が自然に戻る連続したコマで示す。「時間が巻き戻る」演出とは区別する。
- 証言や回想はそのまま事実と見なさない。同じ出来事を異なる証言で描く場合、画面の違いに意図を持たせる。
- モノクロでも人物を見分けられるよう、服の形状・身長・姿勢・小物を変える。

## カムイ能力の視覚表現

### 留め針
安全ピンが損傷に触れると、破損部の周囲に細い青い糸のような輪郭線が現れる。輪郭は動かず、周囲の修復だけが進む。維持時間の限界が近づくと糸の線が細くなる。

### 蝶番
使用者が触らなくても蝶番の回転軸に圧力線が現れ、扉が急加速する。人間への攻撃より、扉と壁の間にある危険を強調する。

### キャサディ・キャサディ
榊の水鉄砲は大量の水で押し流す技ではない。数滴の水を拳銃のような緊張感で使う。動作は小さく、着弾と効果は大きい。

### 神の無干渉
破損した面が徐々に連続してつながる。出血や破断も元に戻るが、失われた生命は戻らない。榊の遺体を見せる最初の場面で、その残酷な差を示す。
