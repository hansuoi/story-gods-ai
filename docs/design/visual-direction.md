# 漫画・キャラクターデザイン方針

本書は文章による初期デザイン仕様。画像・キャラクターシートの完成稿ではない。

## 基本的な画面設計

- ジャンルの軸は異能バトルだけではなく、記録・調査・家族劇。
- 戦闘と事務作業で画面を切り替える。帳票・現場図・鍵・損傷した蝶番・水位標を繰り返し視覚的な手掛かりにする。
- 「修復」は破損部が自然に戻る連続したコマで示す。「時間が巻き戻る」演出とは区別する。
- 証言や回想はそのまま事実と見なさない。同じ出来事を異なる証言で描く場合、画面の違いに意図を持たせる。
- モノクロでも人物を見分けられるよう、服の形状・身長・姿勢・小物を変える。

## カムイ能力の視覚表現

### 留め針
安全ピンが損傷に触れると、破損部の周囲に細い青い糸のような輪郭線が現れる。輪郭は動かず、周囲の修復だけが進む。維持時間の限界が近づくと糸の線が細くなる。

### 蝶番
使用者が触らなくても蝶番の回転軸に圧力線が現れ、扉が急加速する。人間への攻撃より、扉と壁の間にある危険を強調する。

### キャサディ・キャサディ
榊の水鉄砲は大量の水で押し流す技ではない。数滴の水を拳銃のような緊張感で使う。動作は小さく、着弾と効果は大きい。

### 神の無干渉
破損した面が徐々に連続してつながる。出血や破断も元に戻るが、失われた生命は戻らない。榊の遺体を見せる最初の場面で、その残酷な差を示す。

## コマ割りへの具体化

[第1話文字ネーム](../name/episode-01.md) と [32ページサムネイル](../name/episode-01-thumbnails.svg) を試作。

- **P02→P03:** 水滴を溜める小コマから、着弾を大コマへ。榊の能力は水量でなく狙いで見せる。
- **P04→P05:** 「帰るよ」の笑顔から、白い棺の無音の画面へ。
- **P06→P08:** 弔問の声と警察の説明は密度を下げ、無傷の遺体の異様さを先に見せる。
- **P11→P16:** 書類の拡大ばかりにせず、安希が鍵をかけて外へ出る動きを挟む。
- **P17→P24:** 凪の表情と安全ピンへ触れる指を使い、彼女が全部は話していないことを示す。
- **P30→P31:** 「依頼者：神谷榊」から「調査対象：神谷榊」へのページ転換を最大の謎の引きとする。

SVGサムネイルは**ページ設計の図**であって、人物が描かれた完成ネームではない。作画後に見開きの密度を点検し、つまらなければ構成を変える。

## デジタル単ページと紙の見開きの差

現行の第1話ラフは、[32ページ連続ビュー](../art/episode-01/gallery.md) で一枚ずつ順番に閲覧する構成を基準とする。ただし印刷漫画では**同じ見開きに隣接するページが同時に目に入る**。とくに「P04榊の『帰るよ』→P05白い棺」と「P30依頼者名→P31調査対象名」は、印刷のページ配置によって先の情報が読者に先に見えてしまう恐れがある。

- デジタル単ページ表示ではP04→P05、P30→P31の切り替えが読者へ順に見える。
- 印刷または見開き表示へ変更する場合は、ページの左右位置を固定してから引きのタイミングを再設計する。ページ番号だけから見開きの位置を決めつけない。
- 二つの場面が同時に見える場合、それを単なるネタバレとして残すのではなく、**笑顔と棺／依頼者と調査対象の並置**を意図した対比に作り変えるか、ページの挿入・圧縮で配置を変える。
- 物語の完成原稿化に際し、実際の閲覧環境で読めるかを確認する。

## 第3話・能力を画面で説明する際の原則

[第3話「十分間」文字ネーム](../name/episode-03.md)と[留め針の動作図](../name/episode-03-ability-sequence.svg)を制作した。

- 凪が安全ピンで触れるのは**久住のカムイが直接生んだ亀裂**。古い劣化や通常の錆を能力で保持することはできない。
- 久住が修復を発動するより前に凪がピンを接触させる。周辺のカムイ損傷は修復するが、その亀裂だけ残る。
- 安希が『時間が違う』と誤解する演出を置く場合、凪は『時間そのものではない』と説明する。
- 最大10分・直径15cm・一箇所という制約は、図解を長々続けず**目の前の傷と時計と職員の写真**で見せる。
