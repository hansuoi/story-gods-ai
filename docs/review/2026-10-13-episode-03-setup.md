# 第3話「十分間」の面白さ・作画前レビュー

## 物語上の役割

第3話は榊を直接襲った犯人の調査をいったん止め、**安希が自分も情報を隠していることを凪に指摘される**回。カムイの説明ではなく、信頼関係の非対称を読ませる。

## 期待している見せ場

- P04: 安希は凪から真相を聞く前に、凪の能力を見る選択をする。知っていることを伏せたまま見学するので、安希も無垢ではない。
- P08～15: 久住の蝶番で亀裂が生じ、凪が留め針で止め、写真と計測を経て解除する。『10分』を体で理解させる。
- P22～27: 凪が面会を決めたと認めた直後、安希も『知ってたのに黙っていた』と追及される。相手を裁くだけではない構成にする。
- P29～30: 金具に穴は残っていないが、修復記録と交換票に貫通痕の記載が残っている。榊の数滴が別の事件につながる。

## 問題と対応

| 優先 | 問題 | 方針 |
| --- | --- | --- |
| 高 | P05～15が設備講習の教材になりかねない | 板の動き・時計・測定者の手を大きくし、説明台詞を減らす |
| 高 | 久住を最初から不穏に見せると後の裏切りの痛みが弱くなる | 彼の安全確認は本心からの仕事として描く |
| 中 | 訓練で10分いっぱい能力を使う必要はない | 途中で解除してよい。無理に倒れる芝居はしない |
| 中 | 凪の『直径15cm』を半径と読ませる危険 | 脚本台詞を修正済み。作画用の動作図も追加 |
| 中 | 前話の夕方の約束と第3話の朝が食い違う | 第3話の開始を翌日午後に修正済み |
| 高 | P22～26の会話が尋問に見え、凪が一方的に追い詰められる | 凪にも『安希さんも』と反論する主体性を持たせる |
