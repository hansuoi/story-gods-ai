# 第1話・全32ページ構図ラフへのセルフレビュー

## レビュー基準

完成度の自己評価ではなく、**読者が読み続けたくなるか**を基準にする。絵がまだ下描き段階なので、画力を認証したかのような結論は出さない。

## 検証できたこと

1. 全32ページがそれぞれ別のSVGファイルになっており、コマの順番、主な画面配置をページ単位で編集できる。
2. P02の保持ピン、P03の解除レバーと人力救助、P04の修復の順序を脚本・ネーム・カットアウェイ図に統一した。
3. 榊の遺体の場面では、存命時の小道具であるキャンディーを描かないように修正した。
4. P31の「調査対象：神谷榊」は大きな文字で示す。P30では確定情報を先取りしない。
5. 凪と久住の服装、髪型、小物を見分けるためのベクター表現を付けた。

## 読み味に対する未解決問題

| 重要度 | 問題 | 対応 |
| --- | --- | --- |
| 高 | P09～16の帳簿・資料の画面に記号的な図が多く、読む速度が落ちる可能性 | 人物の手・身体・目線を中心に描き直す。文字情報の見せ方は最小限に |
| 高 | P04→05とP30→31は、印刷見開きでは先の内容が見える可能性 | 当面はデジタル単ページ閲覧。紙ではページ左右を確定したうえで再配置 |
| 高 | P01～04の水位・扉の立体的な関係はまだ図解水準 | 背景の三次元構図とレバー動作を実際のパースで描き直す |
| 中 | P05～08の遺体と喪服の安希はデフォルメが強く、喪失の痛みをまだ画力で表現しきれていない | 榊と安希の人物作画を優先 |
| 中 | P17～24の凪の表情は情報量が足りない | ピンへ触れる手と嘘をつく目線を別々のコマへ |
| 中 | P25～32の引きは文字に依存している | 紙の影と安希の反応の描写を増やす |

## 次の実作業

- P04とP05の並置や単ページ表示を検証するサンプルを作り、読み味を比べる。
- 第2話の文字ネームを実際のコマ設計へ移す前に、P16～20の救助の必然性をさらに確認する。
- 可能であれば榊・安希・凪の顔のアップを先に作画確定し、同じ人に見える作画テンプレートを揃える。
