# 面白さに基づく追加セルフレビュー (2026-10-12)

## 評価基準

- 最初の数ページで読みたいと思えるか。
- 事件の真相を知るほど、人物の見方が変わるか。
- 主人公が自分の選択で次の展開を起こすか。
- 能力の固有ルールを使わないと成立しない場面があるか。
- 物語の終わりに、初期の問題が変化した形で返ってくるか。

## 問題と修正

| 旧設定の問題 | どこが退屈か | 対応 |
| --- | --- | --- |
| 久住が最初から最後まで明らかな犯人 | 読者の驚きが乏しい | 芹沢を対立人物、久住を凪の信頼する先輩として描き、推理より関係の変化を重視する |
| 安希が帳簿を読むだけ | 主人公が事件に押されている | 凪を追及し、依頼人を訪問し、榊の過去を公開するか決める |
| 凪が偶然死の現場へ来る | 凪の選択が事件へ関係しない | 凪が榊を自ら呼び、予約情報から襲撃が起こったと変更 |
| 榊は調査で証言を隠しただけ | 榊の葛藤に具体的な痛みが乏しい | 榊自身が水門の安全栓を撃ち抜き、人を救う行為に加担した |
| 凪は写真を残すだけ | 異能バトルの意外性が薄い | 限定的な能力を、証拠か脱出経路かの二者択一に使う |
| 神谷椿の逸話は現在の焼き直し | 過去編に発見がない | 椿自身は犠牲者の名簿を残し、後世の信者が削除したと反転 |
| 榊が開始時点で死んでいるだけ | 魅力を知る前に退場する | 冒頭で榊が能力を工夫して人を救う場面を見せ、後の記録との落差を作る |

## 残る弱さ

- 主な舞台が排水施設や資料館に集中し、画面が単調になりやすい。章ごとに街の風景と人の生活を描く必要がある。
- 殺人犯の意外性だけで長編を持たせない。中盤の「榊も水門を開けた」事実を最も強い反転にする。
- 公共事業の責任と契約の話が説明過多になりやすい。人物の行動・物理的な事件・短い会話で示す。
- 榊の死亡理由と凪の行動を描く際、強さよりも位置取りと選択が勝敗を決めることを画面で示す。
- 人命か物証かという終盤の選択は、意図的な二者択一だと分かるように準備し、都合よく解決させない。
