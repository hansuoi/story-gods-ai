# 第1話「帰ってきた人」文字ネーム v0.1

**制作段階:** 作画前のコマ割り・視線誘導・台詞の指定。全32ページ。絵が実際に入った完成ネームではない。  
**準拠:** [第1話脚本](../scripts/episode-01.md) ／ [ビジュアル方針](../design/visual-direction.md)。  
**読む向き:** 日本語漫画の右から左、上から下。各コマの番号順に読む。「見開き」は左右ページを同時に読む前提で構成する。  
**基本演出:** 2024年は水滴の速い小さな動きと人物の大きな動作。2026年の安置場は余白と静けさ。調査中は安希の手元から相手の顔へ、紙だけに視線が留まらないようにする。

## 主役の見せ方

- 榊：小さく動く指先と、大きな動きで人を救う周囲の人々。技そのものより、狙いと判断が見えること。
- 安希：紙を整える指の速度と、頭が追いつかない時だけ止まる指。経理担当であることは手帳・帳票を見れば分かる。
- 凪：体重を前にかけて話す。嘘をつく時には安全ピンや袖へ指が行き、顔を正面に保てない。
- 久住：大きな体と静かな動作。読者がこの段階で犯人と断定できない優しさを描く。

> **作画ラフ:** [P01～P32のページ別ベクター画](../art/episode-01/README.md) を制作。現時点では線画・機械構造・人物の造形が未完成であり、台詞とコマ順を検証するための試作。

## P01–04：水鉄砲と「帰るよ」

### P01　雨の入り口
1. **縦長を横に広く使う・大**：階段上から地下歩道を俯瞰。雨と手前へ流れる水、階段の壁の水位跡。救助員は大声で「扉が開かない！」。奥の変形した防火扉は小さすぎないよう、長方形と斜めの枠が識別できる。端に「2024年」。
2. **横長の寄り**：扉の縦の隙間から、向こう側の少年の小さな手。膝まで浸水、顔は扉の影に隠れる。手は救助員に届かない。少年「だれか……」。濡れた手から水滴が落ちる小さな時間を使う。
3. **最下段・大**：救助員の背中と、びしょ濡れの革靴が一歩水へ入る瞬間。榊の顔もキャンディーも隠す。「開けりゃいいんだな？」。答えを待たず、靴の着水にページを終える。

### P02　数滴
1. **上段横長**：榊の半身。袖をまくった白シャツ、キャンディーの棒。救助員「水、どかせるのか？」。榊「そんな大仕事できねえよ」。
2. **小**：解除レバーを引こうとしても曲がった保持ピンに拘束されたラッチのカムが動かない。榊の指先がこの保持ピン一本を指す。「壊すのは、ここ」。
3. **細い横コマ**：人差し指の先に水滴が三つ浮かぶ。無音。滴の間に大きな余白。
4. **最下段横長**：榊の瞳と狙う固定ピンを同じ軸に置く。榊の声だけ「……よし」。**着弾の絵は次ページに送る。**

### P03　ピン
1. **ページ上半分・大**：水滴の白い軌跡が雨粒とは逆向きに細く走り、金具に命中。「ピンッ」。榊の手元から金具までを一画面でつなぐ。
2. **中**：保持ピンの切断によってカムが自由になり、救助員が解除レバーを引く。ラッチが退く。別の救助員が扉をこじ開ける。「押せる！」
3. **横長**：複数の救助員が扉を押し、少年の腕を引き出す。**榊一人の万能な救出にはしない。**
4. **小・末尾**：少年の靴が階段の乾いた段へ着く。少年「……たすかった」。

### P04　壊したところだけ
1. **小**：少年「魔法？」。榊、キャンディーを指で外す。「仕事だよ」。
2. **横長**：少年の退避後、榊が手を向けて修復を発動。切断した保持ピンだけがつながる。豪雨で元から曲がっていた金具の形、扉の開放位置、泥水は戻らない。少年「雨は？」。榊「オレが壊したもんじゃないからな」。
3. **中**：電話の着信「安希ちゃん」。安希（電話）「レシートは持って帰って。プリンも二つ」。榊「オレのは？」。安希「自分で買って」。
4. **ページ下の横長**：榊の笑顔。キャンディーを口へ戻す。「帰るよ」。背景の雨が少し白くなる。**次ページは同じ位置に榊を描かない。**

## P05–10：「帰ってきた」もの

### P05　タイトルページ
1. **全面絵**：白い棺が室内の斜め奥へ伸びている。手前に安希の喪服の肩と、握った手。榊の姿はまだ見せない。余白に「2026年10月」／**『神谷家 - 原状回復 -』**／「第1話 帰ってきた人」。**前ページの「帰るよ」と切り替わった意味を一瞬で伝える。**

### P06　無傷
1. **横長・大**：棺の中の榊。皮膚に傷はない。第4ページと同じ横顔の角度を選ぶ。ただし表情はない。台詞なし。
2. **小**：安希の指が頬へ伸びかけて止まる。
3. **縦長**：担当者の顔は半分だけ。「能力による損傷は修復されているそうです」。安希（小）「……それで、死因は？」。担当者の顔より、安希の止まった指の方に視線を戻す。
4. **小**：棺の縁。担当者（画面外）「警察が調べています」。安希の手が触れられないままの画面で終える。『修復と蘇生は違う』という解説台詞は入れない。

### P07　キャンディーがない
1. **大きな無音コマ**：榊の口元。いつもの棒がない。余白に白い花。
2. **細い二コマ**：参列者の言葉の断片「父を助けて」「いい人で」「いつも笑って」。顔は全員見せず、人の群れで圧迫感を作る。
3. **中**：安希の正面。「別の人みたい」。参列者には届かない小さな台詞。

### P08　扉
1. **横長**：警察の説明室。机を挟んで刑事と安希。空白を多く取る。
2. **中**：設備の簡単な参考図。刑事「旧汀橋排水管理室の扉で、頭部を打った可能性があります」。
3. **小**：安希「事故ですか？」。刑事「まだ断定できません」。
4. **大**：安希の顔を少し下から。「榊は、そんな簡単に扉に負けない」。刑事の返答は小さく「だから調べます」。

### P09　いつもあったもの
1. **縦長**：暗い家の玄関。靴箱の片側だけ空。
2. **小**：安希が空白へ無意識に「ただいま」と言いかける。吹き出しの後半を描かない。
3. **小**：テーブルの付箋「経費、帰ってから」。安希の指が端を剥がす。

### P10　返事のない人
1. **中**：安希、付箋の裏に何か書こうとするがペンが止まる。
2. **横長・大**：対面する椅子が二つ、片方に人がいない。安希「次はちゃんと説明してよ」。
3. **小**：時計の秒針。**音なしでページを終える。**

## P11–16：安希が動き出す

### P11　受付
1. **横長**：神谷探偵事務所。榊の椅子の背の白シャツ。
2. **中**：安希はシャツをよけず、帳簿を開く。紙とペンが定位置に戻る。
3. **小**：電卓「カタ、カタ」。次の数字に指が止まる。

### P12　空欄の予定
1. **上段**：予定表の夕方以降は空欄。「本当に休みだった？」
2. **中**：未処理の交通費に「汀橋方面」。安希の指がその行だけをなぞる。
3. **小**：時刻の重なるタクシー領収書。
4. **下段**：安希の横顔。「仕事もないのに、なんで……」。

### P13　2018
1. **大**：引き出しの奥から「2018年／汀橋」の封筒。八年前の封筒だけ端が傷んでいる。
2. **中**：水害の地図、住所一覧、資料番号。大量の文字は読めなくてよい。
3. **小・強調**：榊の字「保留」。その手前で安希のペン先が止まる。

### P14　連絡
1. **小**：安希が日付と案件番号をメモする。
2. **中**：刑事へ電話。「当日の行き先に関係する資料があります」。
3. **中**：刑事（電話）「現場には近づかないでください」。
4. **小**：安希が上着を取り、立ち上がる。台詞なし。**能動性を説明台詞ではなく動作で示す。**

### P15　それでも行く
1. **中**：事務所の扉に鍵をかける。鍵の金属音。
2. **縦長**：高架の下へ向かう安希を遠景で見せる。小さな人物。周囲の街は普通に動いている。
3. **小**：安希（モノローグ）「……誰に会うつもりだったの」。

### P16　現場
1. **横長・大**：古い水位標、旧汀橋管理室の外観。安希と重い扉の大きさが分かる。
2. **小**：新しい金具が柵の奥に見える。安希は立入禁止線に近づき、手を伸ばしかけて止める。距離があるため金具には触れられない。
3. **下段**：見えない背後から凪の声「そこ、工事中ですよ」。**姿はめくった次ページへ。**

## P17–24：三枝凪

### P17　最初の顔
1. **上段・大**：凪、片側を短く刈った髪、前傾の姿勢。胸元の青い糸付き安全ピンはモノクロでは白い細線で識別。
2. **中**：安希「夫が、ここで亡くなりました」。
3. **小**：凪の瞳が揺れる。「神谷さんの……奥さん？」。余計な不穏な効果線は使わない。

### P18　通報した人
1. **横長**：安全な休憩スペース、椅子は向かい合っていない。凪と安希が斜めに座る。
2. **中**：凪「救急に電話したのは、あたしです」。
3. **小**：安希「なぜ、そこへ？」。
4. **小**：凪の指が安全ピンへ。「修復の仕事なんで」。返答が狭いことを手元で示す。

### P19　消える証拠
1. **大・縦長**：スマホの写真。ひしゃげた蝶番と細い輪郭。写真の端に時刻の表示。現場写真と一目で分かるトーン。
2. **中**：安希、扉の新品の金具を思い出す。「今は直ってた」。
3. **小**：凪「十分だけ、直るのを止めました」。**能力の全説明は次ページへ渡す。**

### P20　留め針
1. **小**：安全ピンの先端に焦点。凪「留め針」。
2. **横長**：凪の指で机上に写真の破損範囲を示す。「一箇所だけ。十分だけ」。
3. **中**：安希「榊の身体も……こうやって戻ったの？」。
4. **小**：凪の手がピンを握り込み、答えが出ない。安希は追及しない。

### P21　写真の限界
1. **中**：凪「誰がやったかは、写ってない」。
2. **小**：安希「事故だったとも、まだ言えない」。
3. **横長**：二人が初めて同じ写真を並んで見る。凪「……はい」。

### P22　古い封筒
1. **中**：安希が「2018年／汀橋」の封筒を出す。
2. **小**：凪「まだ、持ってたんだ」。胸元のピンを握る。
3. **小**：安希「『まだ』？」
4. **大**：凪は顔を上げられず「仕事でも古い資料を使うので」。決定的な嘘だと断定できる画面にしない。

### P23　あの雨
1. **中**：安希「昔からこの近くに？」。
2. **横長**：窓の外の水位標。凪「あの雨の日、母もここにいました」。
3. **小**：安希「ごめんなさい」。
4. **小**：凪の視線が戻る。「謝るの、安希さんじゃないでしょ」。

### P24　受付
1. **中**：安希、聞き方を変える。「話してくれて、ありがとう」。
2. **小**：凪は初めて少しだけ笑う。
3. **中**：安希が名刺を差し出す。凪「探偵さん、もういないのに？」。
4. **横長**：安希の手元の名刺。安希「受付は、まだいます」。名刺の「神谷探偵事務所」を見せる。

## P25–28：信じたい顔、調べたい顔

### P25　久住
1. **中**：安希の背中が遠ざかる。
2. **大**：現場の奥から久住が現れる。大柄、作業着、道具を整えた手。「今の人は？」。
3. **小**：凪「神谷さんの奥さん」。久住「……大変だったな」。親切な一言として読める顔。

### P26　普通の先輩

2. **小**：久住「明日、安全点検から」。
3. **横長**：凪「いつもそれだ」。久住が笑う。凪も笑う。**疑いだけを盛るカットは置かない。**

### P27　返事を待つ場所
1. **横長**：帰りの電車。安希の隣の席は空いている。
2. **小**：スマホの凪の写真の金具と榊の無傷の顔が記憶として交差する。
3. **中**：手帳を開く安希。モノローグ「直せたものも、戻らない人も、ここにいる」。

### P28　もう一つの台帳
1. **中**：事務所の鍵を開ける安希。
2. **小**：当日の経費と2018年の案件番号を照合。
3. **大**：古い未整理ファイルの背に同じ番号。「……これ？」

## P29–32：この人は誰だったのか

### P29　本人へ
1. **小**：封筒の裏「本人へ返却」。
2. **中**：安希が榊の筆跡を見比べる。
3. **横長**：封筒を開く。中に薄い一冊。**中身の見出しはまだ読ませない。**

### P30　依頼者
1. **大**：表紙「汀橋水害・再調査」。下の記入欄「依頼者：神谷榊」。
2. **中**：安希「自分で、自分に依頼？」。
3. **小**：表紙を持つ指が、次の欄を隠している。**ページめくりの前に手の動きを止める。**

### P31　調査対象
1. **ページ上半分・大**：指をずらす。記入欄「調査対象：神谷榊」。読者に読める字の大きさ。
2. **中**：榊の顔を写した事務所の写真が、安希の手の影で半分隠れる。
3. **小**：中の紙は途中で切れ、綴じ穴に一枚分の跡。安希「一枚、ない……」。後出しの自白にはしない。

### P32　受け付ける人
1. **小**：非通知の着信。電話の表示だけを見せる。ここで相手の正体を匂わせすぎない。
2. **中**：安希が受話器へ手を伸ばす。手帳は閉じずに机へ。
3. **中**：安希「はい。神谷探偵事務所です」。電話の向こうはしばらく沈黙。
4. **下半分・大**：安希が「調査対象：神谷榊」を見つめる。顔に強い決意だけでなく怖さを残す。「夫のことなら、私が聞きます」。**第1話終。**

## ページをめくる動機の検証

| 仕掛け | 場所 | 読者の問い | 続くページで返すもの |
| --- | --- | --- | --- |
| 何が撃たれる？ | P02→P03 | 数滴で扉をどう開ける？ | 固定ピンだけを撃ち抜き、周囲が人力で救う |
| 「帰るよ」 | P04→P05 | 帰宅する夫婦の日常が続く？ | 2026年の棺。もう帰らない |
| 誰の声？ | P16→P17 | 死亡現場にいた人物は？ | 凪の登場 |
| なぜ凪は言い淀む？ | P18→P19 | 何を見た？ | 修復直前の写真。ただし発信者の秘密は未開示 |
| 調査の対象は？ | P30→P31 | 榊は何の依頼をしていた？ | 榊自身の名前 |
| 誰からの電話？ | P32→第2話 | 事件の犯人からの連絡？ | 実際は芹沢の事務連絡。小さな肩透かしから関係が始まる |

## ネームセルフレビュー

1. **第5ページへの転換が最強の引き。** ここへセリフを追加しない。読者に死を理解させるのは白い棺の画面。
2. **調査場面が長いリスクは残る。** P11～15とP27～30に帳票が集中する。視線の止まりをテストして退屈ならP12～14またはP28～29を圧縮する。
3. **警察が無能に見えないようにする。** 刑事も調査中。安希は業務台帳を持つ当事者だから新しい経路から情報に行き当たる。
4. **第19・20ページの金具の写真は別角度を一度も混ぜない。** 同一の写真だと分かるよう、独特の欠けた形を統一。
5. **能力の線はカラー前提にしない。** モノクロでも細い白の輪郭＋空白で識別する。
6. **第1話が文字ネームのままでは画面の密度は未評価。** 次段階で各ページのサムネイルを実際に並べる。

## 閲覧形式について

現行ネームは**デジタル単ページ閲覧**を暫定の基準にする。紙の見開き形式では、前後ページが同時に視野へ入ることで引きの強さが変わる可能性がある。[画面設計方針](../design/visual-direction.md) を参照。
