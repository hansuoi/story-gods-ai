# 第4話「閉じる扉」文字ネーム v0.1

[第4話脚本](../scripts/episode-04.md)に対応する全28ページ。**構図・読ませる情報・人物の選択**を先に固定する文字ネーム。まだ完成した漫画の絵ではない。

## この回のサスペンス

第4話の謎は『誰が蝶番を動かせたか』ではなく、**榊と凪の面会場所は誰の判断で、いつ、受付から設備廊下へ動かされたか**。凪が自主的に警察へ追加申告する行動と、久住が信頼できる先輩に見えることを必ず描く。

- A=受付、本来の待ち合わせ。B=曲がり角。D=点検扉。C=制御室。E=非常出口。配置・見通しは[現場図](../story/scene-geometry.md)と[作画用平面図](episode-04-site-plan.svg)を参照。
- 久住のカムイは視界内8m、金属蝶番一つの回転に働く。ただし**この回での訓練模型は静的な説明用**。事件の犯行を再現したかのように描かない。
- 凪は当夜の犯人を見ていない。廊下から大きな音を聞き、倒れた榊と破損金具を見たことだけを知る。
- 旧図面は後付けの仕切りを反映していない。写真との一致は仮説止まり。
- P09で撮影許可を得て写した一般向け案内掲示の写真は後半で回収する。内部ログには無断アクセスしない。
- **読み方は暫定的にデジタル単ページ**。右から左、上から下の順にネームを書く。

- **コマ:** 3コマ。
- **画面:** 机を俯瞰で。左『2018』の交換票、右『2026』の現場写真。安希が同じ場所に重ねようとした手を引く。

## 面白さに関するセルフレビュー

**最大の欠点候補:** P10～18は図面と説明の場面が9ページ続く。演出ではA/B/C/Dの位置を毎回説明せず、最初に一度立体的な場所を見せてから、安希の疑問で必要な部分だけを拡大する。
