# 第3話「十分間」文字ネーム v0.1

『神谷家 - 原状回復 -』の第3話・**全30ページ**の画面設計。準拠：[脚本](../scripts/episode-03.md)、[カムイ設定](../setting/kamui.md)、[登場人物](../characters/README.md)。

## 読ませる三つの場面

- **P01～04:** 安希は凪が夫を呼び出したと知っているのに、まだ追及しない。読者は安希の迷いも知る。
- **P05～20:** 久住と凪が実際に人の安全を守る仕事をしている。能力を「直す便利さ」ではなく「何を記録して残すか」の問題として見せる。
- **P21～30:** 相手の秘密を知りながら黙っていた安希と、榊を呼び出したことを隠していた凪。二人の信頼は簡単には回復しない。

### 固定する設定

- 凪の『留め針』は最大10分、直径15cm、カムイ由来の破損1箇所。時間そのものや動く扉は止めない。
- 久住の『蝶番』は視界内8m、同時に1つ。訓練でも人と模型の導線を分かるように描く。
- あらかじめ傷んでいた金具ではなく、**久住がカムイで破損させた新しい亀裂**を観察する。
- 「凪の見せた写真」から安希が直接榊殺害の犯人を知ることはない。
- 同じ日程：第2話で凪が『明日の夕方なら』と約束し、第3話は翌日の午後から始まる。

## 全ページの画面設計

### P01　同じ机

- **コマ数:** 3コマ。
- **画面と視線:** 机上の『差出人：三枝凪』を先に。反対側の榊の写真、安希の止まった手、インターホンの順。恐怖を説明しない。
- **脚本にある出来事:** 翌日の午後、神谷探偵事務所。安希は「差出人：三枝凪」のメールを紙に印刷し、榊の写真の隣に置く。1つ目のコマは向かい合う二つの名前。2つ目は安希の手。3つ目、インターホン。
- **引き:** 凪が約束通り来るか。

### P02　座らない人

- **コマ数:** 4コマ。
- **画面と視線:** 開いた扉を境界として凪が立つ。『ひとりはいる』で安希だけの椅子を見せ、空席は凪が避ける。
- **脚本にある出来事:** 凪が約束どおり来る。凪「探偵事務所って、もう人いないんですね」。安希「一人はいる。お茶くらいは出せます」。凪は榊の椅子を見るが座らない。


### P03　証拠の青い線

- **コマ数:** 3コマ。
- **画面と視線:** 凪の青いピン・写真の青い線を同じ位置へ。二人の口元を交互に、触れない距離で示す。
- **脚本にある出来事:** 安希「写真の青い線、あれは加工じゃないんですね」。凪「警察にも同じの出してます」。安希「その能力、どういうときに使うんですか」。凪「見ないと分かんないかも。今日、実地講習があるんで」。


### P04　伏せたメール

- **コマ数:** 4コマ。
- **画面と視線:** 安希がメール用紙を裏返す指のアップ→凪の表情→『見せてください』。隠し事は優しさにも攻撃にも見える。
- **脚本にある出来事:** 安希は印刷したメールを伏せる。「なら、見せてください」。凪「……奥さんが来るの？」。安希「見るまでは、私も分かったようなこと言わない」。凪は不安そうだが了承する。
- **引き:** 『見せて』の答えは危険な現場か。

### P05　訓練施設

- **コマ数:** 3コマ。
- **画面と視線:** 防護柵・移動板・安全線を一枚の俯瞰で見せる。凪と安希の位置が分かるように描く。
- **脚本にある出来事:** 神楽の訓練倉庫。防護柵・旧水門の小型模型・重量のある防火扉の実物大訓練台。久住が作業員に点検前の手順を説明している。


### P06　壊れた原因

- **コマ数:** 4コマ。
- **画面と視線:** 久住の手元の点検票を中心に、作業員の『戻るのに？』と久住の『記録を残す』を対比する。
- **脚本にある出来事:** 久住「今日はカムイ由来の破損を、修復する前にどう点検するか」。作業員「修復すれば全部元に戻るんじゃ？」。久住「戻す前に原因を見ないと、何が危なかったか残らない。戻っても劣化や誤操作は消えない」。安希、思わずうなずく。


### P07　見学者

- **コマ数:** 3コマ。
- **画面と視線:** 凪が安希へ保護眼鏡を渡す手。久住の『神谷さんの奥さん』への一拍は表情に出しすぎない。
- **脚本にある出来事:** 凪が安希に保護眼鏡を渡す。久住「見学の人？」。凪「許可取ってます。神谷さんの奥さん」。久住は一拍置き、「そうですか。安全線の内側へは入らないでください」。
- **引き:** 久住は何者か。

### P08　蝶番を動かす

- **コマ数:** 4コマ。
- **画面と視線:** 蝶番一つに力がかかる極小のアップ→板の大きな回転。久住が手を直接触れないことを明確に。
- **脚本にある出来事:** 久住が模型の金属蝶番1つを指さす。「この能力は1つの軸だけを回す」。短い手の動き。蝶番が回転し、訓練用の厚い板が勢いよく動く。作業員たちが驚く。
- **引き:** 蝶番の力が新たな破損を生む。

### P09　記録する前に

- **コマ数:** 3コマ。
- **画面と視線:** ビスに細いひび。久住は修復を始めず、凪がピンを近づけるのを待つ。事前の測定器も見せる。
- **脚本にある出来事:** 回転に負けた固定ビスにひび。久住「壊れた部分は神の無干渉で修復できる。だが、その前に記録だ。三枝、お前の番」。久住はまだ修復を発動させず、凪がピンを接触させるのを待つ。
- **引き:** 今から何を残すか。

### P10　留め針の条件

- **コマ数:** 4コマ。
- **画面と視線:** 凪の胸元のピンを外す動作。直径15cmの円を図解し、作業者のカウント用タイマーが始まる。
- **脚本にある出来事:** 凪が安全ピンを外す。「直径15センチの範囲で、1箇所。10分までです」。安希「10分」。凪「はい。それ以上はあたしが先に倒れる」
- **引き:** 一箇所・十 分が効いてくる。

### P11　同じ時間

- **コマ数:** 3コマ。
- **画面と視線:** 亀裂を青い輪郭で留めるコマ、近傍が直るコマ、安希の誤解に凪が答えるコマ。『時間の停止』には見せない。
- **脚本にある出来事:** ピン先が破損した固定ビスに触れる。久住「じゃあ、修復を始める」。青い糸のような輪郭。久住が起こした周辺の小さな損傷はゆっくり修復し、固定ビスの亀裂だけが残る。安希「そこだけ、時間が違うみたい」。凪「時間は同じですよ。傷が直るのを止めてるだけ」


### P12　記録の二分

- **コマ数:** 4コマ。
- **画面と視線:** 記録写真→スケール→時刻『02:00』。写真を撮る職員も主役の一員にする。
- **脚本にある出来事:** 作業員がスケールを当て、記録写真を撮る。久住「何分経った」。凪「2分」。安希はビスの欠けた部分と周りの完璧な金属を見比べる。


### P13　ひとつだけ

- **コマ数:** 3コマ。
- **画面と視線:** 別のひびへ目を向ける安希の視線。凪が指一本で『一箇所』を示し、久住は写真をとる作業員へ視線を戻す。
- **脚本にある出来事:** 安希「他のひびも、留められたら……」。凪「前のが直っちゃう。どれを残すか、先に決めないと」。久住「だから現場は一人の能力任せにしない。人間が写真と図面を残す」


### P14　指の震え

- **コマ数:** 3コマ。
- **画面と視線:** 震える凪の指を大きく、安希の『無理してない？』は小さく。凪の強がりは笑顔と手の差。
- **脚本にある出来事:** 凪の指先がわずかに震える。安希「無理してない？」。凪「いつもです」。強がりだと分かる顔。安希の視線が、榊の写真を見せたときと同じ安全ピンへ落ちる。
- **引き:** 無理に能力を持たせず解除する選択。

### P15　消える亀裂

- **コマ数:** 4コマ。
- **画面と視線:** 安全に計測を終え、凪が解除。二つの縁が連続してつながる。職員の手には写真が残っている。
- **脚本にある出来事:** 計測が終わる。凪がピンを離す。亀裂がつながり、金属が元に戻る。作業員「さっきの亀裂、どこ？」。安希「……ない」。凪「だから残すんです、写真でも、数字でも」
- **引き:** 修復後、証拠はどこにあるか。

### P16　別の扉でも

- **コマ数:** 3コマ。
- **画面と視線:** 休憩室。久住は実際の危険な扉ではなく模型の図で説明する。凪は自分の仕事へ戻る。
- **脚本にある出来事:** 休憩時間。安希は久住に尋ねる。「ああいう壊れ方、扉でも？」。久住「そりゃ構造によります。扉を壊すカムイ使いは俺だけじゃない」。安希は凪の写真を見直す。


### P17　修復と安全

- **コマ数:** 4コマ。
- **画面と視線:** 修復済みと点検済みの異なる印。安希は榊なら好んだ言葉と感じるが、久住の曖昧な視線を見落とす。
- **脚本にある出来事:** 久住が一般向けの修復前後の点検票を示す。「『修復済み』は『安全確認済み』じゃない。だから俺たちがいる」。安希「その考え、榊も好きそう」。久住「榊さんは……現場に首を突っ込む人でした」。


### P18　八年前の現場

- **コマ数:** 3コマ。
- **画面と視線:** 『汀橋』の単語の前後で画面の明暗を変える。警報音は工具を落とした無害な事故と分かる画面に戻す。
- **脚本にある出来事:** 安希「8年前の汀橋でも？」。久住の表情は読めない。「あそこは誰も、好きであんな仕事したんじゃない」。警報音。別の訓練台で作業員が工具を落としただけ。何も起きていない。安希だけが身構える。
- **引き:** 久住の曖昧な言葉の意味。

### P19　この人の仕事

- **コマ数:** 3コマ。
- **画面と視線:** 床の工具を拾う凪。新人から『ありがとう』の目線。凪には安希の知らない暮らしがある。
- **脚本にある出来事:** 凪は床の工具を拾って新人へ返す。「また明日も使うんだから、数えといてね」。安希は凪がここでは頼られる存在だと知る。


### P20　変わらない時間

- **コマ数:** 3コマ。
- **画面と視線:** 倉庫の出入り口。『時間は同じ』は屋外の太陽位置を同じコマで見せる。少し離れた二人。
- **脚本にある出来事:** 倉庫の出口。安希「さっき『時間は同じ』って言ったでしょう。傷が直っても、あの時間に誰が何をしたかは変わらない」。凪「変わってほしいことも、ありますけどね」。二人の間に沈黙。
- **引き:** 安希は本題をいつ切り出すか。

### P21　川の道

- **コマ数:** 3コマ。
- **画面と視線:** 川沿いへ。信号や行き交う人を画面端に置き、突然の尋問室にしない。
- **脚本にある出来事:** 倉庫を出て近くの川沿いへ。安希「昨日の夜から、あなたに聞きたかったことがあります」。凪は立ち止まる。


### P22　見せたメール

- **コマ数:** 4コマ。
- **画面と視線:** 安希が紙を差し出す腕の長さ。凪は受け取る前に文字を見て止まる。紙の宛名だけ読ませる。
- **脚本にある出来事:** 安希が送信メールの印刷を差し出す。「榊の仕事用メールに残っていた」。凪、顔色が変わる。安希「旧施設の面会を決めたのは、あなたですか」。長い無言。
- **引き:** 凪は呼び出しを認めるか。

### P23　呼んだ人

- **脚本にある出来事:** 凪「……そうです」。安希「なぜ、昨日は言わなかったんです」。凪「怖かった」。安希「私が怒ると思って？」。凪「あたしが呼ばなきゃ、神谷さんは死ななかったから」


### P24　どんな穴

- **脚本にある出来事:** 安希「何を見せたかったの」。凪「写真です。八年前の部品の」。安希「どうしてそれを夫に」。凪「見覚えのある穴があったから」。安希「どんな穴？」。凪は目を伏せ、「……次、ちゃんと持ってきます」。


### P25　問う側の嘘

- **コマ数:** 3コマ。
- **画面と視線:** 安希が一歩迫る→足を止める。凪の『安希さんも』をページの最後に小さく置く。
- **脚本にある出来事:** 安希「今、言えない？」。凪「自分でも、間違ってるかもしれない」。安希は追いつめかけて踏みとどまる。「分かった。ただ、もう嘘はつかないで」。凪「……安希さんも」

### P26　試された人

- **脚本にある出来事:** 凪「安希さん、昨日から知ってたんですね。なのに、普通に話してた」。安希は言葉に詰まる。凪「先にあたしのこと、見たかったから？」。安希「……そう。あなたを知らないまま決めつけたくなかった」。凪「それって優しさですか？」


### P27　同じ怖さ

- **コマ数:** 3コマ。
- **画面と視線:** 互いの手から紙を離し、初めて相手の目を見る。『怖いのは一緒』を中心に、和解しきらない。

- **引き:** 信頼の持ち方が変わる。

### P28　交換票

- **コマ数:** 3コマ。
- **画面と視線:** 透明な袋から交換票。安希は勝手に開かず『見てもいい？』と尋ねる仕草を追加する。
- **脚本にある出来事:** 凪が鞄から透明な書類袋を出す。中に2018年の交換票のコピー。凪「写真を持って来るのは明日。この紙が、どの部品かの証拠です」。安希はその場で読まず、凪の同意を確認して受け取る。


### P29　修復済み／交換

- **コマ数:** 4コマ。
- **画面と視線:** 事務所へ戻る。『修復済み』と『後日交換』の二つの印が同じ紙に共存。どちらも消さない。
- **脚本にある出来事:** 安希、事務所へ戻る。交換票に「修復済み／後日交換」の二つの印。榊の2018年の報告には交換の記載がない。安希「直ったのに、なぜ交換する必要が……」。※ここでは「検査用に取り外した可能性」を否定しない。

### P30　どこに撃った

- **コマ数:** 大ゴマを含む3コマ。
- **画面と視線:** 冒頭榊の水滴の射線と、安全栓の貫通痕の写真を重ねる。ただし穴の同一性はまだ断定しない。
- **脚本にある出来事:** 安希が榊の水鉄砲の映像を思い出す。P02の小さな固定ピン。交換票には「安全栓、固定部貫通」。安希の横顔。「あの人は、何を撃ったの」。**第3話終。**
- **引き:** 誰がその穴を開けた？


## ネーム化に先立つセルフレビュー

1. **P05～15の能力講習が説明過剰になる危険:** 時計・傷・観察者・写真に行動を持たせる。台詞を削っても成立するかを描画段階で確認。
2. **P16～19に久住の犯人らしい不自然な目線を入れない:** 仕事を教える先輩としての信頼を先に確立することが後半の痛みになる。
3. **P22でメールを差し出す安希の行動が卑怯に見えうる:** P01～04でメールを伏せたこととP26で凪が指摘することは計画的な対応。安希の弱さとして残す。
4. **P28～30の安全栓と交換票は物証の区別が難しい:** 金具の**実物**に穴が残っているのではなく、修復前の記録と交換票の記載に貫通痕が残る。
5. **デジタルの単ページ閲覧を暫定基準**とし、P29→30の画面転換を印刷見開きにした場合は再検証する。
