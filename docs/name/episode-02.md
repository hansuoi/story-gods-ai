# 第2話「名前のない電話」文字ネーム v0.1

全32ページのコマ構成・画面設計を、[第2話脚本](../scripts/episode-02.md) の各ページに対応付けた。文字ネームであり、人物画が入った完成ネームではない。32ページの配置は [一覧サムネイル](episode-02-thumbnails.svg) を参照。

## 演出の約束

- **安希は31歳、凪は20歳、芹沢は47歳の女性。** [人物デザイン基準](../design/character-study-v01.md) に一致させる。
- 本話の電話は、榊死亡をめぐる脅迫ではなく神楽の資料照会。読者の不安と現実の事務連絡の落差を生かす。
- 住宅街は「悲劇の跡地」だけでなく、現在そこに暮らしている人の生活を必ず描く。
- 折原の場面では報告書の説明よりも、写真を置く、相手の発言を待つ、湯飲みを寄せる所作を優先。
- 芹沢は電話口の事務的な正確さと、現場で子どもを守る速さを両方描く。
- 第1話の凪の言い淀みから彼女を疑う。メールの差出人が凪だと確定するのは**P31**。安希もそれ以前には知らない。
- 榊の業務メールは事務所の共有端末。アクセス権を持たない情報を安希が勝手に取得する展開にはしない。

## ネームを画面に変える際の課題

1. **P05～08:** 帳簿・住所・報告書と紙が続く。P06の現在の地図、P08の白シャツを大きく使い、紙面の反復を避ける。
2. **P12～15:** 折原の言葉が事件の意味を変える部分。人物を正面に並べるだけでなく、写真の移動を描く。
3. **P16～20:** ちょうどそこに子どもが転ぶという偶然が都合よく見えかねない。P16で未固定の柵・立入規制・落ちた玩具と子どもの位置を示し、P17で子どもを視野に残す。P18の事故を読者だけが予見できる配置にする。
4. **P21～26:** メール検索の工程が6ページ。テンポが悪ければ二ページ程度圧縮することを許可する。
5. **P31～32:** 『差出人：三枝凪』はP31で一度だけ明瞭に示す。P32はその文字ではなく、安希の表情と『あなたが呼んだ』の言葉を主とする。

第1話の最終ページと同じ表情で第2話P01を始め、電話の主が分かった直後から時間を進める。

## 閲覧形式について

現行ネームは**デジタル単ページ閲覧**を暫定の基準にする。紙の見開き形式では、前後ページが同時に視野へ入ることで引きの強さが変わる可能性がある。[画面設計方針](../design/visual-direction.md) を参照。
