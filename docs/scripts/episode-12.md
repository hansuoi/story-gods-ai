# 第12話「直す仕事」

**漫画脚本初稿／30ページ想定。** 神楽が人を救っていることも、過去の記録を隠していることも、同じ組織の事実として見せる。芹沢は弁明役ではなく、いま起きた問題に判断を下す現場責任者として描く。

## P01–04　送信しました

**P01｜3コマ。** 魂ヶ丘市の低い住宅地。防災訓練の日。神楽の移動指揮車から職員が案内を配信。「一斉通知、送信完了」。小さな河川の増水センサーが点滅する。

**P02｜4コマ。** 町内会の女性が職員へ「うちの班には何も来てないよ」と告げる。職員「送信は完了しています」。女性「じゃあ、私の携帯が悪いの？」。近くの高齢者も端末を見て首をかしげる。

**P03｜3コマ。** 芹沢が歩いて来る。「送信済みは、受信済みと違う。地区ごとに確認して」。職員が設定画面を開く。特定の配信経路だけ「応答なし」。芹沢「紙の配布と声かけに切り替える」。

**P04｜4コマ。** 職員たちが避難訓練の経路へ走る。凪は神楽の別の班にいて、折原の近所の人を誘導している。「走らなくて大丈夫。段差があるから、そこだけ気をつけて」。芹沢は、ここで仕事を止めない選択をする。

## P05–09　現場へ来た人

**P05｜3コマ。** 安希が神楽の窓口に到着。事前に正式に予約した面談。担当は訓練中と謝るが、安希「訓練を優先してください。私は待てます」。かつて電話で急かした芹沢が遠くにいる。

**P06｜4コマ。** 安希は待合室から屋外の訓練を見て、2018年の「送信処理／受信確認」の空欄を思い出す。端末が鳴らない人々。「八年前も、こうだったのか」。凪の姿を見つけるが声をかけない。

**P07｜3コマ。** 芹沢が戻り、作業靴を拭く。「お待たせしました」。安希「謝らなくていい。あの人たちは、訓練を待ってたから」。芹沢「話があるなら、現場を一緒に歩きましょう」。

**P08｜4コマ。** 工事中の護岸。芹沢「カムイで壊した金具は元に戻せます。でも劣化した壁まで全部直るわけではありません」。安希「だから現場に人が必要なんですね」。芹沢「人がいなければ、間違いも見つかりません」。

**P09｜3コマ。** 安希「八年前には、何を見落としましたか」。芹沢「水位ではないことは確かです」。二人の足元、低い方へ流れる水。「伝える相手のことです」。

## P10–15　八年前の決断

**P10｜4コマ。** 安希、2018年の公開報告を開く。「病院側への浸水を回避。住宅地に被害」。芹沢「病院に避難できない人がいた」。安希「だから門を開けた」。芹沢「はい」。

**P11｜3コマ。** 安希「住宅地には、事前に知らせられた？」。芹沢「送信指示はしました」。安希「届いたことは確認した？」。芹沢、答えに少し間を置く。「確認は取れていませんでした」。

**P12｜4コマ。** 安希「それでも開けた」。芹沢「待てば病院が危なかった」。安希「そう判断した根拠は調べます。でも、確認できないことを後で確認できたように書く理由にはならない」。

**P13｜3コマ。** 芹沢「あなたは正しいことを言う」。安希「そうですか」。芹沢「正しくても、次の雨は来る」。安希「だから、同じ記録の扱い方を続けてはいけない」。

**P14｜4コマ。** 現在の訓練で、応答なし地区に人が向かった報告が届く。芹沢は現場へ指示。「全戸確認した？　完了と書くのはその後」。安希は、芹沢が今日できていることを見ている。

**P15｜3コマ。** 安希「いまは、受信を確認してから完了にしている」。芹沢「八年前の結果を受けて変えました」。安希「変えた事実を誇るなら、なぜ変える必要があったかも書いてください」。

## P16–20　失う仕事

**P16｜3コマ。** 芹沢「過去の資料のすべてを公開すれば、今の委託が止まる可能性があります」。安希「止めるかどうかは行政と市民が決めることです」。芹沢「その間にも水位は上がる」。

**P17｜4コマ。** 芹沢が凪の班を示す。「あの子はここで仕事を覚えた。住む場所も、職も、復旧支援から繋がっている」。安希「その子は、母親を亡くしています」。芹沢「知っています」。目をそらさない。

**P18｜3コマ。** 安希「両方ある人に、どちらかを選ばせてきたのは誰ですか」。芹沢は答えず、応答記録の一覧を見る。安希「夫も、同じことをした」。

**P19｜4コマ。** 芹沢「榊さんは有能でした。だから、頼ってしまった」。安希「あなたも水門にいたんですか」。芹沢「指揮所にいました。現場へ開放の指示を出したのは私です」。安希にとって初めて、芹沢が自分の判断を自分の口で言う場面。

**P20｜3コマ。** 安希「その後の報告も？」。芹沢「統括者として承認しました」。安希「では当時の警告記録を、監査と捜査に出してください」。芹沢「正式な請求なら、受けます」。安希「今日、書いて持ってきています」。書類を差し出す。

## P21–25　残っていた時刻

**P21｜3コマ。** 芹沢は請求書を読む。安希の項目には「発信時刻」「各地区の受信確認時刻」「失敗時の代替連絡」が別々にある。芹沢「こういう書き方をするのは、榊さんと違いますね」。安希「私は、榊ではないので」。

**P22｜4コマ。** 芹沢はすぐに書類を渡せないと説明する。原本の管理者、個人情報、監査の手続きがある。「でも何が残っているかはお伝えできます」。安希「お願いします」。

**P23｜3コマ。** 芹沢「当時のシステムには、送信の記録と、受信応答の記録が別にあります」。安希「どちらも残っている」。芹沢「一部は」。曖昧な『一部』を安希はノートに書く。

**P24｜4コマ。** 芹沢「病院区画は早い時刻に応答がありました。住宅区画の一部は、開門後に応答した記録です」。安希の手が止まる。「開門前には届かなかった？」。芹沢「少なくとも、開門前に受信できたことは確認できない」。

**P25｜3コマ。** 安希「その違いを報告書で伏せたんですね」。芹沢「報告には送信済みとだけ書きました」。安希「送るだけで済んだことにした」。芹沢は否定しない。

## P26–30　いま届く声

**P26｜3コマ。** 凪が訓練を終えて戻り、遠くの安希と芹沢を見る。会いに行きかけて、やめる。職員に「点検票はどこ」と聞かれ、仕事へ戻る。

**P27｜4コマ。** 安希「正式な記録を見られるまで待ちます。その代わり、照会したことは残しておきます」。芹沢「それでいいです」。安希「よくないと思います。でも、勝手に持ち出すよりはいい」。

**P28｜3コマ。** 芹沢「あなたが隠そうとしているものは、ないんですか」。安希の表情が硬くなる。凪の言葉「あなたも同じことするんだ」が頭をよぎる。安希「あります」。初めて自分から認める。

**P29｜4コマ。** 安希「だから、私の記録も後で見てもらいます」。芹沢「榊さんのことを？」。安希「榊が何をしたか。私が何を伏せようとしたかも」。芹沢「……なるほど」。二人は和解しない。

**P30｜大ゴマを含む3コマ。** 訓練の最後の確認票。ある地区の送信欄に○、受信欄にも少し遅れて○がつく。隣に2018年の公開報告「住宅地への警報：送信済み」。安希（モノローグ）「届かなかった時間がある」。**第12話終。**

## 脚本チェック

- 芹沢は2018年の指示と報告への関与を認めるが、「故意に6人を殺した」とは言わない。
- カムイが直接破損させたものだけが修復対象。雨・自然災害は神の無干渉で元通りにならない。
- 受信未確認は、全住民が受信していなかったことの証明ではない。記録の限界を繰り返し明示する。
- 現代の訓練で修正された業務手順を見せ、神楽がまったく学習しなかった組織という描写を避ける。
- 芹沢が安希へ提供するのは記録の存在と管理上の説明。原本は正式手続きを通じて収集する。
- 次の第13話では、神楽の歴史資料と椿の名簿を調べ、現在の「人命を救ったという記録」がどう書き換わるかのテーマを別角度から描く。
