# 第3話「十分間」

**漫画脚本初稿／30ページ想定。** 第2話ラストの直後。安希は凪が面会を設定したと知っているが、問い詰める前に「その能力で何を残せるのか」を見ることを選ぶ。最後には、その選択が榊の癖と似ていたと自覚する。

## P01–04　知っていること

**P01｜3コマ。** 朝の事務所。安希は「差出人：三枝凪」のメールを紙に印刷し、榊の写真の隣に置く。1つ目のコマは向かい合う二つの名前。2つ目は安希の手。3つ目、インターホン。

**P02｜4コマ。** 凪が約束どおり来る。凪「探偵事務所って、もう人いないんですね」。安希「一人はいる。お茶くらいは出せます」。凪は榊の椅子を見るが座らない。

**P03｜3コマ。** 安希「写真の青い線、あれは加工じゃないんですね」。凪「警察にも同じの出してます」。安希「その能力、どういうときに使うんですか」。凪「見ないと分かんないかも。今日、実地講習があるんで」。

**P04｜4コマ。** 安希は印刷したメールを伏せる。「なら、見せてください」。凪「……奥さんが来るの？」。安希「見るまでは、私も分かったようなこと言わない」。凪は不安そうだが了承する。

## P05–09　仕事場へ

**P05｜3コマ。** 神楽の訓練倉庫。防護柵・旧水門の小型模型・重量のある防火扉の実物大訓練台。久住が作業員に点検前の手順を説明している。

**P06｜4コマ。** 久住「今日はカムイ由来の破損を、修復する前にどう点検するか」。作業員「修復すれば全部元に戻るんじゃ？」。久住「戻す前に原因を見ないと、何が危なかったか残らない。戻っても劣化や誤操作は消えない」。安希、思わずうなずく。

**P07｜3コマ。** 凪が安希に保護眼鏡を渡す。久住「見学の人？」。凪「許可取ってます。神谷さんの奥さん」。久住は一拍置き、「そうですか。安全線の内側へは入らないでください」。

**P08｜4コマ。** 久住が模型の金属蝶番1つを指さす。「この能力は1つの軸だけを回す」。短い手の動き。蝶番が回転し、訓練用の厚い板が勢いよく動く。作業員たちが驚く。

**P09｜3コマ。** 回転に負けた固定ビスにひび。久住「壊れた部分は神の無干渉で修復できる。だが、その前に記録だ。三枝、お前の番」。久住はまだ修復を発動させず、凪がピンを接触させるのを待つ。

## P10–15　青い輪郭

**P10｜4コマ。** 凪が安全ピンを外す。「15センチ以内、1箇所。10分までです」。安希「10分」。凪「はい。それ以上はあたしが先に倒れる」

**P11｜3コマ。** ピン先が破損した固定ビスに触れる。久住「じゃあ、修復を始める」。青い糸のような輪郭。久住が起こした周辺の小さな損傷はゆっくり修復し、固定ビスの亀裂だけが残る。安希「そこだけ、時間が違うみたい」。凪「時間は同じですよ。傷が直るのを止めてるだけ」

**P12｜4コマ。** 作業員がスケールを当て、記録写真を撮る。久住「何分経った」。凪「2分」。安希はビスの欠けた部分と周りの完璧な金属を見比べる。

**P13｜3コマ。** 安希「他のひびも、留められたら……」。凪「前のが直っちゃう。どれを残すか、先に決めないと」。久住「だから現場は一人の能力任せにしない。人間が写真と図面を残す」

**P14｜3コマ。** 凪の指先がわずかに震える。安希「無理してない？」。凪「いつもです」。強がりだと分かる顔。安希の視線が、榊の写真を見せたときと同じ安全ピンへ落ちる。

**P15｜4コマ。** 計測が終わる。凪がピンを離す。亀裂がつながり、金属が元に戻る。作業員「さっきの亀裂、どこ？」。安希「……ない」。凪「だから残すんです、写真でも、数字でも」

## P16–20　別の傷

**P16｜3コマ。** 休憩時間。安希は久住に尋ねる。「ああいう壊れ方、扉でも？」。久住「そりゃ構造によります。扉を壊すカムイ使いは俺だけじゃない」。安希は凪の写真を見直す。

**P17｜4コマ。** 久住が一般向けの修復前後の点検票を示す。「『修復済み』は『安全確認済み』じゃない。だから俺たちがいる」。安希「その考え、榊も好きそう」。久住「榊さんは……現場に首を突っ込む人でした」。

**P18｜3コマ。** 安希「8年前の汀橋でも？」。久住の表情は読めない。「あそこは誰も、好きであんな仕事したんじゃない」。警報音。別の訓練台で作業員が工具を落としただけ。何も起きていない。安希だけが身構える。

**P19｜3コマ。** 凪は床の工具を拾って新人へ返す。「また明日も使うんだから、数えといてね」。安希は凪がここでは頼られる存在だと知る。

**P20｜3コマ。** 倉庫の出口。安希「さっき『時間は同じ』って言ったでしょう。傷が直っても、あの時間に誰が何をしたかは変わらない」。凪「変わってほしいことも、ありますけどね」。二人の間に沈黙。

## P21–25　隠していた理由

**P21｜3コマ。** 倉庫を出て近くの川沿いへ。安希「昨日の夜から、あなたに聞きたかったことがあります」。凪は立ち止まる。

**P22｜4コマ。** 安希が送信メールの印刷を差し出す。「榊の仕事用メールに残っていた」。凪、顔色が変わる。安希「旧施設の面会を決めたのは、あなたですか」。長い無言。

**P23｜3コマ。** 凪「……そうです」。安希「なぜ、昨日は言わなかったんです」。凪「怖かった」。安希「私が怒ると思って？」。凪「あたしが呼ばなきゃ、神谷さんは死ななかったから」

**P24｜4コマ。** 安希「何を見せたかったの」。凪「写真です。八年前の部品の」。安希「どうしてそれを夫に」。凪「見覚えのある穴があったから」。安希「どんな穴？」。凪は目を伏せ、「……次、ちゃんと持ってきます」。

**P25｜3コマ。** 安希「今、言えない？」。凪「自分でも、間違ってるかもしれない」。安希は追いつめかけて踏みとどまる。「分かった。ただ、もう嘘はつかないで」。凪「……安希さんも」

## P26–30　記録の外側

**P26｜4コマ。** 凪「安希さん、昨日から知ってたんですね。なのに、普通に話してた」。安希は言葉に詰まる。凪「先にあたしのこと、見たかったから？」。安希「……そう。あなたを知らないまま決めつけたくなかった」。凪「それって優しさですか？」

**P27｜3コマ。** 安希は否定しない。「分からない。あなたが怖がるなら、聞かない方がいいと思った。……聞くのが私も怖かった」。凪「怖いのは一緒です」。二人は初めて真正面から向き合う。

**P28｜3コマ。** 凪が鞄から透明な書類袋を出す。中に2018年の交換票のコピー。凪「写真を持って来るのは明日。この紙が、どの部品かの証拠です」。安希はその場で読まず、凪の同意を確認して受け取る。

**P29｜4コマ。** 安希、事務所へ戻る。交換票に「修復済み／後日交換」の二つの印。榊の2018年の報告には交換の記載がない。安希「直ったのに、なぜ交換する必要が……」。※ここでは「検査用に取り外した可能性」を否定しない。

**P30｜大ゴマを含む3コマ。** 安希が榊の水鉄砲の映像を思い出す。P02の小さな固定ピン。交換票には「安全栓、固定部貫通」。安希の横顔。「あの人は、何を撃ったの」。**第3話終。**

## 脚本チェック

- 訓練用ビスの亀裂は、久住のカムイが直接生んだ新しい損傷。老朽化ではない。
- 凪の「留め針」は亀裂の**修復**を止め、周りの時間や扉の動きを止めない。
- 久住が現場の安全を大切にする姿を具体的に見せる。ここでは彼を犯人扱いしない。
- 凪が隠していたのは面会を決めたこと。自分が殺害を目撃したとは言わない。
- 安希は相手に秘密を明かさせるために情報を伏せたという弱さを持ち、凪に指摘される。
- 2018年の金具は**既に修復済み**。コピーには修復前に記録された損傷の位置・修復記録と交換の事実が残る。
- 次話では資料の来歴の確認、当夜の施設予約、久住による設備の説明を進める。
