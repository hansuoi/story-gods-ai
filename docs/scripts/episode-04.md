# 第4話「閉じる扉」

**漫画脚本初稿／28ページ想定。** 凪が面会を設定したことを認めた後、安希が旧施設の安全な範囲を調べ、榊の死の現場を「能力で何でも起こせる密室」ではなく具体的な空間として捉え始める回。凪と安希は、調査の対象と証拠の扱いを少しずつ合意する。

## P01–04　話せなかったこと

**P01｜3コマ。** 第3話の翌朝。神谷探偵事務所。安希は凪から渡された交換票の複写と、2026年の死亡現場写真を別々のクリアファイルに収める。ラベルは「2018」「2026」。安希「同じ場所でも、同じ事件じゃない」。

**P02｜4コマ。** 凪が来る。安希「昨日は聞かなかったことを、今日聞きます」。凪、身構える。安希「榊に会うつもりだったのは、どこ」。凪「旧管理室の受付脇。人が入れる場所です」。安希「亡くなったのは？」。凪「その奥の設備廊下」。

**P03｜3コマ。** 安希「どうして場所が変わったの」。凪「前日の案内は受付脇だった。着いたら点検の貼り紙が出てて、奥の扉が開いてた」。安希「貼り紙は今もある？」。凪「もう撤去されてると思う」。

**P04｜4コマ。** 安希「警察には？」。凪「奥の廊下で榊さんが倒れてたことは話した。でも、私が呼び出したことは……」。安希「昨日も言った通り、それは今から話すべきです」。凪「怒られますよね」。安希「怒る理由があると思うなら、なおさら」。

## P05–09　知らせること

**P05｜3コマ。** 安希は警察の連絡先を示す。凪が自分の携帯から担当へ電話する。「追加で話しておきたいことがあります。面会は私が頼みました」。安希は横で聞いているが、話すのは凪。

**P06｜4コマ。** 刑事は凪に来署を求める。凪「警察、もう知ってると思ってた」。安希「思ってただけで、伝えてなかった」。凪は気まずそうに笑う。安希「笑うところじゃない」。凪「分かってます」。

**P07｜3コマ。** 2人で旧管理室へ向かう。安希「中に入る必要はない。あなたが待っていた場所だけでも見たい」。凪「守ってくれたんだと思ってた、あの人が」。安希「それは、まだ変わらないんじゃない」。凪「どうだろ」。

**P08｜4コマ。** 閉鎖施設の外。フェンスの向こうの「立入禁止」。凪は正規の見学手続きを案内する。「今は一般の立入りができない。外からの図面説明なら、現場責任者の許可が要る」。安希「お願いできますか」。凪「久住さんに聞いてみます」。

**P09｜3コマ。** 久住が安全区域へ案内。「ここまで。先は現場検証が終わるまで触れません」。見学通路には現在の点検予定と保管資料の区分が載った一般向け案内掲示がある。安希は撮影できる範囲を確認し、掲示を含む通路の写真を一枚撮る。久住「榊さんのことは残念です」。安希「面識が？」。久住「八年前、一緒の現場にいました」。

## P10–15　図面の端

**P10｜4コマ。** 久住が敷地の古い図面を広げる。正面に受付、奥に設備廊下、廊下の右側に厚い点検扉。建物はL字状。安希は向きを確かめて矢印を書く。凪「そこ、図面と違う。あとで仕切りを増やしたから」。

**P11｜3コマ。** 久住「そのとおり。図面が古い。現状確認用のものは捜査で確認中です」。安希「じゃあ、この図面だけで何が起きたか決められない」。久住「ええ」。※久住が正確な技術説明をする人物だと示す。

**P12｜4コマ。** 安希「扉はどちらへ開きますか」。久住「設備側へ。強い力をかければ急に動くけど、手動でも重い」。安希は自分が押した扉を思い出す。「夫はあそこに立っていた？」。久住「現場に居合わせたわけではないので」。凪は顔を伏せる。

**P13｜3コマ。** 久住「事故なら、不具合のある金具が先に破断してもおかしくない」。安希「でも修復が始まったら、破断前後は見えなくなる」。久住「写真を残した凪の判断は正しかったです」。凪は褒められても笑わない。

**P14｜4コマ。** 久住が別の小型模型を使って、重い扉でも蝶番が1つ傷めば思わぬ向きへ倒れると説明する。凪「久住さん、こういうの教えるのうまい」。安希「あなたは能力で蝶番を動かせるんですか」。久住「できます。だからこそ、点検記録を残す必要があります」。

**P15｜3コマ。** 安希（心の声）「できる人がいる。それだけじゃ、犯人だとは言えない」。安希は展示用模型の蝶番の位置と凪の写真の角度を見比べる。位置が左右逆に見えるが、写真の向きはまだ確認できない。

## P16–20　紙に残った入口

**P16｜3コマ。** 安希「凪さん、面会の案内はまだ持ってる？」。凪「メールなら」。職員用の予約システムから本人に届いた通知を、自分の端末で表示する。安希は凪の了承を得て内容をメモする。

**P17｜4コマ。** 最初の案内は「旧管理室・受付脇」。その後の自動通知は「点検導線に変更／設備廊下側の通行扉へ」。安希「変わってる」。凪「当日現場で変わったと思ってた」。安希「もっと前に通知されてた」。

**P18｜3コマ。** 凪「仕事の通知が多くて、見落としてた」。安希「誰が変更したか、ここには？」。凪「部署の名前だけ」。宛名に「神楽防災設備課」。変更者の名前は表示されない。

**P19｜4コマ。** 久住「点検の導線変更は珍しくないですよ」。安希「事故かもしれない。でも、夫は変更を知ってたのか」。凪「分かんない。あたしは奥へ入ろうとして——」。言葉を止める。安希「急がなくていい。昨日みたいに黙ったままにしないなら」。

**P20｜3コマ。** 凪「奥から大きい音がした。走って行ったら、神谷さんが……」。凪はその先を口に出せない。安希、初めて凪の肩へ手を伸ばし、ためらって戻す。「そこまででいい。今は」。

## P21–24　誰かの仕事

**P21｜4コマ。** 施設の外。久住は別の作業員に呼ばれ、点検票を受け取る。安希「調査に協力してくれて、ありがとうございます」。久住「もう二度と同じことが起きないよう、原因を調べるのが俺の仕事です」。

**P22｜3コマ。** 安希と凪、帰り道。凪「久住さんはあたしが仕事できない頃から教えてくれた」。安希「いい先輩なんですね」。凪「……はい」。その答えに嘘はない。

**P23｜4コマ。** 安希「じゃあ、あなたが見せようとした写真も、久住さんに相談すれば？」。凪が足を止める。「それは……」。安希「何か困る理由がある？」。凪「相談したら、自分の見たものが変わっちゃう気がした」。

**P24｜3コマ。** 安希「見たものは変わらない。説明は変わるかもしれないけど」。凪「安希さん、時々ひどいこと言いますね」。安希「榊もよく言ってました」。初めて二人で少し笑う。

## P25–28　矢印の向き

**P25｜3コマ。** 夜の事務所。安希は許可を得てメモした面会通知、古い図面、凪の写真を並べる。安希「『事故が起きた場所』と『約束した場所』は違っていた」。

**P26｜4コマ。** 古い図面に榊と凪の位置を小さな紙片で置く。設備廊下の角を境に、互いが見えていなかったことが分かる。安希「榊は、変更された入口を知ってたの？」

**P27｜3コマ。** 破損写真を回転させると蝶番の向きが旧図面に合って見える。ただし撮影位置と後付け仕切りが未確定で、事故の再現とは言えない。安希はP09で撮った見学通路の写真を隣に開く。背景に写った一般向け点検予定表の端に「2018年旧補助水門・安全栓／管理番号」が読める。

**P28｜大ゴマを含む3コマ。** 点検予定表に写る番号が凪の2018年交換票と一致する。安希は第4話冒頭の『2018』と『2026』のクリアファイルを再び開き、二つの紙を並べる。「八年前の資料も、ここで点検する予定だった」。現物が面会当時その部屋にあったか、榊が見たかは断定しない。最後は再調査報告「調査対象：神谷榊」。**第4話終。**

## ネーム化前のチェック

- 現場の見学は安全区域・図面説明の範囲に留め、捜査で保全されている現場へ無断で立ち入らない。
- 凪が当夜の面会を設定したことは本人が警察へ追加申告する。安希が犯人探しを独占しない。
- 安希は凪本人のメール通知を**同意を得て**確認する。組織内のアクセス権を無断で使わない。
- 「導線変更」は不審な事情だが、この回では変更者も犯意も確定しない。
- 凪が見たのは倒れた榊と壊れた金具。犯行の瞬間・犯人の顔は見ていない。
- 旧施設の詳細図で、久住の視界8m以内・扉の回転方向・榊と凪の位置を検証する。
- 見学写真は**撮影の許可を得て、一般向け案内掲示を写したもの**。内部システムに無断アクセスしない。
- 旧図面と損傷写真が一致して見えても、撮影方向・後付けの仕切りが未確定な限り、現場の動きを断定しない。
