# 第17話「原状回復」

**漫画脚本初稿／30ページ想定。** 第16話の脱出直後。ここでは異能バトルで犯人を倒したからすべて解決した、とはしない。安希が残せたもの、残せなかったものを具体的に仕分け、公的な調査へ渡す。

## P01–04　水の外

**P01｜3コマ。** 非常出口Eの外。凪が肩で息をし、安希がそばに座る。青い輪郭がまだ金具に残っている。凪「あと……何分」。安希「測ってない」。凪「じゃあ、余計に怖いじゃん」。安希が小さく笑う。

**P02｜4コマ。** 職員が2人を安全区域まで誘導し、救急隊が凪の状態を確かめる。安希は凪の手から勝手に安全ピンを取らない。凪「もう、いい」。自分で留め針を解除する。金具の亀裂が修復される。

**P03｜3コマ。** 到着した警察官が旧施設の立入りを規制。水を止める対応と、資料の保全を並行して指示する。安希は職員が撮っていた水の流れと破損金具の写真の所在を伝える。

**P04｜4コマ。** 久住は奥の管理廊下から出ようとするが、職員と警察官が制止する。久住「事故の確認をしてただけだ」。職員「じゃあ、何で俺たちを外へ出したあと扉が勝手に動いたんだ」。警察官「今は動かず、こちらへ」。久住は抵抗せず、身柄を確保される。

## P05–09　いま起きたこと

**P05｜3コマ。** 警察の聞き取り。凪「久住さんが扉を動かした。あたしを閉じ込めた」。刑事「どこからそう判断した？」。凪「目の前で、あの能力を使うところを見た」。彼女は榊殺害時の推測と混ぜずに答える。

**P06｜4コマ。** 安希「私が見たのは外の扉が動いたことと、凪さんが出てきたこと」。刑事「久住本人が能力を使った瞬間は？」。安希「見えていません」。安希は曖昧な証言を補わない。

**P07｜3コマ。** 神楽の職員が排水ハッチの異常・資料の濡損・作業中の警報を説明。職員撮影の写真と設備記録の写しも保全する。刑事は記録の原本を確認すると伝える。

**P08｜4コマ。** 芹沢が現れ、現場を見て顔色を変える。「移送は中止。資料の状態を全部記録して」。安希「本当に今から？」。芹沢「今だからです」。安希はその言葉に頼もしさと怒りの両方を覚える。

**P09｜3コマ。** 凪が救急車で確認を受けている。安希は側で待つ。凪「私が残したかった金具、もう直った」。安希「写真は、ほかの職員が撮ってた」。凪「全部は写ってない」。安希「そうね。全部は、どこにも残らない」。

## P10–14　失ったもの、残ったもの

**P10｜4コマ。** 旧管理室の浸水した資料。紙の一部は読めなくなったが、箱番号と封印票は残る。水害の写真は別保管の写しもある。神楽は原本の被害状況を記録して、処置可能な資料と損失を区別する。

**P11｜3コマ。** 安希は事務所で証拠の一覧を作る。2018年の写真、交換票、榊の協力費、凪のノート、折原の面談メモ、2026年の面会通知。どれにも「原本／写し」「取得先」「まだ確かめられていないこと」を書く。

**P12｜4コマ。** 凪「写真を残せる能力があるから、何でもできる気がしてた」。安希「私も、書類が揃えば全部分かると思ってた」。凪「どっちも無理でしたね」。安希「……でも、無駄じゃなかった」。

**P13｜3コマ。** 安希は警察へ、榊の仕事用メールを取得した事情を含めて提出する。刑事「独自の調査で分かったことと、警察が裏づけを取ることは分けます」。安希「お願いします」。

**P14｜4コマ。** 警察は久住の業務端末、施設の操作記録、関係者の証言を調べると説明する。2018年の不適切な報告は、行政監査にも引き継がれる。安希「これで全部終わるんですね」とは言わない。

## P15–19　何を裁くか

**P15｜3コマ。** 久住に対する現在の監禁・暴行の疑いと、榊死亡時の殺人について、捜査官が別の事件記録として整理している画面。容疑の段階であり、判決ではない。

**P16｜4コマ。** 芹沢が調査担当者へ説明する。「2018年に病院を守ろうとした判断も、住宅側への連絡の扱いも、記録で検証してほしい」。職員「事業はどうなります？」。芹沢「目の前の人命救助を止めない手続きを先に組む」。

**P17｜3コマ。** 安希「あなたが続けるかどうかは、私が決めることじゃない」。芹沢「それは分かっています」。安希「ただ、証拠を隠す人に任せてはいけない」。芹沢は視線を逸らさず「同意します」。

**P18｜4コマ。** 安希は折原へ連絡する。「水害の追加資料について、調査が進むことになりました」。折原「榊さんの件も？」。安希「はい」。折原「……お疲れさま」。安希「まだです」。

**P19｜3コマ。** 凪は母の写真を手にしている。安希「水に濡れたんじゃないの？」。凪「紙じゃなくて、データで残してた」。安希「それでいい」。凪「紙も好きですけどね」。

## P20–24　欠けた一枚

**P20｜3コマ。** 安希は榊の2026年の未完成原稿を再び開く。第1話で欠けていた一枚は、結局どこにも見つかっていない。安希「探せば必ず出てくる、ってわけじゃないんだ」。

**P21｜4コマ。** 凪「そこに何が書いてあったと思う？」。安希「言い訳かも。謝罪かも。分からない」。凪「どっちだったらよかった？」。安希「……返ってきてくれるなら、どっちでも聞く」。

**P22｜3コマ。** 安希「でも榊は帰ってこない」。凪「……うん」。二人は白いシャツが掛かった椅子を見つめる。凪が初めてそこに座る。

**P23｜4コマ。** 安希は報告の草稿から、欠けた一枚の推測をすべて消す。空欄の代わりに「資料未確認」と記載する。凪「空欄のままにするんですね」。安希「分かってないことを分かったふりしないため」。

**P24｜3コマ。** 安希はその草稿を依頼人へ渡すために印刷する。表紙には「汀橋水害・再調査についての現時点の報告（神谷安希）」。「まだ終わってない」という言葉も付ける。

## P25–30　原状回復

**P25｜3コマ。** 折原の集会室。安希と凪は草稿を持って訪れる。折原「全部分かったの？」。安希「いいえ。でも、何が分からないかは説明できます」。

**P26｜4コマ。** 安希「榊が人を救ったことは事実です。榊が話を隠したことも事実です」。折原「同じ人の話？」。安希「はい」。一度で伝わらない情報を、声を荒らげず伝える。

**P27｜3コマ。** 折原「じゃあ、榊さんはどういう人だったの」。安希は少し考える。「……私にも、全部は分かりません」。折原「それなら、私も同じだね」。二人で笑う。

**P28｜4コマ。** 凪が母の写真を机に置く。「私も、八年前のことを話しました」。折原「よく話したね」。凪「怖かったです」。折原「それでも、残る」。

**P29｜3コマ。** 安希は折原へ、公開できる情報と本人の承諾が必要な情報を分けた報告書を渡す。折原が自分の眼鏡をかけ、最初の行を読む。急に全員が納得する演出にはしない。

**P30｜大ゴマを含む3コマ。** 夕方の事務所。安希は榊の古い案件番号の下に自分の名前を追加する。「引き継ぐ」。まだ空白の次の行がある。**第17話終。**

## 脚本チェック

- 久住を拘束する直接の契機は2026年の新たな襲撃と、その場の複数人の証言・記録。2018年水害や榊殺害の責任は捜査で検証する。
- 「留め針」の解除で破損した金具は修復される。現物が残る設定にはしない。
- 2018年の資料の複写を別に保全していたため、浸水だけで真相が消えない。
- 榊の欠落した1ページは無理に見つけない。未知の部分が残ることを、主人公が引き受ける。
- 依頼人への説明では、原本や凪の証言の公開範囲を本人たちと相談する。
