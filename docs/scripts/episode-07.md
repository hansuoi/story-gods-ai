# 第7話「上流と下流」

**漫画脚本初稿／30ページ想定。** 第6話の「榊は現場にいた」を、助かった側・奪われた側の両方から検証する。話の中心は地形の説明ではなく、安希が「夫を責める言葉」を初めて他人の前で言うこと。

## P01–04　ふたつの高さ

**P01｜3コマ。** 汀橋の河川敷。安希が橋の上、凪が橋の下の階段に立つ。凪「こっちが、昔うちのあった側」。安希は護岸の古い水位線を見上げる。凪「当時は私の頭の上まで来た」。

**P02｜4コマ。** 上流の大きな病院へ続く道。道は盛土で高い。反対の住宅地へは低い坂。安希「水を逃がしたら、こっちへ来る」。凪「知ってたと思う？」。安希「……誰が？」。凪「開けた人」。

**P03｜3コマ。** 凪がスマホの2018年の写真を見せる。雨と水で人の顔が分からない。安希「今見ても、こんなに水があったのか分からない」。凪「撮ってる時は、もっと分かんなかった」。

**P04｜4コマ。** 榊の現場費用記録を開く安希。あの日の時間帯に神楽から支払いがある。安希「仕事としていた。だけど誰が何を決めたかは別」。凪「そればっかり」。安希「そこを混ぜたくないの」。

## P05–10　助かった人

**P05｜3コマ。** 病院の敷地。通院患者のための送迎車。旧写真には今より低い出入り口。現在の看護師・春川苑子(はるかわ そのこ、40代)が迎える。2018年当時も勤務していた。

**P06｜4コマ。** 春川が保管された院内広報誌を見せる。見開きにはベッドを運び出す職員の写真。春川「病院を守ったって記事ばかりで、手伝った人の名前はろくに残ってない」。

**P07｜3コマ。** 回想、薄暗い階段。看護師たちが酸素ボンベと車椅子を運ぶ。榊の姿は見えない。春川（語り）「あの夜、一番怖かったのは水じゃなかった。動かせない患者さんの顔を見ることだった」。

**P08｜4コマ。** 凪「水門が開いて、こっちへ水が来た」。春川はごまかさず答える。「そうね。うちが助かったことと、誰かが亡くなったことはつながってる」。安希、春川の両手に当時の古い傷があることに気づく。カムイ由来ではない。

**P09｜3コマ。** 春川「病院にいた人を責めても、いなくなった人は帰らない。でも責めないで済む話でもない」。凪「自分が助かったのが嫌になること、ないですか」。春川「あります。それでも次の患者を運ぶ」。

**P10｜4コマ。** 安希、質問の順番を変える。「助けが来た時刻を、覚えてますか」。春川「時計は見てない。ただ、院内放送は止まってた。非常灯が点いたあとに、人が走って来た」。安希が取材メモの欄を「本人の記憶／裏付け未確認」と分ける。

## P11–15　川の向こうの暮らし

**P11｜3コマ。** 住宅側へ戻る。復旧された団地の中庭。ベンチには子どもの落書き。凪「向こうは病院って呼ぶ。こっちは、誰も地区の名前で呼ばない」。

**P12｜4コマ。** 折原多江が集会室で写真を壁にかけている。安希「また来ました」。折原「約束どおり、お茶を飲みに来た？」。安希「それと、少し話を聞きに」。折原「先に飲みな。いつも質問からだと、喉が渇く」。

**P13｜3コマ。** 壁には6人の名前と、それぞれが普段していた仕事・趣味が短く書かれる。「数字じゃない」と口で説明せず画面で見せる。凪の母が好きだった鉢植えの写真もある。

**P14｜4コマ。** 折原「事故調査の人は、なぜ水が来たかばかり聞く。どうやって逃げようとしたかは聞かない」。安希「ご家族は？」。折原「避難を呼びかけて、戻ってこなかった」。安希は鉛筆の動きを止める。

**P15｜3コマ。** 凪、母の写真を裏返す。「撮った日のこと、覚えてない」。折原は写真を戻さない。「覚えてないなら、覚えてないでいい」。安希は凪が話せるまで黙る。

## P16–21　警報の空欄

**P16｜4コマ。** 折原が公開された当時の避難情報の一覧を取り出す。「住宅区画への警告は発信したって書いてある」。安希「実際には？」。折原「私の家には来なかった。でも、来なかったってどう証明するの」。

**P17｜3コマ。** 安希は表の脚注を見つける。「発信処理」「受信確認」は別欄。住宅区画の受信確認だけ空欄。凪「送信したけど届かなかった？」。安希「まだ、そこも分からない」。

**P18｜4コマ。** 春川の言葉「院内放送は止まってた」と交差させて、病院も住宅も情報伝達が不完全だった可能性を示す。安希「どこが失敗したかを、失敗した人だけの話にしたくない」。

**P19｜3コマ。** 折原「榊さんも、最初はそう言ってた」。安希が顔を上げる。「夫が？」。折原「こっちの言い分もちゃんと残すって」。

**P20｜4コマ。** 折原が初回面談時のメモを取り出す。手書きの出席者欄に丸印が7個、後日の提出報告書には「証言者6名」。安希「一人減ってる」。折原「途中で帰ったんだと思ってた」。

**P21｜3コマ。** 安希、メモの端に子どもが書いた小さな丸い花の落書きを見つける。凪が無意識にバッグの古い刺繍へ手を伸ばす。安希は気づくが、今は聞かない。

## P22–26　六人という数

**P22｜3コマ。** 安希「亡くなった人が6人。聞き取りの6人は、別の6人」。折原「数字が同じだと、何となく揃って見える」。安希「揃っちゃだめだ」。小さく初めて強い声を出す。

**P23｜4コマ。** 折原「榊さんは良い人だったと思うよ。少なくとも、話を聞きに何度も来た」。安希「それでも報告から消したなら、間違ってる」。声に出した自分に、安希が驚く。

**P24｜3コマ。** 凪は横を向く。安希「凪さん？」。凪「……間違ってるって言ってくれるんだ」。安希「そういう時もある」。凪「……言ってくれて、よかった」。

**P25｜4コマ。** 折原は追加のメモを見せる。「最後の子は、親を亡くしたばかりの中学生になる前の子。名前は出せないと言われた」。安希はメモを複写していいか確認し、折原がうなずく。

**P26｜3コマ。** 安希「誰が、名前を出せないと言ったんです？」。折原「榊さん。子どもの安全のためって」。凪の指が刺繍の端を強く握る。

## P27–30　消えた七人目

**P27｜4コマ。** 安希は折原のメモと提出済みの報告書を照合する。双方の日付と集会室名は一致。提出版だけ証言者の欄が一つ少ない。安希「意図して削ってる」。

**P28｜3コマ。** 凪「今、それを調べてどうするんですか」。安希「誰の声だったのか、聞きたい」。凪「……聞かなくても分かるのに」。安希は凪を見る。

**P29｜3コマ。** 安希は凪へ質問しかけ、止める。「あなたが話したい時に聞く」。凪「逃げてる？」。安希「今は、逃げてるのかもしれない」。凪は小さく笑って、泣きそうになる。

**P30｜大きな最終コマ。** 折原が台帳の余白を指す。「七人目には名前の代わりに『水門で見た子』とあった」。安希の手元には、第5話で凪が示した修復前の写真。写真の小さな穴。台帳の書き込みが重なる。**第7話終。**

## 設定・伏線確認

- 「上流と下流」を単純な善悪の対比にしない。病院の命と住宅地の命はどちらも軽くない。
- 2018年の避難警報は**発信と受信を区別する**。空欄だけで無送信を確定させない。
- 7人目を誰が消したかは、提出報告書と原メモの差で示す。凪本人の同意なしに氏名を公開しない。
- 凪の「花」のモチーフは次話の本人確認と、終盤の個人的な記録に使えるが、超常的な判別能力にはしない。
- 第8話では「七人目＝凪」を本人の言葉で確定し、榊が何を聞き、何を消したのか具体的に見せる。
