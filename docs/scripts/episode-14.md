# 第14話「二つの責任」

**漫画脚本初稿／30ページ想定。** この回で調査の一部を「安希だけが知っている秘密」から公的手続きへ移す。榊が水門を開けたことの是非と、報告書で関与を隠したことを分ける。終盤には、久住が凪へ再び面会を求める。

## P01–04　何を渡すか

**P01｜3コマ。** 朝の事務所。安希は3つの封筒を作る。「遺族説明」「警察への追加情報」「行政監査」。同じ紙を何枚も複写しかけ、手を止める。

**P02｜4コマ。** 遺族向けには水害の経過と情報欠落を説明、個人名は本人の意向を確認してから記載。警察向けには榊の死亡と凪の面会、関連する証拠の取得経緯。監査向けには警報の送信・受信差と契約資料への照会。安希「全部同じことを、一度に渡せばいいわけじゃない」。

**P03｜3コマ。** 榊の名前を記載する欄でペンが止まる。安希「ここは逃げない」。草稿に「神谷榊の関与について未確認の点がある」と書く。断定せず消しもしない。

**P04｜4コマ。** 安希は折原多江に電話する。「この順序で説明してもいいですか」。折原「まずあなたが持ってることを、私は自分の言葉で確かめたい」。安希「分かりました。伺います」。

## P05–09　消すだけなら簡単

**P05｜3コマ。** 折原の集会室。テーブルに最初の遺族向け報告と安希の新しい草稿。折原はまず榊の署名を探す。「あの人が書いたのは、これだね」。

**P06｜4コマ。** 安希「新しい草稿には、榊が当日現場にいた可能性と、凪さんの証言を削除したことを書いています」。折原「凪さんの名前は？」。安希「公開する版にはまだ書きません。本人が決めます」。

**P07｜3コマ。** 折原「名前を伏せるのと、話を消すのは違う」。安希「はい」。折原「言われる前から、分かってた？」。安希「分かっているつもりでした」。二人とも薄く笑う。

**P08｜4コマ。** 折原「この部分は何だい」。安希「開門そのものが避けられたかどうかは、まだ結論を出せません」。折原「じゃあそのまま書きな。分からないことに名前をつけてくれればいい」。安希はメモする。

**P09｜3コマ。** 折原「でも、知らせなかったことまで分からないことにしないで」。安希「調査報告の削除は事実です」。折原「そこなら読める」。安希は初めて依頼者に読んでもらえたことを実感する。

## P10–14　もう一度会う

**P10｜3コマ。** 事務所前に凪が立っている。安希が戻って驚く。「連絡してくれたら」。凪「返事を書こうとして、消した」。安希「私も」。

**P11｜4コマ。** 二人で机に座る。安希「この間は、あなたが話すことまで私が決めそうになった」。凪「……うん」。安希「ごめんなさい」。凪「聞きたいのは謝罪だけじゃない」。

**P12｜3コマ。** 安希は作った3つの封筒を見せる。「本人の証言は本人が出す。私は私が確認した書類を出す」。凪「そこは分けたんですね」。安希「最初からそうすべきだった」。

**P13｜4コマ。** 凪「警察には当時のノートのことを話しました。今の事件の資料と一緒に扱っていいか、確認してもらってる」。安希「自分で行ったんだ」。凪「はい。怖かったけど」。安希はそれを自分の功績のように喜ばない。

**P14｜3コマ。** 安希「私が知らない話があっても、あなたが話さない自由はある」。凪「でも、隠れてたら何も変わらない」。安希「一人で抱えることと、誰にも話さないことは違う」。二人の言葉がようやく嚙み合う。

## P15–19　端末W-04

**P15｜3コマ。** 凪は自分の面会通知の控えを見せる。「変更元の端末はW-04。久住さんが普段使ってる」。安希「本人が操作した証明にはならない」。凪「それも分かってる。でも、だから確かめたい」。

**P16｜4コマ。** 安希「警察には？」。凪「控えの番号を伝えました。個人の操作履歴を確認するのは、向こう」。安希「私たちは久住さんを取り調べられない」。凪「……分かってる」。

**P17｜3コマ。** 凪「でも、直接聞いてもいいと思うんです。怖くても」。安希「何を聞く？」。凪「『あの夜、どこにいた』」。安希「答えてもらった言葉が真実とは限らない」。凪「それでも、聞きたい」。

**P18｜4コマ。** 安希は、かつて榊が危険を一人で引き受けたことを思い出す。「会うなら、明るい場所で。少なくとも自分の予定を人に知らせて」。凪「分かりました」。この忠告は、支配ではなく安全のための相談として描く。

**P19｜3コマ。** 凪「久住さんは、私が14歳の時から仕事を教えてくれた」。安希「それは嘘じゃない」。凪「それでも、疑ってしまう」。安希「……そうね」。

## P20–24　ふたつの報告

**P20｜3コマ。** 行政の受付。安希が資料照会と監査に関する申入れを提出する。職員「内容を確認して回答します」。安希「受け取ったことを記録に残してください」。控えに受付印。

**P21｜4コマ。** 警察には榊の業務メールの写しと入手経緯を説明する。刑事「こちらでも関係者から話を聞いています」。安希「凪さんのことも、本人に直接聞いてください」。刑事「当然そうします」。

**P22｜3コマ。** 安希、事務所を出たあと空を見上げる。榊の「条件を見ようぜ」が記憶に浮かぶ。「条件って、変えられるのね」。自分が同じ言葉を別の使い方で理解し始める。

**P23｜4コマ。** 一方、神楽の事務所。芹沢が古い報告の保存手続きに署名する。久住「その資料、外に出すんですか」。芹沢「照会が来ている。まず原本を保全する」。久住「……そうですか」。

**P24｜3コマ。** 久住の手元。記録庫の点検予定表。翌日に古い紙資料を移送する予定が書かれている。彼は凪の名前のある作業予定へ目を留める。

## P25–30　また会おう

**P25｜3コマ。** 凪が職場を出ようとすると久住から声。「三枝。例の古い資料のことで、一つ聞きたい」。凪「ここで？」。久住「機器番号が絡む。旧施設の保管庫に現物がある」。

**P26｜4コマ。** 久住「明日の移送前に、一緒に点検してほしい。夕方、旧管理室で」。凪「芹沢さんは？」。久住「資料の保全は正式に決まった。中身の照合を先にしたい」。久住は実際の保全手続きに便乗し、もっともらしい説明をする。

**P27｜3コマ。** 凪「設備課の人も来ますか」。久住「俺が対応する」。凪は返事を保留する。「確認してから連絡します」。久住「そうしろ」。普段と変わらぬ態度。

**P28｜4コマ。** 凪は安希へ日時と場所を送る。「久住さんから、古い資料の確認に呼ばれました。どう思います？」。安希「一人では行かないで。まず芹沢さんと警察に確認を」。凪はメッセージを読む。既読。

**P29｜3コマ。** 凪は久住へ「管理者に確認するまでは入れません」と返す。久住のスマホに表示。久住は短く息を吐き、保管庫の操作盤を見つめる。※凪が危険を軽視して単独で突っ込まない。

**P30｜大ゴマを含む3コマ。** 夜の旧排水管理室。誰もいない記録庫で、久住が金属蝶番の可動部を試す。「ぎい」という音。棚には「2018年・補助水門」。久住「明日、来るのか」。扉の影が伸びる。**第14話終。**

## 脚本チェック

- 凪は疑わしい先輩の呼び出しに即応しない。安希へ共有し、管理者と警察の確認を優先する。これが第15話の展開を変える。
- W-04は共用端末であり、久住の能力や犯意を確定する証拠ではない。
- 安希は遺族への説明、捜査への資料提出、監査の照会を分け、それぞれの権限と本人の同意を尊重する。
- 久住は資料保全の手続きが進むことを知って追い詰められる。今後の実力行使には、なぜ逃亡より破棄を選ぶかを具体化する必要がある。
- 第15話では凪が単独で罠に入り込まない展開を組む。狙いは安希・凪が正しく慎重に動いても、久住の行動で危険が生じる構造。
