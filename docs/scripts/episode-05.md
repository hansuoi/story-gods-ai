# 第5話「誰の写真」

**漫画脚本初稿／30ページ想定。** 第1幕の区切り。古い水害の写真に何が写り、誰がなぜ残したのかを調べる。写真1枚で真相を決めず、読者の頭に「榊がいたのでは？」という疑いを置く。

## P01–04　失われた紙

**P01｜3コマ。** 安希と凪、神谷探偵事務所。凪が透明袋からコピーを出す。「これが、言ってた写真」。安希「もっと前に見せてほしかった」。凪「もっと前に見せるの、怖かった」。

**P02｜4コマ。** 2018年の写真。濡れた安全栓の固定金具に小さな穴。写真の隅に日付、時刻、作業票番号。安希は拡大する。「穴が空いてる。でも、これだけじゃ何が通ったか分からない」。凪「分かってる」。

**P03｜3コマ。** 凪「でも八年前、あたしは見たんです。神谷さんが、水の粒を撃つのを」。安希「あなたの言葉と写真が、同じことを示すのね」。凪「そう。だから、違ってたら困る」。

**P04｜4コマ。** 安希「誰が撮った写真？」。凪は交換票の下の小さい欄を指す。「検査担当者が記録したものです。神楽の保管庫の点検フォルダにあった」。安希「修復前に撮った理由は？」。凪「安全検査のため」。安希「なら、記録を作った本人にも聞きたい」。

## P05–09　コピーを信じる前に

**P05｜3コマ。** 安希は3枚の紙を並べる。交換票の部品番号、写真の部品番号、榊の2018年の報告にある施設名。番号は前二者で一致するが、榊の報告には部品番号がない。

**P06｜4コマ。** 安希「写真の加工や取り違えの可能性もある」。凪「じゃあ、あたしが見たのは？」。安希「あなたを嘘つきだと言ってない。確かめないまま言い切れないって言ってる」。凪は唇を噛む。

**P07｜3コマ。** 凪「本人に聞いてきます。保管先も確認できるから」。安希「一緒に行きたい」。凪「職場ですよ。奥さんが来たら騒ぎになる」。安希「じゃあ、誰に何を頼むかだけでも決めよう」。

**P08｜4コマ。** 2人で、神楽に対する書面の質問を作る。①写真の保管元 ②撮影者 ③修復記録 ④榊が関わったかどうか。安希が「分からない」を欄として残す。凪「そんなの、空欄のままじゃないですか」。安希「空欄だから調べられる」。

**P09｜3コマ。** 凪は質問書を持って職場へ。安希は折原多江に電話をかけ、写真を見せることの了解を求める。別々に動く二人を横長のコマで対比する。

## P10–15　人がいた場所

**P10｜4コマ。** 折原の集会室。机には当時の被災地の写真。折原「水門の向こうに病院があったのは知ってる。向こうの人が助かったことも」。安希「それと、亡くなった人がいたことは一緒に書けます」。折原「それを言うのは簡単だよ」。

**P11｜3コマ。** 折原は2018年の報告書の余白に鉛筆で名前を書いたページを見せる。「ここで亡くなった6人」。安希は一人ひとり読む。名前をコマいっぱいに書かず、人が生活していた痕跡の写真を添える。

**P12｜4コマ。** 安希「榊は、ここへ通っていたんですね」。折原「あの人はパンを買って、話を聞いて、いろんな人に頭を下げてた」。安希「何を隠していたかは？」。折原「そこまでは分からない。だから、調べてくれる人がいるといい」。

**P13｜3コマ。** 折原「あなたにはつらい話になる」。安希「それでも聞きたい」。折原「榊さんは嫌いじゃなかった。でも、報告が届いた日から、信じきれなくなった」。安希は報告書を閉じない。

**P14｜4コマ。** 折原の古い写真。小さな花壇の隣、雨のあとでも笑っている家族。安希は黙って見せてもらう。折原「その写真も、神の無干渉で直せると思う？」。安希「……いいえ」。

**P15｜3コマ。** 安希は折原に資料の複写の範囲を確認し、渡してよい部分だけの撮影許可を得る。「また来ます」。折原「次は、お茶を飲みにおいで」。

## P16–21　神楽の保管室

**P16｜3コマ。** 神楽の事務室。凪は正規の手続きで写真の管理者へ確認を申し出る。受付「古い保管物は、管理担当と現場統括の承認が必要」。凪「分かりました」。

**P17｜4コマ。** 芹沢と凪が面談する。芹沢「なぜこれを調べるの」。凪「神谷さんに見せようとしてた写真です」。芹沢「榊さんの死の調査は警察の仕事」。凪「私も、あの場にいました」。

**P18｜3コマ。** 芹沢は言い返さない。「写真の原本と管理履歴を、適切な手続きで保存します。あなたの私的なコピーは、原本の代わりにはなりません」。凪「……はい」。芹沢「それでも持っていたのは、よかった」。

**P19｜4コマ。** 芹沢「ただし、あなたが個人で資料を持ち出し続ければ、仕事を失う可能性がある」。凪「それ、脅しですか」。芹沢「職員に説明するべき規則です」。凪「規則のせいで、八年前の話は消えたんじゃないんですか」。芹沢の表情が曇る。

**P20｜3コマ。** 久住が廊下ですれ違う。「三枝、今夜の点検は外した方がいい。落ち着くまで休め」。凪「心配してくれるんですね」。久住「仕事の先輩だからな」。凪「……分かってます」。不安が残る。

**P21｜4コマ。** 凪が安希へ連絡。「原本の所在は確認してもらえる。でも、私が勝手に持っていていい資料じゃないらしい」。安希「じゃあ、警察にも保管の必要を伝えよう」。凪「本当に、やるんですね」。安希「もう始めてる」。

## P22–26　二つの記録

**P22｜3コマ。** 安希が2018年の現場業務表と、榊の2018年の調査報告を並べる。報告書では榊が翌日に初めて現場へ入ったように読める。しかし現場表には当日の「外部協力者1名」の欄。

**P23｜4コマ。** 安希「同じ人とは限らない」。スマホで調べ、神楽の公開資料に当日の協力事業者が記載されていたことを知る。小さな注記「民間救助協力」。安希「榊も民間で動いていた……」。

**P24｜3コマ。** 榊の古い経費メモを探す。2018年の水害当日のタクシー代が、別の救助活動費として記録されている。日付と場所が一致する。

**P25｜4コマ。** 安希「たまたま同じ地区にいただけかもしれない」。そこへ凪から新しいメッセージ。「写真に写る損傷、榊さんの水鉄砲でできると思います」。安希は第1話の水滴の「ピン」という音を思い出す。

**P26｜3コマ。** 安希が古い経費帳に指を置く。消しゴムで消した下から「汀橋」の字の一部。「あなたは、その日にいた」。証明ではないが、安希の見方が変わる。

## P27–30　写真の外側

**P27｜3コマ。** 凪が仕事帰りに事務所へ寄る。安希は、依頼主の許可を得た折原の報告書と凪の写真を並べる。凪「合わせると、何が分かる？」。安希「少なくとも、あなたの記憶だけの話じゃない」。

**P28｜4コマ。** 凪「じゃあ榊さんは、水門を開けるのを手伝った？」。安希「まだ断定できない」。凪「安希さん、そればっかり」。安希「私の仕事は、そう簡単に終わらせないこと」。

**P29｜3コマ。** 安希が経費帳の1行を見せる。「2018年当日、榊が汀橋に行った記録」。凪の目が潤む。「……やっぱり」。安希「ここから先は、夫に聞けない。私たちで確かめる」。

**P30｜大ゴマを含む3コマ。** 安希が写真の背後にわずかに写る靴先を見つける。凪「そこ、誰かの足ですか」。安希「分からない」。最後の大ゴマは写真の穴と、その近くの人影。安希（モノローグ）「写真を撮った人は、何を見ていたんだろう」。**第5話終。**

## チェックと次話への接続

- 「写真に穴が写っている」だけで榊が撃ったと確定させない。凪の証言・当日の経費・業務表を重ねる。
- 2018年の金具の損傷は修復済み。資料の来歴を確かめることと、現物が破損状態で残ることを区別。
- 神楽が資料の保管を守ること自体を悪事とは扱わない。芹沢の態度は被災者への不十分な説明と両立する。
- 折原には写真の扱いについて同意を得る。氏名・証言の公開には別途判断が必要。
- 30ページは仮の枠。折原の場面はできるだけ台詞を削り、写真と所作で生活の喪失を見せる。
- 第6話では同じ弾痕を作れる能力者が他にもいる可能性を検討し、榊の2018年当日の行動を特定する。
