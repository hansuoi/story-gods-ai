# 第5話「誰の写真」【改稿第2稿】

**漫画脚本／24ページ想定。** 第4話から続く。旧稿の「紙を並べて同じ疑いを何度も確認する」場面を圧縮。凪が勤務先との関係を危険にさらしてでも記録を守ろうとする回にする。

## P01–04：凪の手

**P01／3コマ** 神谷探偵事務所。凪は古い記録写真を安希の机へ置く。金属製の安全栓に、小さく鋭い穴。「これを榊さんに見せたかった」。安希はすぐには手を伸ばさない。「どうして？」

**P02／4コマ** 凪は写真の隅を指す。番号「TB-18-042」、修復前、撮影時刻。安希「穴だけなら、工具でも開く」。凪「でも、あたしは見た。榊さんが水を撃った」。安希「見たのと、この写真が同じ場面かどうかは、まだ別」。

**P03／3コマ** 凪「その言い方、ほんと嫌い」。安希「私も嫌い。でも間違ったら、取り返しがつかない」。二人の間の紙が白く浮かぶ。

**P04／4コマ** 安希「写真の元は？」。凪「神楽の保全フォルダ。交換票もある」。安希「勝手に持ち出せるの？」。凪、目を伏せる。「コピーを個人で保存した。正規の手順じゃなかった」。安希は注意する前に、凪が震えている手に気づく。

## P05–08：間違えた人

**P05／3コマ** 神楽の事務室。凪は写真の保全を正式に申告する書式を受け取る。担当者「個人端末への保存は報告事項です」。凪「……はい。自分で報告します」。

**P06／4コマ** 芹沢が申告書を見る。芹沢「写真を見つけたことと、規則違反は別々に調べます」。凪「仕事、続けられなくなりますか」。芹沢「まだ分かりません」。凪「正直ですね」。芹沢「嘘はつけません」。

**P07／3コマ** 凪「原本は消えませんか」。芹沢「文書保全の申請を受けた以上、保管の記録を残します」。凪「じゃあ、お願いします」。凪は書式へ署名し、手を離す。

**P08／4コマ** 通路で久住に会う。久住「面倒なことを始めたな」。凪「久住さんなら、記録を残せって言うでしょう」。久住は一呼吸置く。「そう教えた」。凪が一瞬ほっとする。しかし久住は「俺にも、見せてくれないか」と続ける。凪「原本は管理者を通してください」。小さな沈黙。

## P09–12：写真に写っていない人

**P09／3コマ** 安希は折原へ会いに行く。折原は水害で亡くなった人が写る日常写真を並べる。安希が安全栓の写真を見せると、折原は首を振る。「それが何か、私には分からない」。

**P10／3コマ** 折原「でも、こっちの写真は分かる」。台所で鉢植えに水をやる人、夏祭りで笑う子。安希「……はい」。安希は証拠写真をすぐしまう。

**P11／4コマ** 折原「榊さん、何度も来て話を聞いてくれた。嫌いじゃなかったよ」。安希「でも報告は……」。折原「書けなかったことがあるなら、いま私が聞きたいのはそこ」。安希「夫は、もう答えられません」。折原「あなたは？」。安希は返答できない。

**P12／3コマ** 安希「私が調べます。ただ、もし夫が何かをしたなら……そのことも」。折原は特に褒めない。「うん」。そして温かいお茶を注ぐ。

## P13–16：どちらの記録

**P13／3コマ** 神楽で凪が写真を記録管理担当に引き継ぐ。原本のファイル番号と撮影者欄を確認し、保全の受領番号を受け取る。凪「これで消せない？」。担当者「手続きの記録は残ります。原本の真偽は、また別の確認です」。

**P14／4コマ** 凪は撮影者欄を見て顔をしかめる。「これ、修復作業の班だ」。担当者「当時の作業台帳が残っているか調べます」。凪「教えてください。勝手に取り出しません」。窓の向こうで、現場作業員たちが次の出動の準備をしている。

**P15／3コマ** 凪から安希に写真の保全受付番号が届く。安希は折原宅の玄関先で画面を見る。折原「持ってる紙が増えた？」。安希「増えたのは、紙の責任を持つ人です」。

**P16／3コマ** 折原が安希へ2018年の依頼報告の複写の利用を許可する。「凪さんのことは、本人に聞いてね」。安希「はい」。依頼者のために作る報告書と、凪の証言は別だと意識し始める。

## P17–20：現場にいた男

**P17／4コマ** 帰宅後、事務所で安希は水害当日の帳簿を開く。単に「汀橋」の移動費ではなく、「緊急救助協力」の入金がある。支払人は神楽。安希「調査依頼を受ける前に……」。

**P18／3コマ** 裏づけに、契約控えの受領欄を開く。水害当日の協力者欄に「神谷榊」。安希の手が止まる。「ここに、いた」。

**P19／3コマ** 凪から電話。「原本は保全してもらえます」。安希「分かった。それと、榊が当日現場にいた記録が出た」。凪「……見たって言ったでしょ」。安希「うん。あなたが見たと言ったことが、少しずつ違う紙からも見えてくる」。

**P20／3コマ** 凪「それで、信じる？」。安希は答えを急ぐ。「凪さんが見たことを、もっと聞きたい」。凪「まだ言わなきゃいけないの？」。電話の両端で沈黙。

## P21–24：穴の向こう

**P21／3コマ** 安希「ごめんなさい。あなたを試してるつもりになってた」。凪「試されるの、嫌い」。安希「私は榊がいないから、あなたの話を聞くしかない」。凪「……そういう言い方も嫌い」。

**P22／4コマ** 凪「あの日、榊さんがあそこにいたのは覚えてる。水を撃ったのも」。安希「ありがとう」。凪「写真は、私の記憶に合わせて選んだかもしれない。それは怖い」。安希「だから原本とほかの記録を確かめる」。凪「……はい」。

**P23／3コマ** 安希が受領書を榊の未完成原稿の隣へ置く。二つの書類に共通する案件番号。白いシャツの袖が視界に入る。安希「救った日を、隠したの？」

**P24／大ゴマ＋2コマ** 水害当日の報告書「開門の経緯：詳細不明」。その横へ、榊の署名入り「緊急救助協力」の控え。安希は指を引く。「あなたは、そこで何をしたの」。**第5話終。**

## 脚本管理

- 安全栓の実物は2018年に修復済み。穴は修復前写真にのみ存在。
- 写真の保全受付番号は撮影内容を認証する万能の証明ではない。改竄・誤認・撮影者の問題は残る。
- 凪による職場の写真保存は不適切だったと認め、正規手続きへ移す。規則違反の扱いは保全とは別。
- 第6話では、**榊が現場にいたこと**から**何を行ったか**へ問いを進める。同じ入金記録をもう一度「発見」しない。
- 第7話に残す役割は、上流と下流それぞれの生活と警告の伝達の問題。
