## 見せ場の検証

- **P02→P03:** 着弾をページの境界へ送り、「小さな水滴が何を変えるのか」を見せる。
- **P04→P05:** 「帰るよ」の笑顔から、2年後の棺へ一気に飛ぶ。この切り替えは第1話の中心的な引き。
- **P16→P17:** 凪をページをめくるまで見せない。
- **P30→P31:** 「依頼者：神谷榊」から「調査対象：神谷榊」へ。文字が読める大きさが必須。
- **P32:** 非通知電話の正体は第2話冒頭で分かる。第1話で犯人からの脅迫と見せかける描写はしない。

## セルフレビューと未解決

- 防火区画扉の説明はフィクションの作画設計。P02～04の金具・レバー・扉の位置はさらに具体的な断面線画にする必要がある。
- P09～16は人物表情が簡略化されており、安希の悲しみから調査へ切り替わる感情がまだ弱い。
- P17～24の凪の青糸はカラーで補えるが、モノクロ化すると見落としやすい。安全ピンの形でも見分けられるよう描き込む。
- P25～26の久住は悪役顔にしない。優しい先輩だったことが後半の裏切りを強める。
- 現時点のSVGはコマを並べて機能を確認するプロトタイプであり、完成した漫画の面白さを保証しない。次の工程は**人物・背景・機械的な動作の線画品質向上**。

## 生成画像の採否

初期の画像生成による複数ページ試作は、2024年の救助を2018年と混同し、少年を少女に変えるなどの重大な不一致があったため採用しなかった。今回の全32ページのSVGラフは、対象ページと描画オブジェクトを明示して作成した別の試作である。
