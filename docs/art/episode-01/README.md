# 第1話P01–P04 作画ラフ v0.1

第1話の2024年の救助を4ページ別々のSVGで作った。目的は完成原稿ではなく、**コマの画面上の情報量、ページめくり、扉と金具の位置**をレビューできる状態にすること。人物は輪郭中心のベクター下描きであり、完成した漫画作画ではない。

| ページ | 画面ラフ | 読者に理解させたいこと |
| --- | --- | --- |
| P01 | [雨の入り口](p01-rough.svg) | 扉の向こうに少年がいる／外側に救助員／榊はまだ顔を見せない |
| P02 | [数滴](p02-rough.svg) | 扉全部を壊すのでなく固定ピンの一点を狙う／水滴は三つ／射撃は次のページへ |
| P03 | [ピン](p03-rough.svg) | 水滴が金具に命中／救助員が扉を開けて少年を救助／榊ひとりの成果にしない |
| P04 | [帰るよ](p04-rough.svg) | 壊した金具だけ直る／扉の位置と雨水は戻らない／妻との電話と榊の笑顔 |

## 絵として確定できた判断

- P01の扉と水位の大きさを見せてから、少年と榊の位置を切り出す。
- P02に狙う固定ピンを大きく描き、P03冒頭で同じ形に命中させる。
- P03の脱出は救助員複数人の仕事。
- P04の最後は表情を大きくして「帰るよ」。P05の棺への対比を最大化する。

## ラフの未達点と次の手直し

1. 榊・少年・救助員の顔と手は、現段階では記号的なベクター描写。造形が決まったわけではない。
2. 2024年の防火扉の構造は、金具が破損したあと扉が開くまでの関係を実在の機械構造に基づき再設計する必要がある。「固定ピンの破壊でなぜ扉が開くか」は今後の重要課題。
3. P01とP03の靴の配置は作画仮置き。水の深さと安全な踏み段の連続性を確認する。
4. P04の「神の無干渉」は、榊が**自分で修復を発動させた**描写を入れる。位置や時間の巻き戻しではない。
5. 生成画像による外部試作は第1話以外の年代・少女・葬儀を混ぜてしまったため不採用。SVGは手作業で描画順と台詞を指定した別試作。
6. ページ内に配置した日本語台詞は校正前。縦組み吹き出しに移す前に、話者・語調・文字数を見直す。
