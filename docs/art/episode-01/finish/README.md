# 完成原稿制作・試作管理

現行の構図ラフ（第1～4話122ページ）から、**清書原稿を制作する別工程**を開始した。

## 最初の仕上げ試作

- [第1話P05「葬儀の扉絵」ベクター試作 v0.1](p05-title-ink-trial.svg)
- SVG画面 1600×2400px相当。白黒に近い低彩度、デジタル単ページ閲覧を暫定想定。
- 完成イメージ：2026年10月、白い棺、葬儀室、安希31歳の顎下までの黒髪・黒い喪服・握りしめた手。**棺の中の榊はP05で見せない**。
- タイトル・日付は画像生成に任せず、編集可能な文字要素として配置。
- 人物の線画はまだ記号化が強く、手指・顔のパースと衣装の皺、棺の花、静けさの演出に再作画が必要。**仕上げ候補であり、完成原稿と認定していない**。

## 採用基準

1. **設定整合性:** 2024年の救助と2026年10月の葬儀を混同しない。P05には少年・救助員・水鉄砲を描かない。
2. **構図:** P04の榊の笑顔から一転した無音の棺を見せる。遺体の顔はP06まで見せない。
3. **識別:** 安希は31歳女性、顎下の黒い髪（片耳をかける）、眼鏡は常用しない。幼く見えたり別人物に見えたりする造形を避ける。
4. **漫画としての読み味:** 説明の見出しがなくても喪失の意味が画面で伝わること。見せ場を文章で補うだけでは合格としない。
5. **制作物:** 解像度・書体・可読性・レイヤー管理を確認し、最終原稿はページ単位で読書チェックを行う。

## 2026-10-13の画像生成試験について

第1話P01およびP05の単ページ画像化を試みたが、どちらも指示したページとは異なる複数ページの救助漫画が生成された。年が2018年になり、救助対象が少女になっていたため、**両方を不採用**とした。これらはリポジトリにコミットしていない。

画像の雰囲気が良くても、設定・事件・ページ・台詞が違えば不採用。今後はより小さな場面単位で生成・作画・合成し、完成版と呼ぶ前に全文字と人物を照合する。
