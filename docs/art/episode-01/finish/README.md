## 採用前に守る条件

- **原稿の因果:** 榊は水滴で保持ピンを切るだけ。救助員がレバーを動かし、扉を開け、少年を救助した後に榊が切断したピンだけを修復する。
- **人物・時系列:** 榊は32歳で死亡する男性で2024年の救助では30歳。少年は少女に変更しない。P05は31歳の安希の喪服、2026年10月、閉じた棺。P06で初めて榊の遺体を見せ、P07では棒付きキャンディーを一切描かない。
- **漫画としての面白さ:** P01の小さな手→P02の狙い→P03で救助→P04の日常→P05の棺→P06～07の無傷の身体と口元→P08で安希が反論。説明を増やして感情の速さを失わない。
- **実画面の確認:** 実際にレンダリングし、人物造形、パース、文字の判読、視線誘導、ページごとの線の品質を確認する。未実施の段階で完成と言わない。

## 不採用にした画像生成

単ページの完成原稿を画像生成で試行したが、複数ページを混同し、2024年の救助を2018年、少年を少女として描いた画像が出た。**両件不採用、リポジトリには未登録**。ベクター試作は別手法で作成した。

## P09～P10の制作と引き算

- **P09：** 暗い玄関に靴の空き場所を残す。喪服姿の安希が「ただ……」と言いかけ、机の付箋「経費、帰ってから」を見つける。分かりきった『一人で帰宅した』というナレーションは清書試作から削除。
- **P10：** 安希が付箋を裏返して書こうとする手、誰も座っていない向かいの椅子、無音の時計を別のコマに配置。説明用の『返事はない』という文字は削除。
- **連続性チェック:** P09で剥がし始めた付箋がP10で手元に移ること、安希の喪服・髪型・姿勢、椅子の向きと位置を本格作画時に照合する。
- **採用前の問題:** 下描きの立体感、特に靴の二足分の距離、安希の口元、指と紙の接触位置は実レンダリングで確認できていない。完成原稿と認定しない。

## P11～P12の仕上げ試作

- [P11](p11-ink-trial-v01.svg)：榊の白いシャツが掛かった空席と、安希が帳簿を開き電卓を使う三コマ。静かな日常の空白から、手が止まる瞬間へ。
- [P12](p12-ink-trial-v01.svg)：予定表の空欄、汀橋方面のタクシー代、領収書、安希の問いを四コマで配置。時刻・金額など未確定の数字は書き込まない。
- **未解決:** 机と椅子の方位を前後ページで統一すること、P12の書類文字が本当に読めるか、四コマが情報過多でないかを実画面で検証すること。完成採用は保留。

## P13～P16：見つける → 伝える → 行く → 止まる

- [P13](p13-ink-trial-v01.svg)：封筒から水害の住所・地図を経由し、最後の大コマに榊の『保留』を置く。4コマに増やし、資料の厚みと不穏さを分離した。
- [P14](p14-ink-trial-v01.svg)：安希は独断で証拠を持ち去るだけでなく、刑事へ電話し写しの提供を約束する。警察にも捜査上の制限を語らせる。
- [P15](p15-ink-trial-v01.svg)：施錠・高架下の歩行・『誰に会うつもりだった』の問い。単なる場面移動にせず、安希の決断として描く。
- [P16](p16-ink-trial-v01.svg)：施設の全景・柵の中の新しい蝶番・安希の制止・姿を見せない声。4コマ。警察の制止に反して捜査区画に触れないよう修正済み。

P13とP16のコマ数は脚本および文字ネームに反映した。**これは編集可能なベクター原稿試作で、完成採用16ページではない。採用0ページを維持する。**

## P17～P20：相手の気持ちを見せる

- [P17・改稿](p17-ink-trial-v02.svg)：P16で声だけを聞かせ、P17冒頭で初めて凪の顔を見せる。『神谷さんの奥さん？』のあとに、ピンを握り込む無言の4コマ目を追加。
- [P18・改稿](p18-ink-trial-v02.svg)：救急への通報と『修復の仕事』という答え。凪が面会を設定したことはまだ安希に言わない。余白は心理的な躊躇として残す。
- [P19・改稿](p19-ink-trial-v02.svg)：現物はすでに修復済みでも写真に残った破損を示す。青い輪郭は現在の金具に残る傷ではなく**撮影時に凪が保持していた傷**。
- [P20](p20-ink-trial-v01.svg)：安全ピンを大きく見せてから、安希の『夫の身体も』という問いに答えない凪を下段に置く。能力が蘇生を可能にするという誤解を与えない。
