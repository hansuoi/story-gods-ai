## 採用前に守る条件

- **原稿の因果:** 榊は水滴で保持ピンを切るだけ。救助員がレバーを動かし、扉を開け、少年を救助した後に榊が切断したピンだけを修復する。
- **人物・時系列:** 榊は32歳で死亡する男性で2024年の救助では30歳。少年は少女に変更しない。P05は31歳の安希の喪服、2026年10月、閉じた棺。P06で初めて榊の遺体を見せ、P07では棒付きキャンディーを一切描かない。
- **漫画としての面白さ:** P01の小さな手→P02の狙い→P03で救助→P04の日常→P05の棺→P06～07の無傷の身体と口元→P08で安希が反論。説明を増やして感情の速さを失わない。
- **実画面の確認:** 実際にレンダリングし、人物造形、パース、文字の判読、視線誘導、ページごとの線の品質を確認する。未実施の段階で完成と言わない。

## 不採用にした画像生成

単ページの完成原稿を画像生成で試行したが、複数ページを混同し、2024年の救助を2018年、少年を少女として描いた画像が出た。**両件不採用、リポジトリには未登録**。ベクター試作は別手法で作成した。

## P09～P10の制作と引き算

- **P09：** 暗い玄関に靴の空き場所を残す。喪服姿の安希が「ただ……」と言いかけ、机の付箋「経費、帰ってから」を見つける。分かりきった『一人で帰宅した』というナレーションは清書試作から削除。
- **P10：** 安希が付箋を裏返して書こうとする手、誰も座っていない向かいの椅子、無音の時計を別のコマに配置。説明用の『返事はない』という文字は削除。
- **連続性チェック:** P09で剥がし始めた付箋がP10で手元に移ること、安希の喪服・髪型・姿勢、椅子の向きと位置を本格作画時に照合する。
- **採用前の問題:** 下描きの立体感、特に靴の二足分の距離、安希の口元、指と紙の接触位置は実レンダリングで確認できていない。完成原稿と認定しない。
