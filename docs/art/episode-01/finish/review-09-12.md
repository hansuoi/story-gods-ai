# 第1話P09～P12　面白さ・連続性レビュー

## ねらい

P05～08の葬儀・警察の説明のあと、P09～10は説明を減らして喪失を残す。P11～12で安希が数字の矛盾に気づき、物語を動かす。

- P09：空いた靴の位置と、榊の「経費、帰ってから」という付箋が主役。『一人で帰った』というナレーションは削除した。
- P10：指・空席・時計で返事のない時間を描き、『返事はない』という説明文字は削除した。
- P11：白いシャツのある事務所を安希が整える。経理担当だった経験に基づき、まず手を動かす。
- P12：空欄の予定、タクシー代、領収書という情報を、数字が曖昧なままでも矛盾が伝わるように配置した。

## 実画面の合格条件

1. P09とP10で安希が同じ人物、玄関の壁・テーブルの位置が矛盾しないこと。
2. P10とP11で『榊が座らなくなった席』の方向がつながること。
3. P12で予定表の空欄が読者にも一目で分かり、説明文字を読まずに交通費と対応させられること。
4. 過度な説明でテンポを殺さないこと。P09～P10は『描かずに見せる』余白を優先する。
5. P09～P12は編集可能なSVG試作であって**完成採用0ページの状態は変わらない**。
