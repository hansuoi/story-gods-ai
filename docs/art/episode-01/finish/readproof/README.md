## 品質と採用の区別

ファイルの存在やSVGのタグ構造は確認できても、画力・パース・コマ運び・文字の判読を保証しない。現在、**仕上げ試作32ページ／読書検証版32ページ／完成採用0ページ**。

**未実施の確認:** 実画面の連続表示、人物の同一性、セリフの縮小判読、入稿用のサイズとフォントの扱い。ここまで済むまで完成原稿とは呼ばない。

次の工程はP05～P08とP17～P20の絵の連続性を重点的に直すこと。説明を戻して補うより、コマの視覚情報を改善する。
