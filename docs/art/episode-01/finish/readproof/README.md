[全32ページを通して読む](reader.md) ／ [元の仕上げ試作](../reader.md) ／ [文字ネーム](../../../../name/episode-01.md)

32ページのSVGを順に配置した、読書テスト用の比較原稿。制作管理の注記と、動作を言い直す説明文を整理した。各ページの元の試作は比較用に保存している。

[SVG検証・PNG出力ツール](../../../../../tools/README.md)も追加した。HTMLやPDFへの完成入稿用出力ではなく、コンタクトシートでコマ運びを確認するためのもの。現時点でレンダリングを実行した結果の合格判定はない。

**P05は手の改稿v0.2、P06は葬儀4コマ案v0.2を比較版に使用した。** 読書検証用の仮選択であり、完成採用ではない。

## 品質と採用の区別

ファイルの存在やSVGのタグ構造は確認できても、画力・パース・コマ運び・文字の判読を保証しない。現在、**仕上げ試作32ページ／読書検証版32ページ／完成採用0ページ**。

**未実施の確認:** 実画面の連続表示、人物の同一性、セリフの縮小判読、入稿用のサイズとフォントの扱い。ここまで済むまで完成原稿とは呼ばない。

次の工程はP05～P08とP17～P20の絵の連続性を重点的に直すこと。説明を戻して補うより、コマの視覚情報を改善する。

## 今回実施した静的チェック

- 連続ビューのSVG参照32件が P01→P32 の順で存在することを確認。
- 32ファイルそれぞれについて、SVG開閉タグの対応、空のtext要素、未エスケープのアンパサンド、注記除去時の余分な閉じ文字を点検。**この範囲のチェックでは異常なし。**
- ただし、これはDOMや画像を実際にレンダリングして目視した結果ではない。視覚上の品質と最終採用判定は未実施。完全なXML妥当性・PNG出力は[検証スクリプト](../../../../../tools/README.md)で別途確認する。

## 2026-10-16・台詞とページ演出の照合

脚本と読書検証版SVGの台詞を全32ページ比較し、以下を修正した。

- P06：修復に関する担当者の言い回しを『修復されているようです』へ統一。
- P14：安希の資料発見と『写しを渡します』の申出を2行で明示。捜査への協力を行動で示す。
- P15：現場に向かう独白を『誰に会ったか、自分で確かめる』に揃え、単なる質問から意思決定へ。
- P31：同じ書類の表題・依頼者を繰り返し表示せず、初めて分かる『調査対象：神谷榊』を強調。
- P32：直前に読んだ書類の表題・依頼者を再表示せず、電話を受ける安希の台詞を中心に。

これらはテキストの照合とSVGの変更であり、作画完成の承認ではない。[PDF・コンタクトシートの自動書き出し](../../../../../.github/workflows/episode01-proof.yml)を別途追加しているが、実行結果・実画面の通読検査はまだ未確認。

## 原稿内の伏線・台詞を自動検査する

[必須の物語上の要素と、明かしてはいけない情報を検査するスクリプト](../../../../../tools/check_episode01_story.py) を追加。第1話の年表、2018年の「保留」、警察への資料提供、凪の能力、久住の信頼、P30からの二段階開示、最後の電話の返答について欠落・情報漏れを検出する。CIの画像書き出し前に実行する。

**この検査を通っても、人物作画の質・台詞の自然さ・読み味は合格したことにならない。**
