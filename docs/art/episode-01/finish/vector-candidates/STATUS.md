# 第1話ベクター作画候補：保存状況と採用範囲

## 検証済みの事実（2026-10-19）

- [32ページ連続閲覧](./READTHROUGH.md)：P01〜P32すべてに、個別のSVGとGitHub Actions生成PNGへのリンクがある。
- [レンダリング検証記録](./render-manifest.json)：PNG 32件。各PNGは1024×1536ピクセルで、バイト数・SHA-256・対応SVG名を記録している。
- コミットを通じてGitHubにSVGとPNG本体を保存でき、SVG変更後にPNGが再生成される仕組みを確認した。
- **本レーンからの最終採用は0ページ。** 上記の32件は「ベクター作画候補の作成・保存」であり、「完成原稿32ページ」ではない。

## 高品質カラー候補との関係

- P05・P06：別途、画像生成による高品質カラーPNGの暫定候補が存在する。ベクター候補は代替完成稿として扱わない。
- P07：画像生成カラーPNGと、独立組版のP07 v01〜v03が別途存在する。ベクター候補は完成採用とは別。
- 高品質なPNGをGitHubへ直接アップロードする経路は未確立。現時点で実証済みなのはSVG→GitHub→PNG再生成の経路。
- ネーム、文字画像、台詞の正確さ、見た目を評価するレビューが必要。画像が32枚存在することは作品としての完成を意味しない。

## 制作上の確認事項

1. [連続閲覧](./READTHROUGH.md)を通しで読み、P04→P05、P16→P17、P30→P31の引きと、コマ順・密度を確認する。
2. コマ内の日本語を実際のレンダリング画像で確認し、文字切れや不自然な重なりを修正する。
3. 榊・安希・凪・久住の顔、服、姿勢と重要な小道具（青糸付き安全ピン、固定ピン、証拠写真）を連続して比較する。
4. P19・P20・P21は同一のPNG証拠写真を埋め込んでいる。写真の表示範囲と明瞭さを確認する。
5. 読書に支障がある箇所を補修し、必要に応じて高品質カラー作画に差し替える。正式採用はページごとの実画像レビュー後とする。
