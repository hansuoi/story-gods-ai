# 第1話全32ページ・台詞整理改稿の検査（2026-10-15）

## 改稿の目的

『読み手がすでに見ているものを、文章で二度説明していないか』を検査。漫画内の文字は①人物の台詞、②効果音、③手掛かりとして読者が必要とする書類、④効果のある内心の声に絞る。画面の制作指示は作品内へ載せない。

## 作業結果

- 32ページのXML風SVG内の文字要素を調査。
- P01～04、P06～08、P14、P16、P21～22、P24～32の**20ページ**に改稿バリエーションを追加し、閲覧ページの参照先を新案へ変更した。
- 旧案は削除せず残す。文字を削った結果、間の取り方や意味が悪化したページがあれば元案へ戻せるようにする。

## 大きい改稿

| ページ | 改稿 |
| --- | --- |
| P01～04 | 『次の瞬間へ』『安全な階段』『みんなの手で』など、絵の機能や制作上の指示に近い文字を削る |
| P06～08 | 『傷がない』『机の向こうから……』など、絵の見た目を言い直す文字を削り、担当者の語尾を脚本に合わせる |
| P14・16 | 『別の捜査も進んでいる』『新しい金具は柵の向こう』を削り、警察への連絡と安希の制止を行動で見せる |
| P21～24 | 封筒を置く・顔を上げないなど演出指示の文章を削る |
| P25～29 | 遠ざかる背中、小さな笑い、空席、封筒の裏という文字を削る。人物の視線と配置が伝わるかが検査対象 |
| P30～32 | P30の表紙文字の反復を削り、P32は『着信音』を効果音に変更。再調査ファイルの文字は主張を弱め、安希の返答を強くする |

## 残る作画の問題

1. **SVG構造検査と描画品質検査は別**。タグの数が正しくても人物の顔、手、目線、遠近、吹き出し位置は不合格かもしれない。
2. P01～04は冒頭救助の視線移動とピンの破損・修復の手順を、実際にページを並べて読ませて確認する。
3. P21～24は文字を削って「沈黙」が伝わるか、表情・指先が不足しないか確認する。
4. P25～26は久住を単純な不審者に見せない。仕事への誠実さを損なう台詞や暗い目元を加えない。
5. P30→31→32で読者が読むべき情報の順序は『依頼者→調査対象→安希の返事』。名前の反復より人物の選択を引きにする。
6. 完成採用0ページ。実レンダリング、実読書、線画清書と印刷・画面サイズの検査が必要。
