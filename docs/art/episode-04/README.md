## 絵にする際に守ること

- P05：凪本人が追加証言を警察へ伝える。安希が代弁しない。
- P09：安全区域で撮影許可を得た一般向け点検掲示は終盤の手掛かり。掲示が読者にも見えている必要がある。
- P10～15：図面の読み取りだけで9ページ使わない。安希の手が動き、凪が古い図面を否定し、久住が機構の説明をする流れへ役割を分散。
- P16～20：通知は凪の端末に届いたもの。受付から設備廊下への事前変更は判明したが、変更者の個人名は分からず、榊が確認したかも不明。
- P21～24：久住は凪にとって誠実な先輩。この時点では悪役らしい演出を付けない。
- P25～28：P01の二つのファイルへ戻る。資料番号の一致は**点検予定の一致**であり、証拠の現物が榊の死亡現場にあったことまでは意味しない。

## 本格作画前の問題

- P09の安全区域、C→Dの視界8m、扉の開く方向は一枚の断面パースに合わせる必要がある。
- P20は凪の証言であり殺害場面の客観的な回想とは区別する。
- P26の紙片は立体的な視界・遮蔽物の証明ではなく仮説図。
- P27は写真背景の掲示文字を単ページでも判読できるように仕上げる必要がある。
