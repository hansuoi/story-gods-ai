## 読み味の中心

- P01～04：安希が凪から話を聞く前に能力を見ようとする。印刷したメールを伏せる手の動きが、のちの対立を準備する。
- P05～15：久住と凪の訓練。傷が残るのは留め針の範囲だけ。撮影・計測のためにほかの職員が必要なことを見せる。
- P16～20：久住は信用できる指導者として描く。現場で頼られる凪を安希が初めて見る。
- P21～27：凪の隠し事と安希の隠し事。二人が自分の言葉で説明し、すぐに和解しない。
- P28～30：修復前の交換票と修復済みの金具を区別し、榊の小さな水滴と2018年の水害をつなぐ。

## セルフレビュー上の課題

1. 訓練場の動線・安全柵・蝶番の回転軸は抽象的な画面ラフに留まる。完成ネームで人と扉の位置関係を決める。
2. 青い糸と亀裂は色がなくても判別できる形・光の輪郭へ再設計する。
3. P22～27は会話が続く。手を出す・紙を受け取らない・一歩止まるなどの動きでリズムを変える。
4. 第1話の救助に使った保持ピンと、2018年の水門の安全栓を同一の物体として描かない。似た「数滴の狙撃」が二つの事件をつなげる。
5. 電子書籍は単ページ表示を前提。紙の見開きへ移す際には配置を再検討する。
