## 面白さと整合性の判定

- **P01～04:** 第1話の非通知電話を直接受け、相手が女性47歳の神楽・芹沢だと判明する。ただしこの場面で芹沢の顔は出さず、事務的な声と安希の反応で読む。報告書の欠けた1枚をP04に置き、話が単なる電話照会で終わらないようにする。
- **P05～08:** 2018年の調査報酬は神楽ではなく住民による個人依頼。折原多江の旧住所は現代の地図上で建物がない。6人が死亡した報告書に取材住民の氏名がないという違和感を示し、安希が訪ねる決断をする。
- **発話の区別:** P01～03の芹沢は電話越しの女性の声。安希の顔と声だけを描いて、芹沢が目の前にいると誤解させない。
- **時系列:** P01～04は第1話の電話直後、P05以降は翌朝。
- **連続性:** 榊の白シャツ、事務所の机と椅子、安希の顔と髪型は第1話P11～12と同一である必要がある。
