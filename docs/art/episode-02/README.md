## 面白さの見せ場

- P01～04: 前話の非通知電話が事務連絡に変わる。それでも芹沢の「先に資料」という価値観は安希と衝突する。
- P09～15: 調査資料から、町の生活、店、遺族の生きた写真へ。報告の空欄を人数の問題で終わらせない。
- P16～20: 作業区画の外から転がった玩具と未固定柵を先に見せ、子どもの危険を偶然だけにしない。
- P21～26: 榊の業務メールを閲覧。返信の「旧管理室の入口で」を読者へ提示するが、差出人の名はまだ伏せる。
- P27～30: 安希が凪へ電話し、凪が否定を避ける。帰宅の提案ではなく「事務所で会う」に決める。
- P31～32: P31で凪の名を確定。P32で同じ名を大写しにせず、榊の空席と安希の反応へ画面を移す。

## 作画と脚本の間の未解決事項

1. P21～23のメール探索からP24～25の安希の選択へ場面の役割を変更した。SVGラフは名刺と電話を主にしているが、指先の迷いは作画時に要改善。
2. P17～19の救助は事前の玩具・安全柵が必要だが、現場作業員の配置と交差する腕の位置に描き込みが要る。
3. 折原の写真は、町を失った人の話と榊への複雑な感情を結びつけるもの。単なる図解資料にしない。
4. 芹沢は47歳女性、凪は20歳女性。設定画・シルエットとの照合を続ける。
5. ページ区切りはデジタルの単ページ閲覧が基準。印刷見開きへのレイアウト変更は別途検証する。
