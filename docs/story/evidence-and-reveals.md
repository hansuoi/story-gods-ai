# 証拠・証言・伏線の管理（第1～12話）

このファイルは制作側のネタバレ資料。**事実／証言／推測／未確認**を区別し、主人公が「作者にしか分からないこと」を知っているように描かないための台帳。

## 作品上の真相（制作側の確定情報）

1. **2018年の汀橋水害:** 芹沢が病院区画を守るために開門を承認。榊は詰まった固定部を水鉄砲で破壊、久住は蝶番へ能力を用いて水門を開く。住宅区画への受信確認を待たずに開門し、避難が間に合わなかった住民6人が死亡した。
2. **2018年の隠蔽:** 榊は、自分が現場にいたことと、12歳の凪が見たという証言を遺族向け報告から削除した。芹沢は送信と受信確認の差を曖昧にした報告を承認した。
3. **2026年の殺人:** 凪が安全栓の修復前写真に疑問を持ち榊を呼び出す。神楽の予約システムから面会情報を知った久住は現場の導線を変えて待ち受け、蝶番の能力で攻撃した。榊は凪を守ろうとして致命傷を負った。
4. **2026年の凪:** 犯人の顔や犯行の全経緯は見ていない。証拠を短時間保全して撮影・通報した。榊を呼び出した事実を最初は隠したが、第4話で警察に追加申告した。
5. **1598年の神谷椿:** 堰を開いて中心部を守り、低地の12人が死亡。椿は死者の名簿を自分で記録。後世の神楽が美化し、犠牲者の存在を公式の語りから省いた。

### 演出上の絶対的な区別

- **「読者が見た」≠「安希が知っている」:** 第9話の過去回想は安希の記憶ではない。
- **「資料に書いてある」≠「その内容が正しい」:** 証言者の書き間違い、通信ログの欠落、記録の編集可能性に留意。
- **「証拠が怪しい」≠「証拠を消してよい」:** 現物・コピー・証言を保全した上で独立検証する。
- **「神楽が社会に必要」≠「過去の隠蔽が免責される」:** 事業の継続と責任追及は両立可能。
- **「久住の端末W-04が使われた」≠「久住本人が操作した」:** 共用端末。ログ、行動履歴、証言を照合する。

## 現時点の構成上のリスク

1. **第5～8話の調査が紙中心になりがち。** ネーム化時は現物の視覚的な差や登場人物の反応を増やし、報告書の文章は短くする。ページ単位の脚本を圧縮する可能性がある。
2. **「安全栓の穴」からの推理が長い。** 読者が第1話の水鉄砲を覚えていることを活かし、推理をくどく解説しない。
3. **第9話の回想で読者が真相を先に知る。** 第10話以降は「誰が犯人か」だけで引っ張らず、安希と凪がどう選ぶかを中心にする。
4. **警察が進んでいないように見える危険。** 安希の私的な調査で得た資料を適切に提出し、警察は別の経路で確認していると描く。
5. **後半の事件舞台が旧施設に集中。** 第13話では資料館と町、14話では行政の記録庫や住民側の場所を使い、風景の反復を避ける。
