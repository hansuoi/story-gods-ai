# 企画・物語の核

## 作品情報

- タイトル: 神谷家 - 神様が直せないもの -
- ジャンル: 異能バトル・捜査サスペンス・群像劇
- 舞台: 魂ヶ丘市
- 主人公: 北内海美
- 主要視点人物: 北内海美・栞・神谷榊
- 想定構成: 全5章の長編

## あらすじ

破壊された物は神の力で修復されるが、死者は蘇らない街。母を殺された少女・北内海美が「修復を止める能力」に目覚め、神谷榊と出会い、街が隠し続けた死亡事件を明らかにしていく。

## 物語の中心となる問い

**壊れたものが元通りになったとき、その原因までなかったことにしてよいのか。**

損傷の修復と、行為に対する責任の解消は異なる。神の無干渉という能力の仕組みを通じて、秘密を守ること・記録を残すこと・人を救うことの衝突を描く。

## 主人公の目的の変化

1. 母を殺した相手を見つける。
2. 母の敵討ちのため、戦う力を身につける。
3. 母の死が隠された理由を調べる。
4. 他の被害者の事件も明らかにする。
5. 私刑ではなく、真実と責任を残す方法を選ぶ。

## 物語の方針

- 戦闘の勝敗と事件の解決を分けて描く。
- 能力の効果・条件・限界を定め、状況に応じて恣意的に変えない。
- 登場人物の目的と手段を区別する。善意による隠蔽も、正当な問題提起を掲げた暴力も、無条件に正当化しない。
- 血統による使命を否定する。神谷家という名前は、血縁だけでなく意思と行動を引き受ける人々を指す。
- 神谷榊・北内海美・神谷椿を中心に置きつつ、原作の展開や結末に拘束されない。

## 結末

神谷椿の復活と都市規模の惨事を経て、海美たちは「すべての修復を止める」のではなく「救助と証拠の保全を両立させる」方法を選ぶ。椿の計画を阻止し、隠蔽を公表する。榊は過去の秘匿について責任を問われ、海美は鈴宮を殺さずに罪を明らかにする。数年後、海美と栞は神谷探偵事務所を引き継ぐ。
