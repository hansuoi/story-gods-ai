# 作品の構想

## 基本情報

- タイトル: 神谷家 - 原状回復 -
- ジャンル: 異能バトル・捜査サスペンス・家族劇
- 舞台: 魂ヶ丘市(架空の多摩地域の都市)
- 時代: 2026年を基準とする現代
- 主人公: 神谷安希(31歳、非カムイ使い)
- 重要人物: 三枝凪、神谷榊、芹沢慧、久住真琴、神谷椿
- 構成: 序章・前半・中盤・後半・最終部

## 出発点

夫・神谷榊が死亡した。カムイ能力によって負った傷は「神の無干渉」で修復されたが、死者は生き返らない。

安希は夫の死の真相を調べる。榊が持っていた古い依頼書には、8年前の「汀橋水害」に関する記録が残っていた。水害の責任について、榊は当時の調査結果の一部を隠していた。

榊の死を目撃した三枝凪は、証拠を残せる特殊な能力を持つ。彼女は水害の生存者でもあり、真相の一部を安希に隠している。

## 作品の中心になる問い

**失われたものが戻らないと知りながら、残された人は何を引き受けるのか。**

- 修復された物体と、取り返せない生命。
- 人を守ろうとした判断と、その判断が傷つけた人々。
- 家族を愛することと、家族の過ちを認めること。
- 過去を「なかったこと」にする記録と、過去の責任を引き受ける記録。

## 主人公の行動と変化

1. 榊を殺した人物を突き止めるため、事務所の会計資料・依頼記録・顧客との連絡を調べる。
2. 修復工事を行う神楽と、現場を目撃した凪に接触する。
3. 榊が8年前に証言を隠していたことを知る。夫を擁護するため、その事実を公表しない選択を考える。
4. 同じ災害で家族を亡くした人々の記録を読み、榊が守った人と見捨てた人の両方に向き合う。
5. 自分自身にも不利益が及ぶと理解したうえで、記録を公表し、夫の死と水害の責任を明らかにする。

## 主人公が自分で解決すること

安希はカムイ能力を持たない。代わりに、事務所の経理と依頼受付を担当してきた経験を使い、支払い記録・見積書・備品履歴・契約変更の食い違いから情報を集める。凪の能力で残した痕跡を、独立した事実と照合する。

戦闘の決着を凪に委ねても、事件をどこまで公表するか、榊について何を認めるかを決めるのは安希。

## 結末

榊の死は口封じのための殺人だったと判明する。安希と凪は関係者の記録を揃え、捜査・監査につなげる。神楽の修復事業は停止ではなく、責任の明確化と監督体制の変更を迫られる。

安希は榊が隠した証言を公開する。榊が人を救った事実と、被害者から真相を奪った事実を、どちらも残す。

神谷家は失った家族を元に戻さない。戻らないものとともに生き続ける。
