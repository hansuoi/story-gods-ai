# 中心となる事件の因果関係

## 事件A: 2018年・汀橋水害

### 発生状況

豪雨により魂ヶ丘市の汀橋地区で浸水の危険が生じた。神楽は市から緊急時のカムイ防災対応を受託していた。

現場責任者・芹沢慧は病院側の浸水を防ぐため、旧水門を開けて排水経路を切り替えることを承認した。技術員・久住真琴は「蝶番」で水門の錠前の金具を破損させ、通常の開閉手順を省略した。

病院側の浸水は回避されたが、住宅地側への警告が遅れ、住民6人が死亡。現場に残った金具のカムイ由来の損傷は後に修復され、水門への強制介入が物証から分かりにくくなった。ただし雨水による自然な浸水被害、当時の証言と一部の通信・支払い記録は残った。

### 報告と隠蔽

報告書には豪雨と排水能力不足を主要原因として記載。水門の意図的操作と住宅地側への警告遅延を十分に説明しなかった。

当時の神谷榊は24歳で、被害者の依頼による民間調査に従事していた。12歳の三枝凪から、手動ではなかった水門操作に関する証言を得た。しかし脅迫を恐れ、凪の同意を得ずに証言を報告書から削除した。これは凪を守ろうとする行為だったが、遺族の補償・責任追及を妨げた。

### 責任の構造

- **芹沢:** 非常時の水門操作の判断と、報告書で経緯を十分に開示しなかった責任。
- **久住:** カムイによる操作の実行と、その記録を隠した責任。
- **行政:** 警告・避難伝達の制度と、契約業務の監督の責任。
- **榊:** 民間調査の証言を隠し、依頼者に不完全な調査結果を渡した責任。

水門を開けた判断そのものが違法・不合理だったと、初めから結論づけない。状況と代替策を検証する。

## 事件B: 2026年・神谷榊殺害

### 発生状況

榊は8年前の資料を調べ直し、旧汀橋排水管理室へ久住を訪ねる。久住は、榊が水害の操作記録を公開しようとしていると知り、カムイで扉を強制的に動かして攻撃する。

榊は頭部に致命傷を負い、死亡する。久住が神の無干渉を発動させたことで、直接の損傷が修復される。ただし生命は戻らない。

### 目撃者と手掛かり

凪は榊の死亡直後に現場に到着し、蝶番の破損箇所が修復される前に「留め針」で一部を短時間固定して写真を撮る。凪には犯行の全経緯は見えておらず、写真だけでは殺人を立証できない。

榊の支払い記録、施設の入退場履歴、久住の勤務・作業記録、当日の通話、凪の写真を突き合わせて矛盾を絞り込む。能力による痕跡の修復があっても、これらの記録が自動的に消えることはない。

### 動機

久住は、8年前の操作と隠蔽が公になると、当時の責任を問われ、修復事業にも悪影響が出ると考えていた。口封じは久住自身の選択であり、芹沢から殺害の指示は受けていない。

## 事件C: 1598年・神鵠村の堰切り

神谷椿は洪水時、堰を開いて村の中心部への水を逃がし、中心部の住民を救った。しかし低地の集落では12人が死亡した。

椿は自らの判断に責任を感じたが、死後に成立した神楽の記録では「誰も犠牲にしなかった奇跡」に置き換えられた。

2018年の災害は、1598年と似た構造を持つ。しかし現代の人物が歴史をなぞるために災害を引き起こしたわけではない。「多数を救うために少数が被害を受けた」という結果を、誰がどのように記録するかが共通する。

## 証拠の役割

| 情報 | 分かること | その情報だけでは分からないこと |
| --- | --- | --- |
| 凪が撮影した蝶番の損傷 | 修復直前に異常な破損があった | 誰が何の目的で破損させたか |
| 榊の会計・交通記録 | 榊が調査を再開し現場へ行った経緯 | 殺人の実行者 |
| 施設の入退場・勤務記録 | 久住が現場にいた可能性 | 犯罪の動機・行為の詳細 |
| 過去の住民証言 | 水門操作に関する当時の目撃情報 | 判断の合理性・全責任 |
| 神楽と行政の文書 | 操作の承認、警告の手順、報告の経緯 | 個々の人物の主観 |
| 現代の複数証言 | 事件前後の状況の照合 | 単独では犯行の確定 |

最終部では、証拠を提出しただけで自動的に有罪が確定する描写にはしない。捜査・裁判・行政監査は別の過程。
