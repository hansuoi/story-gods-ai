# 連載構成：第1部（全18話の設計）

**対象:** 『神谷家 - 原状回復 -』。全18話をひとまず第1部の完成単位とする。想定は第1話32ページ、以後24～32ページ程度。ページ数は面白い場面の密度に応じて変える。

## 読者との約束

- 榊の死の真相は序盤の主な謎。中盤のより大きな謎は「榊自身が8年前に何をしたか」。
- 毎話、人物の能動的な選択・発見・関係の変化のうち最低2つを起こす。謎を伏せるだけの引きは使わない。
- 榊の過去は「よい証言」と「悪い証言」の交互提示ではなく、ある選択の前後関係が具体化することで見え方を変える。
- 神の無干渉、留め針、蝶番はルールを偽らない。「実は何でもできる能力」を犯人当ての答えにしない。
- 日常の楽しさ（夫婦の冗談、凪の仕事仲間としての居場所、誰かに実際に救われた経験）を先に描き、失われることに痛みを生む。
- 警察や行政を無能化しない。安希は独自の資料と人脈を持っているから捜査に並走できる。

## 第1幕の連続性

1話の非通知電話は**芹沢**。神楽の代表番号から番号非通知でかかる。榊の死亡を知り、神楽との過去の業務に関する未返却資料の有無を確認する事務連絡である。脅迫や万能な情報提供ではない。2話の前半で判明する。

凪は榊に直接「8年前の写真を見せたい」と伝えた。榊の面会予定を決めたが、安希にはそれを知られたくない。神楽の予約システムには凪の職員IDが記録されており、神楽の利用規則に従った開示がなければ安希には直接は見られない。

第2～3話で安希が凪の面会を疑うのは、事務所の業務メールの送受信記録・凪の反応・榊が用意した古い封筒という手掛かりの積み重ねによる。神楽内部の記録をハッキングして知る展開にはしない。

## 立証と演出の制約

- 2018年の金具の損傷は修復済み。写真に弾痕があっても現物に穴は残らない。
- 第3話の「留め針」実演は**新たに生じたカムイ由来の破損**を対象にする。単なる老朽化を修復できる能力にしない。
- 久住の回転操作は常に1箇所の蝶番のみ。既に運動している扉の慣性まで止まるわけではない。
- 榊は能力が強いから傷がつかなかったのではなく、攻撃に対処する余裕と退路の有無に依存する。
- 現代の殺人犯の確定は複数証拠と捜査の積み重ねで行う。未確定の凶器写真1枚から断定しない。

## 漫画の制作順序

1. 全18話の物語上の役割と真相を先に管理する。
2. まず第1～6話の脚本初稿を制作し、冒頭から中盤への推進力と能力表現を検証する。
3. 説明過多や退屈な回を発見した場合は、この連載構成を改変する。話数は拘束条件ではない。
4. 漫画ネーム・画面化は場面の位置関係とページの引きが成立してから進める。
