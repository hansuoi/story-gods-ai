# 汀橋の事件：空間・時刻・証拠の設計

**用途:** 第4話以降のネーム／アクション設計時に、人物の位置、見えるもの、能力の制限を一貫させる。以下は脚本初稿に対応する暫定仕様。設備の実在性を確認したうえで改変できる。

## 2026年の旧排水管理室

### 位置関係

場所はL字状の通路がある旧設備棟。道路からの入口は南。入口の受付脇から北へ歩くと曲がり角があり、東へ折れると点検扉Dと制御室Cがある。

- **受付A:** 本来の面会予定地点。外部からの立入りを受け付ける場所。
- **曲がり角B:** Aから奥へ6m。ここからDが見えるが、Cの中は見えない。
- **点検扉D:** Bから東へ約4m。金属蝶番で東側の設備室へ開く厚い扉。能力により急回転させられるが、蝶番の1箇所だけが作用点となる。
- **制御室C:** Dの奥の北側。点検窓からDの蝶番まで6mで視界が通る。Bからは窓の奥の人影が見えにくい。
- **非常出口E:** 設備室から南側の別の通路へ抜ける出口。常時施錠されておらず、久住が移動するときに使用できる。

簡略図（上下左右は相対位置。縮尺ではない）。

```text
        北
        ↑
   ┌────────┐      ┌────────┐
   │制御室 C│ 窓   │設備室   │
   │久住    ├────→ D 点検扉  │
   └────────┘      │         │
                    └──── E ─┘
           ↑
A 受付 ── B 曲がり角 ── 榊・凪の接近方向
```

扉Dは能力の操作対象。扉の回転半径内に人が立つと衝突する。壁や扉の位置を読者が把握できるよう、攻撃前に同じ角度の引きのコマを配置する。

## 2026年の事件：暫定時系列

| 前日 | 凪が神楽の予約システムを通じ、榊との面会場所を受付Aに設定 | 凪、榊、予約管理者 |
| 同日 | 予約通知が「受付A→設備廊下」に変更される。変更権限は神楽の設備管理者にある | 通知を受けた凪、管理者。榊が閲覧したかは未確定 |
| 当日18:40前 | 久住が予約記録を見て榊を待ち受ける | 久住 |
| 18:40頃 | 榊が奥の設備廊下へ進み、久住に遭遇する | 榊、久住 |
| 18:41頃 | 凪が曲がり角Bへ近づく。榊が凪の接近に気づく | 榊、凪（一部） |
| 直後 | 久住が制御室の点検窓からDの蝶番1つを操作。榊は凪の進路を塞ぐ扉の動きを防ごうとして身体を入れる | 榊、久住。凪は攻撃者を見ない |
| 数秒後 | 榊は扉の直撃で頭部に致命傷。久住は修復を発動させようとする | 久住、凪は直後に到着 |
| その前 | 凪が金具の損傷に「留め針」を接触させ、破損の修復を部分的に止める | 凪 |
| 数十秒後 | それ以外の対象は修復される。凪は写真を撮影し、救急へ通報 | 凪。電話受付にも記録 |
| 10分以内 | 凪が保持を解除。金具の破損も修復。警察が到着する前に現物の損傷は消える | 凪 |
| 事件後 | 久住は現場作業者として振る舞い、凪や他者に面会変更への関与を明かさない | 久住 |

時刻の細部は、救急通報時刻・現場到着・修復の発動を矛盾なく描けるようネーム前に確定する。上表は「能力の発動順」の基準として扱う。

### 榊が退かなかった理由

凪がDの回転範囲へ向かうのが見えた。榊は自分が回避すれば凪が危険になると判断し、扉の近くで進路を塞いだ。水鉄砲は方向と射線が重要で、角の先に凪がいる状況では射撃の自由が制限される。

この選択が榊の死の原因になったが、「だから榊が正しかった」とはしない。2018年の独断と同じ性格が、2026年には別の結果を生んだ。

### 凪が見た範囲

凪はBからDへ向かった際、榊が倒れた直後の状況と、破損した蝶番の一部を見る。制御室Cにいる久住の顔も、発動そのものも見えていない。

久住の身元は施設の管理担当として後から分かるが、**現場に居た可能性と、能力を行使した証明は別**。凪の写真だけで犯人が決まることはない。

## 2018年の補助水門

2018年の水門は、扉Dと同一の設備ではない。旧補助水門には固定用の安全栓と回転する開閉部があった。

1. 芹沢が緊急開放を承認する。
2. 固定部が動かず、榊が水鉄砲で安全栓の固定部を撃ち抜く。
3. 久住が蝶番に力を加えて開門する。
4. 水が流れ、病院側の浸水が減る。住宅地では警告の遅れもあり6人が死亡。
5. 開門後、榊は直接破損させた金具に修復を発動させる。設備が過去の閉門位置に巻き戻ることはない。
6. 修復済みの安全栓は後日、安全点検のため取り外され交換される。修復前の記録写真と交換票が残る。

現物の安全栓を見ても2018年の穴はない。後世の人物が得られるのは写真・部品番号・作業票・証言。写真にある穴だけで射手を特定することはできない。

## 最終部の設備上の条件

- 久住は同時に1箇所の蝶番にしか能力をかけられない。
- 凪が壊れた蝶番を留めても、扉の回転そのものを停止させることはできない。
- 金具が壊れたことで扉が傾き、狭い脱出用の隙間ができる。修復が進むと扉が元の強度を取り戻して、隙間を通れなくなる。**扉の位置が時間逆行するわけではない**。変形した金具・扉枠の形が戻ることで隙間が狭まる。
- そのとき凪は別の損傷1箇所の修復を留めており、どちらを保持するか選ぶ必要がある。
- 安希の選択と凪の能力が決着を生むが、久住の責任を認定するのはその後の捜査・裁判による。

## ネーム化前に検証すること

- DとCの視界距離が8m以内で、凪の視点から久住の顔が見えない構造を描けるか。
- Dの回転軸1つを操作した場合の扉の動き・破損が矛盾しないか。
- 凪が損傷へピンを当てる時間が、久住の修復より先になるか。
- 安希の第4話の見学が、警察による保全区域に立ち入らず成立するか。
- 最終部の破損による隙間が、修復だけで狭まる理由を読者が図で理解できるか。

以上のいずれかが成立しないなら、位置関係または能力の制限を改訂してからネームを制作する。
