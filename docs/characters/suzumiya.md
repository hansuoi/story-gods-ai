# 鈴宮耕平

- 年齢: 34歳
- 立場: 毒慄の指導者
- カムイ能力: アンリ・カール
- 媒体: 植物の葉

## 人物像

カリスマ性と人心掌握力を持つ。国家による能力者の秘匿、対外的な立場、教育制度などを問題視している。ただし目的のためならテロ・殺人・脅迫を容認する。

## 能力

葉に吸水性能を付与し、接触対象の水分を奪う。人体を短時間でミイラ状態にできる。身体能力と心理戦にも優れる。

## 物語での役割

道下真百合の死亡に関与した人物。海美の無効化能力を国家への攻撃に利用しようとする。神楽とは敵対するが、海美たちの味方にはならない。

## 結末

海美に殺害されず、逮捕と責任追及を受ける。思想への反論と、実行した犯罪行為への責任を分けて描く。
