# 神谷榊

- 32歳で死亡。安希の夫、神谷探偵事務所の元所長。
- 能力: キャサディ・キャサディ(水を操る)。
- 物語開始時点では故人。読者は現在の証言と過去の行動から榊を知っていく。

## 魅力

もとは弱かった能力に厳しい制限を課して強力な技へ育てた。戦闘のときも、考え事をするときも、軽い冗談を言う。困った人を放っておけず、相手が助かる方法を考えるのが速い。

白シャツ、袖まくり、キャンディーをくわえた姿。攻撃は大量の水ではなく数滴の水鉄砲。どこから水を用意したか、相手が気づく前に決着がつく。

## 欠点

自分なら相手を守れると信じ、相手に相談せずに判断してしまう。

2018年には災害対応へ自ら参加し、水門の安全栓を撃ち抜いた。病院を救うために動いたが、住宅地の6人が死亡した。

その後遺族から調査を頼まれると、自分の関与を説明せず、当時12歳の凪の証言も勝手に隠した。表向きは凪を報復から守るため。しかし自分が責任を問われるのを恐れてもいた。

## 2026年の死

再調査のため、凪との面会に応じた旧施設で襲われる。榊は久住の「蝶番」に応戦するが、扉の向こうに現れた凪を守るため退路を失い、致命傷を負う。

強い使い手が死ぬ理由を、相手の強さだけにはしない。過去の「誰かを自分だけで守ろうとする」性格が最後の行動にも現れる。

## 安希との関係

家では飄々として、事務所の経費の扱いは大雑把。安希に怒られて笑う。だが、仕事では誰にも言わずに危険を引き受ける癖があった。

安希は彼を愛し続けながら、榊の過去の嘘を追う。

## 口調の方向

「できないって決める前に、できる条件を考えてみようぜ」
「ごめんな。これだけは、お前にも相談できなかった」

後者をただの美しい遺言にせず、安希がその考え方自体に反発する余地を残す。
