# 神谷榊

- 年齢: 26歳
- 立場: 神谷探偵事務所所長
- カムイ能力: キャサディ・キャサディ
- 関係: 神谷安希(妻)・神谷詞野介(息子)・我修院光・梶原猛・河内広則
- 過去の関係: 道下真百合

## 人物像

観察力と戦闘技術に優れた探偵。人を守ることに強いこだわりを持つ一方、保護のために他人へ情報を知らせないことを正当化してきた。

幼少期から神楽に命を狙われ、道下に守られてきた。道下が死亡した事件の現場におり、海美が真相を追うほど自分の過去にも向き合うことになる。

## 能力

水を操作する。もともと弱い能力に厳しい制限を設け、少量の水による高威力の水鉄砲を成立させている。水源の配置・制限の運用・相手の心理を利用して戦う。

## 葛藤と結末

海美を守りたいが、過去の秘匿を知られれば信頼を失うと理解している。椿との戦いには生き残るが、自分が隠してきた情報を公開し、法的責任を問われる。
