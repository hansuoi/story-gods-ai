# 神谷榊

## 基本情報

- 年齢: 32歳で死亡
- 性別: 男性
- 立場: 神谷探偵事務所の元所長、安希の夫
- カムイ能力: キャサディ・キャサディ(水の操作)
- 物語での役割: 行動・記録・他者の証言から生前の姿が再構成される故人

## 欲求と欠点

目の前の人間を守りたい。自分の判断力に自信があり、難しい事態では他人の意思を確認する前に最善だと思う行動を選んでしまう。

2018年、凪の身を守るためと考えて、彼女の証言を同意なく調査報告から削除した。後にその判断が遺族から情報を奪ったことを理解し、再調査を始める。

人助けをした記録は多いが、完全な英雄ではない。

## 能力: キャサディ・キャサディ

水を操る。もとは水害対策に使われてきた弱い能力。榊は水鉄砲という限定した技を定義し、発射後に水を再操作しない制限を課して威力を高めた。

制限を利用した戦術は、榊の発想と工夫を示す重要な要素として原作から残す。

## 他者との関係

- **安希:** 妻。多くのことを共有していたが、仕事で隠した判断については十分に話さなかった。
- **凪:** 2018年の証言者。守ろうとして声を奪ってしまった相手。
- **芹沢:** 災害対応の記録をめぐる過去の関係者。
- **久住:** 榊が再調査した相手。最後には口封じのため殺された。

## 外見・画面設計

- 体格: しなやかな長身。過剰に筋肉質にはしない。
- 髪: 長めの黒髪を無造作に流す。
- 服: 袖をまくった白いシャツ、動きやすい暗色のパンツと靴。
- 小物: 棒付きキャンディー、持ち歩く薄いメモ帳。
- 仕草: 状況を読み切るとキャンディーを噛み砕く。考えるときは指先を小さく動かす。
- 演出: 生前の回想と他人の証言では同じ表情が違って見えるように描く。

## 結末

物語開始時点で死亡している。最後に安希が夫の過ちも残すことで、榊の人生が「英雄か悪人か」の二択ではなかったことを示す。
