## 設計方針

名前・性格・能力・外見は、原作と一致させるためには決めない。各人物は、欲しいもの、恐れるもの、能力と行動の制約、他人との関係、場面での具体的な行動から設計する。

容姿は完成画ではなく文章によるデザイン仕様。色・形・姿勢・小物によって、モノクロ漫画でも区別できるシルエットを考える。
