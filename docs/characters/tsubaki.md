# 神谷椿

- 生年: 16世紀後半
- 立場: 神楽が崇拝する人物
- 状態: 長期の眠りを経て現代に復活する
- カムイ能力: 物体の質量に関わる操作能力(原作の「トップ・オブ・ザ・ワールド」を基に再設計)

## 人物像

卓越した能力を持つが、自分の過ちを認めない。かつて大量の殺人を犯し、カムイ能力で修復された街を利用して、犠牲を正当化した。

## 思想

人間が死んでも秩序が維持されれば正しいと考える。「修復されたのだから何も失われていない」という論理を人々に受け入れさせようとする。

## 物語での役割

神楽の教義の源流。復活後、神楽の資金・人員と帰天環を利用して魂ヶ丘市を支配しようとする。

## 結末

榊たちに計画を阻止され、戦闘不能となる。ただし本人を倒しても、数百年続いた思想や組織の問題は終わらない。
