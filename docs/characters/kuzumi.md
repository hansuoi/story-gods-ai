# 久住真琴 (くずみ まこと)

- 38歳。神楽の防災設備技術員。
- 能力: 蝶番(ちょうつがい)。
- 2018年の補助水門操作に従事し、2026年には榊を殺害する。

## 表の顔

設備の構造に詳しく、修復作業員から頼られている。凪が被災後に神楽の仕事へ入った際、道具と安全管理を教えた先輩。口数は少ないが、機械の説明では親切になる。

凪からは「久住さん」と呼ばれ、困ったときに最初に相談される存在。

## 隠しているもの

2018年の緊急開門では、多くの人を救った一方、住宅地で6人が死亡した。判断は芹沢の承認を受けていたが、設備の記録と警告の遅延について久住自身も黙ってきた。

榊と凪が旧施設で面会すると知り、過去が明るみに出ることを恐れて待ち伏せる。事故ではなく、口封じを意図して能力を使う。

## 欠点

自分は人命を守る技術者だと思っている。あの時助けた人々を根拠に、犠牲になった人々の話を避ける。凪を気にかけてきたのは事実で、それでも現在の凪を危険にさらす。

彼をただの利己的な犯人にはしない。仕事と人間関係を守りたかった人物が、決定的な一線を越える。

## 能力

8m以内の金属製蝶番1つを操作し、扉や開閉設備を動かす。金具の耐久性以上に力を加えると破損し、"心"を大きく消費する。複数の蝶番を同時操作できない。

## 外見

大柄で前傾、太い前腕。短い黒髪、作業着と安全靴。指先で小さな蝶番を回す癖。疲れているときほど工具を丁寧に並べる。

## 物語での見せ方

序盤に親切な場面を用意し、後半の疑惑を単なる犯人当てにしない。凪が彼を信じたいほど、安希が事実を追及する行動が2人の衝突を生む。
