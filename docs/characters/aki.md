# 神谷安希

- 31歳。神谷探偵事務所の経理・依頼窓口、榊の妻。
- カムイ能力: なし。
- 主人公。何が起きたかを自分で確かめるため、夫の仕事の関係者を訪ね歩く。

## 性格

日常ではユーモアがあり、言葉は簡潔。事務所の無茶な経費申請に文句を言いながら、依頼者の名前と事情はよく覚えている。

緊張すると作業を増やして考える時間をなくす。相手が何かを隠していると気づくと、聞かずに帰れない。人に助けを求めるのが苦手で、調査途中で凪を危険に巻き込む。

**欠点:** 夫を守りたい気持ちから、一度は榊の過去の関与を公表しない選択をしようとする。榊の隠蔽を批判する資格が自分にあるのか、問われる。

## 主体的な行動

- 榊の移動と依頼記録の不一致を発見し、死亡現場へ出向く。
- 凪の連絡履歴を自分で探し、嘘を問い詰める。
- 昔の依頼人と直接会い、榊の報告とは異なる話を聞く。
- 榊が水門操作に関与した可能性を知り、凪に調査の中止を提案して対立する。
- 最終局面で凪の安全を選び、証拠保全を他の手段に切り替える。
- 遺族へ榊の報告原稿を提供する。

## 外見

中背、顎下の黒髪を片耳へかける。長い上着、大きなショルダーバッグ、傷んだ紙の手帳。身の回りの物を整える癖と、調査に熱中すると髪がほどける変化を描く。葬儀の黒服が、事件を追うにつれて普段着へ戻っていく。

## 台詞の方向

「数字が合わないとき、大抵は誰かが説明を省いてる」
「私が好きだった人の話を、私が聞く。いい話だけじゃなくて」

## 結末

榊が救った人も、隠された被害者も、同じ台帳に記す。夫を否定するためではなく、その人生をひとつの評判に縮めないため。
