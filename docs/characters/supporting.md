# 脇役・周辺人物

主要人物が抱える問題を別の角度から見せるために登場する人物。物語のために証言を都合よく変える道具にはしない。

## 折原多江 (おりはら たえ)

- 年齢: 70歳前後。
- 立場: 2018年汀橋水害の遺族、神谷榊へ調査を依頼した人物。
- 登場: 第2、5、7、11、14、17、18話。
- 核心: 榊が聞いてくれたことと、報告書が不完全だったことの両方を認める。
- 自分の目的: 死者を数字で扱わず、当時の避難と開門の経緯を説明してもらいたい。
- 性格: 言葉を急いで言い切らない。若い人へ無理に結論を要求しないが、「分からない」と「調べない」を混同することには厳しい。
- 外見: 小柄、短く整えた銀髪、鮮やかな柄のスカーフ。集会室では丸い眼鏡を掛け、いつも写真を一枚ずつ並べている。
- 行動の特徴: 安希へ茶を勧め、相手が急いでいるほど席に座らせる。対立する場合も声を荒らげず、証言の抜けを指さす。
- 注意: 「遺族全員の代表」ではない。他の被災者は違う意見を持ってよい。

## 春川苑子 (はるかわ そのこ)

- 年齢: 40代。
- 立場: 魂ヶ丘市の病院で勤務する看護師、2018年の水害当時も勤務。
- 登場: 第6、7話。
- 核心: 病院の患者を助けられたことと、下流側で人が亡くなったことを同時に抱える。
- 自分の目的: あの夜の事実を知ると同時に、目の前の患者の安全を守り続けたい。
- 性格: 現場では判断が速く、日常では冗談も言う。自分が見ていない住宅地の状況について、もっともらしい断言をしない。
- 外見: 髪をひっつめた中背の女性。仕事の現場では救急関連のポーチと古い腕時計。手の甲に作業由来の小さな傷がある。
- 行動の特徴: 患者の目線まで屈んで話す。話しながら無意識に病院の出口を確認する。
- 注意: 病院の側が「善」、住宅の側が「悪」といった対比にしない。単に知り得たものが違う。

## 長瀬初音 (ながせ はつね)

- 年齢: 34歳。
- 立場: 地域資料館の学芸員。
- 登場: 第13、18話。
- 核心: 神谷椿の伝説を否定したいのではなく、史料が何を支持し、何を支持しないか説明したい。
- 自分の目的: 資料の来歴と解釈を公開し、次の世代が再検証できるようにする。
- 性格: 説明は丁寧だが、分からないことを分かると言わない。伝承を信じる住民へも、頭ごなしに誤りだと断言しない。
- 外見: 明るい茶色のボブヘア、細い眼鏡、小さな襟のシャツと作業用カーディガン。ポケットに白い薄手の手袋を持つ。
- 行動の特徴: 史料を示す前に日付と保管経路を確かめる。椿の神像に近づくときも観察する対象として扱う。
- 注意: 「四百年前の真相を知る万能解説者」にしない。史料からの推定と確定を分ける。

## 2024年の救助に登場する少年

第1話に登場する、地下歩道の浸水で救助された少年。名前と生い立ちは未確定。榊が能力を人命救助に使える人物だったことを見せるために登場する。最終部で榊を美化するための証言者として都合よく再登場させない。

## 設定追加の条件

- 新人物の役割が既存人物の役割と重複しないこと。
- 証言をする場合、その人物が何を見て、何を伝聞で知ったか分けること。
- 退場や再登場は「読者に説明する必要があるから」だけでは決めない。
