# 北内海美

- 年齢: 16歳
- 立場: 魂ヶ丘学園の生徒
- カムイ能力: ローリング・スター
- 媒体: 母の形見のロザリオ
- 関係: 栞(幼なじみ)・神谷榊(師匠)・道下真百合(母)・鈴宮耕平(母の死に関わる人物)

## 人物像

正義感が強く、納得できない結論を押しつけられることを嫌う。行動力はあるが、復讐心によって他人の被害を軽視しやすい。

## 能力

他のカムイ能力による物理的な働きを無効化する。AI版では神の無干渉による修復を局所的に止められ、現物の証拠を残すことができる。負傷者への使用には大きな危険がある。

## 目的と変化

- 初期: 母の死を調べ、鈴宮を殺す。
- 中盤: 自分以外の被害者についても、事件と責任を明らかにしようとする。
- 終盤: 鈴宮を殺さず、証拠を残して責任を問う方法を選ぶ。

## 課題

敵を殺すことだけが母を忘れない方法だと思っている。栞の調査や榊の過去を知ることで、復讐と記録の保全を区別できるようになる。
