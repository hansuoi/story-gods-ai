# カムイ能力

## カムイと"心"

カムイは物体・自然現象などに宿る神。カムイ使いは自身の生命エネルギーである"心"を与えることで能力を借りる。"心"は体内でも使われており、酷使すれば疲弊し、使い果たせば死亡する。

能力を発動できる条件と使い手の工夫は戦闘・作業に影響する。自ら厳しい制限を課すことで、限定した効果を強められる場合がある。

## 神の無干渉: 修復の規則

### 対象

- カムイ能力が**直接**生じさせた、物体または肉体の物理的損傷。
- その能力に由来する損傷でも、能力との直接の因果関係が切れている二次被害は自動的に修復されない。
- 雨水による自然な浸水被害、通常の老化、病気、一般的な機械故障まで無条件に修復するわけではない。

### 発動

- 能力の使い手が意識的に修復を発動できる。
- 使い手が気絶・死亡したときにも、残る修復対象に対して発動する。
- 修復によって対象の物理的損傷が回復するが、能力で一時的に動かした設備が、過去の位置へ必ず巻き戻るわけではない。

### 限界

- **修復によって死者は蘇らない。**
- 修復しても、他人の記憶や行動履歴は巻き戻らない。
- 証言、映像、記録済みの情報、直接のカムイ損傷ではない痕跡は原則として残る。
- 同一損傷の修復を同時に複数の使い手が自由に制御できるわけではない。
- 修復は治療の代用品として万能ではない。カムイの直接損傷ではない症状には作用しない。

### 捜査上の帰結

カムイ能力による殺人では、遺体に致命傷が残らない場合がある。ただし修復現象が起きるだけで殺人の事実が完全に隠せるわけではない。検案、死亡までの時間、目撃・通信・利用施設の記録を併用する必要がある。

## 個別能力

### キャサディ・キャサディ / 神谷榊

- 系統: 水を操作する一般系操作型
- 特徴: もともとは水害から小さな集落を守るための弱い能力。
- 制限: 攻撃を少量の水による「水鉄砲」に限る。発射後の水の操作権を放棄する。
- 強み: 厳しい制限による高威力、技術と地形の活用。
- 弱み: 水源と発射条件を制限される。万能な水操作には戻せない。

原作の能力をあえて残す。弱いものを工夫で使う榊の性格と、洪水をめぐる事件に接点があるため。

### 留め針 (とめばり) / 三枝凪

- 系統: 特定系付与型
- 媒体: 祖母から受け継いだ、青い糸を結んだ安全ピン
- 発動: カムイ由来の損傷が修復される前に、ピンを損傷箇所に接触させ、"心"を流す。
- 効果: **1箇所の連続した損傷**に限って、「神の無干渉」による修復の進行を一時停止する。
- 範囲: 直径15cmを上限とする。
- 時間: 最大10分。長く留めるほど"心"の消費が増える。
- 同時対象: 1箇所。新たな対象へ移すと先の対象の停止が解除される。
- 解除: 任意の解除・経過時間・使用者の気絶で修復が再開する。
- 限界: すでに終わった修復を巻き戻せない。カムイ由来でない損傷を留められない。生命を復活させない。

使い手本人が傷のすぐ近くに行く必要があるため、危険な現場での使用には代償がある。写真や採取物の信頼性を無条件に保証する能力ではない。

### 蝶番 (ちょうつがい) / 久住真琴

- 系統: 金属製の蝶番を媒体とする一般系操作型
- 媒体: 使用者の視界内・8m以内にある金属製の蝶番
- 効果: 蝶番の軸へ回転力を加える。扉、水門、シャッターなどの開閉機構を強引に動かせる。
- 制限: 同時操作は1つの蝶番のみ。回転軸以外の直線移動には使えない。蝶番のない構造物は操作できない。
- 特徴: 閉じた扉を勢いよく動かせるが、金具が損傷するほどの使用は"心"を大きく消費する。
- 限界: 本体の重量や蝶番の耐久性は消えず、大きな構造物の操作には負荷が生じる。

2018年は水門の固定金具を壊して緊急操作した。2026年には同じ能力で榊を殺した。能力の種類ではなく使用者の判断が責任を生む。

### 継ぎ目 (つぎめ) / 神谷椿

- 系統: 構造物の接合部へ干渉する特定系操作型
- 媒体: 椿が携帯していた古い鉄製の楔
- 効果: 施工された木材・石材の継ぎ目を一定範囲で緩め、堰・柵などの構造を分離できる。
- 制限: 加工された継ぎ目以外には作用しない。自然の岩盤や水流そのものは操作できない。
- 役割: 1598年の堰切りで使用した能力。
- 状態: 本人は死亡している。現代で能力を発動しない。

神楽の後世の記録では、実際には水路の構造を壊したにすぎない能力が「水を鎮める奇跡」として語られている。

## 濁神と神器

濁神は、生命そのものを代償として発動し、死後も持続し得る特殊な能力の状態。AI版の初期構想では主軸にしない。

神器は、使い手を限定せず能力を発動できる例外的なカムイを宿した物体。現時点では、都市規模の新規神器「帰天環」は**採用しない**。

## 未確定項目

- 映像に能力の発動自体が映るか、物体の変形だけが映るか。
- 補助的なカムイ使いを追加する場合の能力の種類と制限。
