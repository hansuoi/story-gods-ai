# カムイ能力

## 基本原理

### カムイ

物体・自然現象などに宿る神。通常は眠っており、人間が生命エネルギーである"心"を与えると能力を貸す。

### "心"

生命活動を支えるエネルギー。能力の発動、身体能力の強化などに用いる。使用すると疲労し、使い果たせば死ぬ。時間の経過で回復するが、無制限ではない。

### カムイ能力

通常、使い手1人につき1能力。能力の実用上の強さは、能力の特性・使い手の"心"・使用制限・戦術・環境に左右される。

## 能力の分類

| 分類軸 | 区分 | 意味 |
| --- | --- | --- |
| 宿る対象 | 一般系 | 同種の複数の物体などに宿る |
| 宿る対象 | 特定系 | 固有の対象に宿る |
| 宿る対象 | 概念系 | 物理的な対象を必要としない |
| 働き方 | 操作型 | 対象や現象を操作する |
| 働き方 | 媒体型 | 媒体を使い別のものを生成する |
| 働き方 | 付与型 | 対象に性質を付与する |
| 働き方 | 摂取型 | 何かを取り込むことで発動する |

原作の分類を基本として引き継ぐ。例外が生じた場合は能力の仕様を先に明確にし、無理に分類へ合わせない。

## 制限による強化

能力の使用条件を厳しくすることで、限られた条件下での効果を高められる場合がある。制限は実際の行動を拘束する必要があり、万能の強化手段ではない。

### キャサディ・キャサディ

神谷榊の水を操作する能力。もともとは小さな集落を水害から守るための弱い能力。

榊は攻撃手段を一度に数滴の水を使う「水鉄砲」に限定し、一度発射した水の操作権を放棄する制限を課した。これにより高い威力を実現する。水の配置と条件の抜け道を使う戦術を得意とする。

## 神の無干渉

カムイ能力で破壊・損傷した物体や肉体を修復する現象。使い手の意志で発動でき、使い手の気絶・死亡で自動的に発動する場合もある。

**修復しても生命は戻らない。** 肉体の傷が修復された遺体でも、死んだ人間は死んだままである。

能力の終了と修復は別の現象。証言・映像・非カムイ由来の損傷まで一律に消去するものではない。

## ローリング・スター

- **使用者**: 北内海美
- **媒体**: 母から受け継いだロザリオ
- **効果**: 他のカムイ能力による物理的な作用を無効化する。AI版では、神の無干渉の修復作用も局所的に阻止できる。

### 制限と危険

- 効果はロザリオと海美の"心"が作用する局所的な対象に限る。
- 完了済みの修復を巻き戻せない。
- 無効化中は"心"を消費する。
- 修復を止められた負傷者は、カムイの修復では助からない危険がある。
- 死者を生き返らせたり、記憶を書き換えたりはできない。

この能力を使い、普通なら修復される損傷を証拠として残せる。証拠保全と人命救助の対立が物語の中心になる。

## 濁神

"心"ではなく生命そのものを代償として発動するカムイ能力。使用者の死亡後も持続する場合があり、通常の神の無干渉が働かない。成功例は極めて少ない。

## 神器

誰の"心"にも反応し得る例外的なカムイを宿した物体。能力者が自分の能力以外の力を行使する手段ともなる。

### 帰天環 [AI版新規]

神楽が完成させようとする都市規模の神器。複数の使い手から"心"を集め、カムイ由来の破損に対して「神の無干渉」を同時に発動させる。

- 生き返らせる能力はない。
- 使用者に大きな負担がかかり、強制的な供給は死亡につながる。
- 修復対象はカムイ由来の損傷に限る。
- 停止条件・最大効果範囲・必要な"心"の量は未確定。

## 今後確定する値

- ローリング・スターの作用距離・持続時間・最大同時対象数。
- 修復を阻止された損傷が後から再び修復できるか。
- 帰天環の発動に必要な人数と"心"の量。
- 修復後の遺体から医学的に特定できる死因。
