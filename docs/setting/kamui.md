# カムイ能力

## 基本

カムイは物体・自然現象などに宿る神で、使い手の生命エネルギー「心」によって能力を貸す。過度の使用は生命に関わる。

能力ごとに媒体・範囲・効果・制約がある。厳しい制約を課すことで限定された能力が強まる場合がある。分類は原作の一般系・特定系・概念系、操作型・媒体型・付与型・摂取型を参考にするが、物語に必要な理解を優先する。

## 神の無干渉

### 修復対象

カムイ能力によって**直接**発生した物理損傷。能力で動かした扉が人を傷つけるなど、能力と接触が直接つながる損傷も対象となる。

カムイで開けた水門を通った雨水による浸水は、能力から離れた二次被害であり自動的な修復対象ではない。

### 修復の発動

能力者本人の意思で修復できる。本人の気絶・死亡では原則として残っている損傷への修復が起きる。

物体の損傷は修復されるが、物の位置や機械の操作履歴、書類・記憶・映像が過去へ巻き戻るわけではない。

### 生命の扱い

修復されても、**死亡した人は蘇らない**。修復中に救命の余地がある場合でも、医療処置が不要になるわけではない。

## 主要能力

### キャサディ・キャサディ / 神谷榊

- 媒体: 水
- 効果: 水を操作する
- 制限: 戦闘では「水鉄砲」と呼ぶ数滴の水を高速で撃つ攻撃に限定。発射後の水を再操作しない。
- 長所: 発射条件を工夫した高度な狙撃・牽制。
- 弱点: 狭い場所、人質のいる状況、攻撃が届く方向の制約。

原作の制限による強化を意図的に採用。2018年には水門の安全栓を撃ち抜いたことが、後に榊自身の過去を示す手掛かりとなる。

### 留め針 (とめばり) / 三枝凪

- 媒体: 青い糸を結んだ古い安全ピン
- 分類: 特定系付与型
- 効果: カムイ由来の損傷が修復される**前に**、損傷箇所に安全ピンを接触させ、修復の進行を一時停止する。
- 同時保持: 連続した損傷1箇所のみ。
- 範囲: 直径15cm以内。
- 最大持続: 10分。"心"の消費は経過時間とともに増加。
- 解除: 本人の意思、時間切れ、本人の気絶。解除後は通常の修復が再開する。
- 限界: 完了した修復を巻き戻せない。損傷していない物を固定できない。扉や人間の動きそのものは止められない。

**面白さのための使い方:** 事件の証拠を残したい場面と、壊れた扉をあえて壊れたままにして誰かを脱出させたい場面が重なる。どちらか一方しか選べない。

### 蝶番 (ちょうつがい) / 久住真琴

- 媒体: 視界内8m以内の金属製蝶番。
- 分類: 一般系操作型
- 効果: 1つの蝶番の回転軸に力を加え、扉・可動式の水門・開閉機構を動かす。
- 同時保持: 1つ。回転軸のない設備を動かせない。
- 制限: 機構の耐久性や物の重さを無視できない。過負荷で破損すると"心"の消費が増加し、修復が必要になる。
- 戦い方: 施設の扉や安全柵を利用して動線を操作する。攻撃そのものより、次の通路を塞ぐために使用する。

2018年は開門のため、2026年は殺害のために使用した。同じ能力を使う人物でも、使用する目的と責任は異なる。

### 継ぎ目 (つぎめ) / 神谷椿

- 媒体: 古い鉄楔
- 効果: 人工的な構造物の接合部を緩め、堰などを開く。
- 限界: 水や岩盤そのものを操作できない。
- 状態: 1602年に使い手が死亡。現代では発動しない。

## 濁神・神器

原作の設定を参照するが、中心事件には登場させない。都市規模の神器「帰天環」は不採用。

## 描写上の注意

- 榊の死の現場で凪が見つけた金具は、久住が能力で過負荷にしたためカムイ由来の損傷と判定できる。
- 凪の能力が守れるのは破損部分の修復停止であり、生命の復活ではない。
- 「壊れた状態が脱出に役立つ」場面では、扉の構造を描いて読者に理由が分かるようにする。
- 証拠の写真が撮れたことと、裁判で真実が証明されたことは同一視しない。
