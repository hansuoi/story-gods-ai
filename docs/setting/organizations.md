# 組織

## 神谷探偵事務所

榊が運営していた小規模な探偵事務所。安希は依頼受付・請求・顧客管理を担当していた。事務所には8年前の不完全な調査報告が残っている。

安希は夫の死亡をきっかけに、業務記録へアクセスし始める。依頼者との接触や資料の入手は、彼女自身の調査行動によるものとする。

## 神楽

椿を救済者として語る宗教的共同体に由来する法人。現代ではカムイを利用した防災・修復・避難支援事業も担う。

- **芹沢慧:** 現場統括責任者。2018年の判断と報告の責任を負う。
- **久住真琴:** 水門・扉等の設備技術員。凪の仕事の先輩。
- **三枝凪:** 修復補助の作業員。2018年の被災者でもある。

神楽は本当に人命を救っている。住民の生活と仕事を守りたい人々がおり、組織に不正があったからといって一律に悪と描かない。

芹沢は過去の説明不足を隠したい。一方、久住は現在の生活を守るため、榊の殺害という一線を越える。

## 行政・警察

魂ヶ丘市は一部の防災業務を神楽へ委託している。緊急時に何が決まり、誰が何を実施したかの監督責任は行政にもある。

警察は榊の死亡について、修復後の遺体・施設記録・証言から通常の捜査を進めている。能力が存在する社会でも、証拠の評価が自動的に決まるわけではない。

## 地域資料館と遺族

神鵠村の古い名簿、汀橋水害の写真・通報記録、凪の証言などをそれぞれ異なる経路で保管している。安希が関係者を直接訪ねることで、組織の公式報告とは別の情報が集まる。
