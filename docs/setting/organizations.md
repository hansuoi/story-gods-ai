# 組織と関係者

## 神谷探偵事務所

神谷榊が所長だった小規模な探偵事務所。安希は経理・受付・依頼記録の管理を担ってきた。榊の死後は、安希が資料の整理と未完了の依頼の対応を始める。

少数の協力者はいるが、原作の事務所構成を一律には引き継がない。長編に必要な人物だけを追加する。

## 神楽

カムイ信仰に由来する組織。現代では防災・能力を使った修復・避難支援の事業も行う。

- 現場責任者: 芹沢慧
- 技術者: 久住真琴
- 活動: 災害対応、設備修復、行政からの委託事業
- 強み: 実績、専門技術、地域住民の信頼、継続運用の体制
- 問題: 事故記録の不十分な開示、業務と責任の混同、過去の隠蔽

神楽を単なる悪の宗教組織として扱わない。現場職員の多くは実際に人を救うために働く。

## 行政・警察

魂ヶ丘市は災害対応の一部を神楽へ委託している。契約、緊急対応、記録保存、監査の責任がある。

警察は榊の死亡について捜査し、行政の担当部署は2018年の業務を検証する。権限の異なる活動であり、資料の提出だけで捜査と監査が完了するわけではない。

原作の公安マイナス1課は、この作品には登場させない。

## 地域資料館・被災者団体

神鵠村の歴史資料や、2018年の水害に関する記録を保全する。

安希が真相へたどり着くためには、神楽の内部資料だけではなく、別の経路で保存された資料も必要となる。
