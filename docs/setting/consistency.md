# 設定間の整合性

## 確定した制約

1. 神の無干渉は物理的損傷を修復できるが、死者を復活させない。
2. 修復は犯罪行為そのものを無効にしない。現物以外の証拠は個別に確認する。
3. ローリング・スターは局所的な修復阻止に使えるが、完了した修復は巻き戻せない。
4. 証言・映像・現物はどれも単独で真実を保証しない。独立した情報源を照合する。
5. 帰天環は多数の使用者の"心"を必要とし、無限のエネルギーを持たない。
6. 能力に制限を課しても、事前に定義した条件を無視して新しい効果を発動できない。
7. 首謀者を倒しても、制度的な問題や被害者の損失は残る。
8. 榊は最終章で死亡しない。成人後の海美と栞が事務所を引き継ぐまでには時間が経過する。

## 未確定事項

| 項目 | 決める必要があること | 必要な時期 |
| --- | --- | --- |
| 第1章の事件 | 加害者・被害者・能力・死因・修復契機 | 第1話の脚本作成前 |
| 修復の痕跡 | 血液・衣服・映像・電子記録への作用 | 第1章のネーム作成前 |
| ローリング・スター | 距離・同時対象数・持続時間・後からの再修復 | 第1章の戦闘脚本作成前 |
| 榊の過去 | 隠した事実・理由・被害者への損害 | 第2章の脚本作成前 |
| 母の事件 | 鈴宮の行為・榊の関与・当時の証拠 | 第2章の脚本作成前 |
| 帰天環 | 発動条件・燃料・停止条件・制御者 | 第3章の脚本作成前 |
| 椿 | 封印の仕組み・能力の限界・復活条件 | 第4章の脚本作成前 |
| 公表・逮捕 | 情報の検証・被害者保護・証拠能力・拘束手段 | 第5章の脚本作成前 |

## 変更方針

設定変更は自由に行える。ただし新事実・能力の例外を追加するときは、既存の条件と矛盾しないことを確かめる。矛盾がある場合は、新旧のどちらかの設定を明示的に改変する。
