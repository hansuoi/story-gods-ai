# 設定・整合性

## 決定事項

1. 舞台の現代は2026年。榊32歳で死亡、安希31歳、凪20歳、久住38歳、芹沢47歳。
2. カムイはある程度社会に認知されている。秘密なのは2018年の水門操作の全経緯と、一部の行為への責任。
3. 神の無干渉はカムイ能力が直接与えた物理損傷を修復する。死亡した人は蘇生しない。
4. 「留め針」は直径15cm以内の損傷を1箇所のみ最大10分、修復前に留める。事後の巻き戻しや物体の固定能力ではない。
5. 「蝶番」は視界内8m以内の金属製蝶番を1つだけ回転操作する。金具・構造物の負荷や損傷はそのまま発生する。
6. 2018年の旧補助水門操作では芹沢が判断し、榊が水鉄砲で安全栓を壊し、久住が蝶番を動かした。
7. 住宅区画で6人が死亡した。雨水による溺死と家屋被害は、カムイの直接損傷ではなく自動的に修復されない。
8. 2018年の榊は遺族からの調査依頼を受けた後、自分の関与を明かさず、凪の証言を本人に相談せず隠した。
9. 凪は2026年に榊を施設へ呼んだ。設備の予約履歴を久住に見られたことに気づかなかった。
10. 2026年の榊殺害は久住自身の判断。芹沢が殺害を指示したわけではない。
11. 凪が死亡現場で見たのは榊が倒れた直後と破損した金具。凪は久住の顔も襲撃の全過程も目撃していない。
12. 久住の攻撃時、榊は凪の逃げ道を守るため退避できず、致命傷を負った。
13. 凪は呼び出したことを当初隠すが、現場にいたことと救急へ連絡した事実は警察に知らせている。
14. 安希は非カムイ使い。物語の決定的な行動・公開の決断は自分で行う。
15. 神谷椿は1602年に死亡し、現代には復活しない。犠牲者の名簿は椿自身が残した。
16. 警察による事件捜査、行政監査、裁判上の判断は別の過程。読者への真相の開示と法的な確定は区別する。

## 漫画制作で特に注意すること

- 榊の死亡時に金具へ凪が「留め針」を当てるのは、久住が修復を発動する**前**。
- 2018年の安全栓は修復済み。現物には弾痕が残らない。修復前の写真と交換票を手掛かりとする。
- 久住が1度に複数の扉を同時に動かす場面は描かない。
- 「留め針」で凪が止められるのは損傷の修復。扉が動いていること自体は止められない。最終部の二者択一は、どちらも2026年に生じた新しい損傷を対象とする。
- 2018年の水門操作が避難警告の遅れを必然化したわけではない。どの判断に責任があるかは分ける。
- 安希が得た帳簿1枚だけで殺人の実行者が確定する展開にはしない。
- 榊の口封じには久住の動機が必要だが、凪を殺そうとしたかは場面の具体化で詰める。

## 未確定事項

- 正確な日付・時刻と、2018年の避難情報の伝達経路。
- 水門の実施設計と、2026年の事件現場の扉と通路配置の画面上の最終確定。[空間・時刻の暫定設計](../story/scene-geometry.md) を参照。
- 「留め針」の損傷の部分性と、物証としての保全の限界。
- 漫画の具体的な巻数・ページ数・背景作画。
- 榊が再調査へ向かったとき、どの証拠の所在まで把握していたか。

未確定事項は描く前に確定するが、面白さを損なう制約は設定の方を改めてよい。
