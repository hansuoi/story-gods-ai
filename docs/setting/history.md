# 年表

| 年 | 出来事 |
| --- | --- |
| 1576 | 神谷椿誕生 |
| 1598 | 神鵠村の洪水。椿の堰切りで低地の12人が死亡。椿は名簿を残す |
| 1602 | 椿が26歳で死亡 |
| 近代以降 | 椿が神楽によって「犠牲者のいない救済者」として神格化され、名簿の存在が忘れられていく |
| 2018 | 汀橋水害。病院区画は救われるが住宅区画で6人が死亡 |
| 2018 | 榊は避難支援中に水鉄砲で補助水門の安全栓を撃ち、久住が水門を開ける |
| 2018 | 榊は後に民間調査を請け負うが、自分の関与と凪の証言を依頼者へ報告しない |
| 2018以降 | 神楽は被災者の地域支援を行い、久住は凪に修復の仕事を教える |
| 2026 | 凪が2018年の安全栓の保管資料を発見して榊を旧施設へ呼び出す |
| 2026 | 久住が榊を殺害。凪が損傷を短時間留めて撮影する |
| 2026 | 安希が夫の死と過去の水害を調べ始める |
| 2026 | 記録移送の際に久住が排水ハッチを開き、紙資料の破損を狙って凪を襲う。久住は身柄を確保され、捜査と監査が進む |
| 2027年初頭ごろ | 数か月後。神楽の記録手順と椿の展示に変更があり、安希は事務所で新しい依頼を引き受ける |

## 史実と創作

汀橋、神鵠村の堰切り、神楽の防災事業はフィクション。原作の設定を流用した名称であっても、このリメイク版の出来事として独立させる。
