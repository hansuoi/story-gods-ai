# 原作からの変更と判断理由

自由改変を前提とし、**残した理由が説明できない要素は自動採用しない**。原作との一致が作品の優劣を決めるわけではない。

| 対象 | 判断 | 理由 |
| --- | --- | --- |
| 作品名「神谷家」 | 維持 | 安希が夫の死後も家族と事務所の記録を引き受ける、物語の中心に直結する |
| 副題 | 「神様が直せないもの」から「原状回復」へ変更 | 物理的な修復と、失われた関係を元に戻したい気持ちを重ねられる |
| 主人公・北内海美 | 不採用 | 仇討ち・師弟関係が原作の展開を繰り返す主因となっていた |
| 神谷安希 | 主人公に変更 | 原作では妻の役割が主だったが、夫の死と過去の調査を選ぶ主体へ転換できる |
| 神谷榊 | 故人として登場 | 最強の師匠を置くのではなく、証言によって姿が変わる人物として描ける |
| 榊のキャサディ・キャサディ | 維持 | 弱い能力を制限で強化する仕組みが人物の工夫と水害の舞台に結びつく |
| 栞 | 不採用 | 原作の友人関係を残す理由がなく、調査の役割を主人公が担える |
| 神谷詞野介 | 現時点では登場させない | 原作の家族構成を自動継承せず、夫婦と故人への向き合い方に集中する |
| 三枝凪 | 新設 | 修復を止める能力と、被災者・目撃者の立場を統合する |
| ローリング・スター | 不採用 | 原作のロザリオと能力の由来を引き継ぐ必然がない。新能力「留め針」に設計し直す |
| 鈴宮耕平・毒慄 | 不採用 | 武装組織との抗争を続ける必要がなく、主題と役割が重複する |
| 神谷椿 | 名前を残し全面改変 | 原作との接点を保ちつつ、復活する敵ではなく、後世に評価が書き換えられた歴史人物として扱う |
| 神谷椿の性別 | 女性へ変更 | 神格化された母性的な聖人像と、現実に苦渋の選択をした人物像を対比する |
| 椿の能力 | 質量操作から「継ぎ目」に変更 | 水門の開閉という選択と自然に結びつき、16世紀の道具・風景に適合する |
| 芹沢慧 | 新設 | 単なる邪悪な宗教指導者ではなく、事業を継続したい現場責任者を描く |
| 久住真琴 | 新設 | 水門事件と榊殺害を、同じ能力と人物の別の判断で接続する |
| 神楽 | 公共防災組織として再設計 | 実際に人を救っている組織にも隠蔽がある、という葛藤を作れる |
| 公安マイナス1課 | 不採用 | 秘密能力社会の維持より、公開された社会での記録と責任が重要だから |
| カムイ能力の周知 | 公知の制度へ変更 | 目撃者・映像が普及した社会で能力の存在を全面的に隠す不自然さを避ける |
| 神の無干渉 | 維持、条件を明確化 | 物理的な修復が責任の解消ではない、という事件の核になる |
| 濁神 | 背景設定に後退 | 中心事件に必要がなく、現時点で使うと能力体系が散漫になる |
| 帰天環 | 不採用 | 都市規模の決戦へ物語を引っ張り、中心事件から離れてしまう |
| 原作全10部 | 不採用 | 世代交代より、1人の遺族が事件と向き合う時間に集中する |

## 名前の方針

- **神谷榊・神谷安希・神谷椿:** 原作との直接の接点として意図的に継承。名前の字面が物語の真相を説明する、という後付けはしない。
- **三枝凪・芹沢慧・久住真琴:** AI版の役割に合わせて新設。名前よりも、人物の判断と口調によって区別する。
- 旧作の組織名・能力名・人物名は、登場させたいという理由だけでは再導入しない。
