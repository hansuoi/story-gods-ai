# 原作からの主な変更点

この文書では、原作『神谷家の呪われし宿命』からAI版への変更を記録する。原作の設定・展開がAI版の出来事を自動的に決めることはない。

| 対象 | 引き継ぐ点 | AI版で変更する点 |
| --- | --- | --- |
| 舞台 | 魂ヶ丘市・神谷探偵事務所・学園 | 修復と秘匿を主要な社会問題にする |
| カムイ | 神が力を貸す、"心"を消費する、能力には制限がある | 能力の証拠保全上の問題を強調する |
| 神の無干渉 | 物体・肉体の損傷を修復するが、生命は戻らない | 捜査サスペンスと中心的な対立に使う |
| 濁神 | 生命を代償とし、死後も能力が持続し得る | 修復されない例外として活用する |
| ローリング・スター | 物理的なカムイ攻撃の無効化 | 神の無干渉による修復も局所的に阻止できる |
| 神器 | 特定の使い手以外も利用可能な特殊なカムイ | 都市規模の修復神器「帰天環」を追加 |
| 神谷榊 | 探偵、水の能力、道下の遺志 | 過去の隠蔽への責任を問われる |
| 北内海美 | 母の死、ロザリオ、復讐心 | 敵討ちから証拠保全へ目的を変える |
| 栞 | 海美の友人 | 非能力者の調査担当・視点人物とする |
| 神谷椿 | 神楽が崇拝する存在、封印と復活 | 支配の方法と思想の由来を再構成する |
| 毒慄 | 鈴宮が率いる武装組織 | 国家への告発と暴力の問題を強調する |
| 神楽 | 椿を神格化する宗教組織 | 都市の修復を救済として演出する |
| 公安マイナス1課 | カムイ犯罪を扱う秘密部署 | 隠蔽による被害と組織内の対立を扱う |
| 全10部構成 | 世代を超える意思の継承 | 全5章・単一長編へ変更する |
| 結末 | 椿との決着、宿命の解消 | 被害の記録と責任、血縁を超える継承 |
