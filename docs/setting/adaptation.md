# 原作からの変更

判断の最優先は「この漫画が面白くなるか」。原作と同じこと自体に価値を置かず、残す理由がある設定だけ引き継ぐ。

| 対象 | 採否・変更 | 物語上の理由 |
| --- | --- | --- |
| 神谷家という題名 | 継承 | 神谷榊を失った妻が、夫の功績も過ちも引き受ける家族劇の中心だから |
| 副題 | 原状回復 | カムイの修復と、元に戻らない家族を対比させる |
| 神谷安希 | 主人公へ | 強力な能力では解決できない事件を、記録と人間関係の選択で動かせる |
| 神谷榊 | 故人 | 回想で魅力を示し、捜査で過去の別の一面が明らかになる |
| 榊のキャサディ・キャサディ | 継承 | 少量の水と制限の駆け引きが映える。2018年の行為の手掛かりにもできる |
| 北内海美、鈴宮、毒慄、公安マイナス1課 | 不採用 | 師弟抗争や大規模戦争より、この事件の人物関係を濃くする方が適切 |
| 三枝凪 | 新設 | 限定的な修復停止能力、榊との過去、久住への信頼を一人の人物に持たせられる |
| 「留め針」 | 新設 | 1箇所だけ10分残せるという制約が、証拠か人命かの選択を生む |
| 久住真琴・「蝶番」 | 新設 | 移動を制限する戦闘と、扉を開けて人を救った過去を対比できる |
| 芹沢慧 | 新設 | 現実に人を救った責任者が、不都合な過去を守ろうとする対立を作る |
| 神谷椿 | 性別・能力・生涯を全面改変 | 生前の判断と、後世による美化のギャップを謎にする |
| 神楽 | 防災事業者へ変更 | 倒せば終わる悪の組織でなく、社会が依存する組織との対立を作る |
| 神の無干渉 | 継承・明確化 | 傷は直るが死者は戻らないという、設定自体に感情的な力がある |
| 2018年の榊 | 水門操作に直接関与 | 調査員の報告ミスより、自分が救済と犠牲の当事者である方が痛みが強い |
| 凪と久住 | 指導者と教え子の関係を追加 | 犯人探しが関係の崩壊を伴うようになる |
| 神谷椿の名簿 | 新設 | 過去を隠したのが椿本人とは限らないという反転を作る |
| 師弟による復讐・世代交代・椿の復活 | 不採用 | 新作では同じ役割を担う必然がない |

原作・公開作品ページ: https://ukigmo.work/works/gods01/
