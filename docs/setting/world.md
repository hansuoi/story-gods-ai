# 世界設定

## 舞台: 魂ヶ丘市

東京都多摩地域を下敷きにした架空都市。住宅地・私立学園・宗教施設・警察関連の地下施設が並存する。

- **魂ヶ丘学園**: 海美と栞が通う学校。能力者にまつわる噂がある。
- **神谷探偵事務所**: 住宅街にある探偵事務所。一般の相談もカムイ関連の事件も受ける。
- **神楽本部**: 椿を神として崇拝する宗教組織の拠点。
- **公安マイナス1課の関連施設**: 能力者の記録・監視・拘束に使う秘密施設。
- **地下カジノ・闘技場**: 毒慄の資金源となる施設。

## 社会

カムイは物体・自然現象などに宿る神。カムイの力を扱える人間を「カムイ使い」と呼ぶ。一般社会ではその存在が広く知られていない。

公安マイナス1課はカムイ犯罪を秘匿しながら扱ってきた。カムイが公表されれば社会不安や差別が拡大するという説明には一定の根拠がある。しかし、国家がカムイの軍事利用を検討していることも、秘密保持の背景にある。

カムイによる破損は「神の無干渉」で修復できるが、死んだ人間は生き返らない。証言や記録まで自動的に消えるわけではない。

## 社会的な争点

- カムイ使いと非能力者の権利・扱いの違い。

- 国家による能力の軍事利用。
- 神楽による神の秩序の強制。
- 修復された被害の記録と、加害者の責任。
