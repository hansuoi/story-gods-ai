# 世界設定

## 舞台

2026年の架空都市・魂ヶ丘市。東京都多摩地域を下敷きにした住宅地・丘陵地・学園・河川・排水施設のある都市。

カムイと呼ばれる神々、その力を利用するカムイ使い、能力により損傷した物を修復する「神の無干渉」は、社会に認知されている。

## カムイと社会

カムイ使いの存在を国家が完全に隠しているわけではない。能力の用途・危険性・活動資格をめぐる制度がある。能力使用による損害については、通常の事故や犯罪と同様に調査と責任の検討が必要。

神の無干渉は、物理的な損傷の一部を修復するだけであり、生命の復活、記憶の消去、経歴の変更、行政記録の書き換えはできない。

能力を使う救助・工事に従事する場合は、実施者と使用日時を記録する規定がある。しかし緊急時の逸脱・不適切な記録・組織的な隠蔽が起こり得る。

## 修復事業

宗教法人としての歴史を持つ神楽は、現代では法人としての防災・修復事業も行う。行政から委託を受けた災害対応、修復工事、避難支援を行い、実際に多くの人命を救っている。

一方で事業継続や契約維持のために情報を隠した過去があり、過去の記録を再検証されることを恐れている。神楽の全職員が不正に関与しているわけではない。

## 主な場所

- **神谷探偵事務所:** 榊の仕事場。安希は依頼の受付、請求、記録管理を担当していた。
- **汀橋地区:** 2018年に洪水が発生した住宅地。旧水門と排水管理室がある。
- **市立病院区画:** 汀橋水害で浸水を免れた地域。
- **神楽防災事業部:** 神楽の修復・救助業務を担当する組織。
- **地域資料館:** 神谷椿と神鵠村の災害に関する資料が保存されている。

## 現代の公的機関

事件の捜査は警察、施設・契約の監督は行政と監査部門が担当する。原作の「公安マイナス1課」は採用しない。異能事件の担当者は一般の警察機構内に配置される。

## 作品で扱う問題

- 被害を小さくするための緊急判断と、その後の説明責任。
- 利用価値が高い公共サービスに不正があった場合、どう監督・改善するか。
- 記録が失われることと、意図して記録を隠すことの違い。
- 家族の行為を受け継ぐことと、過去の判断を正当化することの違い。
