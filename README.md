# 神谷家 - 原状回復 -

浮曇非路原作『神谷家の呪われし宿命』のAIリメイク版。

## あらすじ

神谷榊が死んだ。

カムイによる損傷を元に戻す「神の無干渉」が働き、彼の遺体から傷は消えた。しかし、命は戻らなかった。

探偵だった夫の死を調べ始めた神谷安希は、榊がかつて災害の記録を隠していたことを知る。榊の死亡直後の現場に居合わせた若いカムイ使い・三枝凪とともに、8年前の汀橋水害と、神として語り継がれる神谷椿の過去を追う。

夫を守るために、夫の過ちを隠すのか。それとも、愛していた人が何をしたかを残すのか。
