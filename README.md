# 神谷家 - 神様が直せないもの -

浮曇非路原作『神谷家の呪われし宿命』のAIリメイク版。

## 作品概要

カムイと呼ばれる神々の力によって、破壊された物体や肉体が修復される街・魂ヶ丘市。しかし、修復された死体に命は戻らない。

母の死の真相を追う女子高生・北内海美は、修復そのものを無効化する力に目覚める。彼女が探偵・神谷榊と出会ったとき、街で繰り返されてきた死亡事件と、その痕跡を隠してきた仕組みが明らかになり始める。
