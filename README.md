# 神谷家 - 原状回復 -

浮曇非路原作『神谷家の呪われし宿命』のAIリメイク版。

## あらすじ

神谷榊が死んだ。遺体の傷は「神の無干渉」で修復され、何が起きたのかを直接示す痕跡はほとんどない。

残された妻・神谷安希は、榊を最後に旧排水施設へ呼び出した人物が、8年前の水害の生存者・三枝凪だと知る。榊の死亡、6人が亡くなった汀橋水害、神として語り継がれる神谷椿。調査が進むほど、救済者だったはずの榊自身が水害の当事者だったことが明らかになる。

信じた人が嘘をついていたとして、その人と過ごした時間まで嘘になるのか。

## 制作状況

第一部・全18話の漫画脚本初稿を作成済み。第5・6話はテンポ改善の第2稿へ改稿。第1話は32ページの文字ネーム・構図ラフ・連続閲覧用ギャラリーを制作済み。第2話も32ページの文字ネームと個別SVG構図ラフ・連続閲覧ギャラリーを制作済み。第3話は30ページの文字ネーム・レイアウト一覧・能力の動作図・個別SVG構図ラフまで制作済み。第4話は28ページの文字ネーム、現場平面図、全28ページの構図ラフを制作済み。合計で第1～4話122ページのSVG構図ラフが存在する。**人物・背景の仕上げ試作は第1話P01～P08で制作中だが、最終ネームと完成採用原稿は未制作**。脚本・設定・構図は引き続き推敲する。

**閲覧形式:** 当面はデジタルで1ページずつ表示することを基準に演出を設計。紙の見開きへ組む際はページの左右・先読みを再検証する。
