# 神谷家 - 原状回復 -

浮曇非路原作『神谷家の呪われし宿命』のAIリメイク版。

## あらすじ

神谷榊が死んだ。遺体の傷は「神の無干渉」で修復され、何が起きたのかを直接示す痕跡はほとんどない。

残された妻・神谷安希は、榊を最後に旧排水施設へ呼び出した人物が、8年前の水害の生存者・三枝凪だと知る。榊の死亡、6人が亡くなった汀橋水害、神として語り継がれる神谷椿。調査が進むほど、救済者だったはずの榊自身が水害の当事者だったことが明らかになる。

信じた人が嘘をついていたとして、その人と過ごした時間まで嘘になるのか。
